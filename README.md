# Cubicle Survivor

一个办公室加班题材的 Brotato-like 肉鸽小游戏原型。

在线游玩：
https://245269946-blip.github.io/Cubicle-Survivor/

## 当前版本重点

- 武器和个人属性分途径成长，第一关后先选择非咖啡武器方向。
- 加入站场、陷阱、防御、语言、酒意等属性路线和稀有后期选择。
- 后期怪物增加办公室化特性、弱点克制、Boss 出场和随机加班事件。
- 视觉继续向手绘微像素霓虹办公室推进，并压低素材粉色边缘。

## 本地运行

```bash
python -m http.server 5173
```

然后打开 `http://127.0.0.1:5173/`。
