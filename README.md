# Cubicle Survivor

一个办公室加班题材的 Brotato-like 肉鸽小游戏原型。

在线游玩：https://245269946-blip.github.io/Cubicle-Survivor/

## 当前版本重点

- 属性池已精简，幸运承接材料和额外掉落，工程体系由幸运与拾取自然放大，爆发由伤害与暴击承担。
- 经验曲线已重调，第一关升级节奏压到约 2 次，避免早期属性滚雪球。
- 升级改为 4 选 1，并提供 1 次免费刷新，优先照顾当前武器方向。
- 武器升级加入 Lv.3 / Lv.5 / Lv.7 质变点，路线 Tier 3 也会解锁中期行为特效。
- 路线升阶会即时给材料、伤害或武器等级奖励，并进入可回看的终局线索。
- 混合 Build 增加“全能工位”兜底共鸣，不再只有专精路线有爽点。
- 商店武器强化拆分出频率、弹量、贯穿、范围、脉冲、连锁等方向。
- 暂停和 Build 面板可查看武器等级、职业共鸣、终局线索和属性。
- 暂停面板增加“放弃本轮”，开始页改为更完整的游戏入口和引导卡片。
- 关卡 Banner 区分随机事件、章节内容与新威胁提示，后期波次更长。
- 难度曲线重调，降低后期刷怪和精英血量的断层，保留终局压力但减少纯数值墙。
- 战斗可读性增强：角色光环、危险敌人警告、粒子透明度收束。

## 本地运行

```bash
python -m http.server 5173
```

然后打开 `http://127.0.0.1:5173/`。
