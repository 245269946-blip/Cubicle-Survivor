# Demo V3.8 — 保温杯双路泄压反馈

## 本轮目标

Demo V3.8 完整继承 Demo V3.7 的数值、关卡、敌群、Boss、模块、组件和穿戴结构，只解决一个视觉问题：

> 保温杯背部压力装置不能只是合理地存在，还必须在每次攻击时显露其工作过程。

## 攻击因果链

每轮保温杯攻击统一表现为：

> 背部压力装置释放贴身半环压力波并产生短促后坐 → 压力经管线送至近身杯体 → 杯口喷出真实攻击。

泄压动画与真实攻击事件同步触发，不使用独立装饰计时器。

## 路线语法

### 未选择模块

- 中央装置释放贴身的中性白色小半环。
- 只负责说明基础压力系统正在工作，不伪装成任何模块路线。

### 冷凝

- 冷青冰雾、霜粒和十字冰晶沿角色冷凝侧形成贴身半环，并向外扩一小段后消散。
- 冷凝外挂包产生短促前向回弹，表现压力缓冲。
- 等级越高，半环半径、冰雾厚度和冰晶密度越明显，但不改变伤害判定。

### 击杀热浪

- 琥珀高温蒸汽、亮白热核和波形火星沿角色热浪侧形成贴身半环，并向外扩一小段后消散。
- 热浪储压包产生独立短促回弹。
- 等级越高，半环半径、热核亮度和火星数量越明显。

### 混合路线

- 两侧可以在同一次攻击中同时出现各自的半环。
- 冷凝始终为冷青冰雾，热浪始终为琥珀热蒸汽。
- 不把两条路线混成同色大光团，不遮挡杯口主攻击。

## 视觉层级

1. 杯口主攻击仍是伤害方向的第一读数。
2. 背部泄压是“装置如何驱动攻击”的第二读数。
3. 外挂包辉光与回弹是路线和等级读数。
4. 泄压事件不产生伤害、控制或额外攻击判定。

## 验收

- 每轮真实攻击只触发一次对应路线半环。
- 冷凝和热浪在实机尺寸下一眼可区分。
- 双路线同时存在时，两侧喷流仍可分别追溯到对应外挂包。
- 外挂包回弹只跟随人物身体方向，不跟随自动瞄准旋转。
- Demo V3.7 与 Demo V3.8 的四武器数值快照完全一致。
