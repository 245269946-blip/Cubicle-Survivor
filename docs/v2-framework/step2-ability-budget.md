# 第 2 步：能力预算表 — 双轴系统的功率分配

**日期：2026-06-22**
**前提：核心公式已冻结。现在给每个槽位、每张卡、每个协同分配功率预算。**

---

## 2.0 预算原理

> **槽位不平均。天赋 = 基准 100%，其余槽位的功率通过"风险折价"和"条件缩放"来差异化。**
> **总功率上限由现有 softCap 约束（1.82/2.18），不做新硬上限。**

---

## 2.1 五大属性槽的功率系数

每个槽位有一个**功率系数**（相对于"天赋"的 100%）：

| 属性槽 | 功率系数 | 条件 | 设计理由 |
|--------|---------|------|---------|
| 🧠 天赋 | 100% | 稳定，无代价 | 基准线 |
| 🔧 技能 | 80~100% | 随部门投资从 80%→100%（线性） | 初期弱、后期追上 |
| 💪 努力 | 140% | 每触发效果带 20% 代价（扣血/降速） | 净收益 120%，但风险自担 |
| 🤝 人脉 | 70%+10%/每张其他卡 | 上限 130%（6 张其他卡） | 孤狼 70%，满联动 130% |
| 🎲 运气 | 40%~300% | 概率分布：10%~30%触发率 | 期望值 ~90%，方差极大 |

**为什么不是平均分配：**
- 平均分配的后果：玩家永远选天赋（最稳），其他槽失去意义
- 差异化：每个槽瞄准不同玩家心理
  - 求稳 → 天赋
  - 成长型 → 技能
  - 激进 → 努力
  - 联动型 → 人脉
  - 赌徒 → 运气

## 2.2 部门投资缩放（Dead Cells 式）的功率预算

```
部门投资等级 = 该部门拥有的卡牌数量

Lv.1 (1张): 基准，无加成          → 总功率 1.00×
Lv.2 (2张): 该部门所有卡 +8%     → 总功率 1.16×（2×1.08-2×1.00=0.16）
Lv.3 (3张): 该部门所有卡 +16%    → 总功率 1.48×（3×1.16-3×1.00=0.48）
Lv.4 (4张): 该部门所有卡 +28%    → 总功率 2.12×（4×1.28-4×1.00=1.12）
Lv.5 (5张): 该部门所有卡 +42%    → 总功率 3.10×（5×1.42-5×1.00=2.10）
```

**边界检查：**
- Lv.2 (2 张同部门)：+16% 额外功率 → 散在 2-5 个槽位，每槽不到 8% → 安全
- Lv.3 (3 张同部门)：+48% 额外功率 → 可能集中到 2-3 槽 → 开始需要 softCap 保护
- Lv.4 (4 张同部门)：+112% 额外功率 → 软上限大概率触发
- Lv.5 (5 张同部门)：理论上限，极少出现 → 此时硬上限必然触发

**关键约束：部门投资缩放不绕过 softCap。** 即使部门 Lv.5 给出 +42%，如果 damageMult 已到 1.82，后续只算 0.35 每点。

## 2.3 武器套装加成（Brotato 式）的功率预算

```
同部门武器 2 把：该部门卡在「天赋/技能」槽 +10%
同部门武器 3 把：所有槽位该部门卡 +15%，该部门稀有卡概率 +15%
同部门武器 4 把：传说卡前置从 3→2 张

功率影响：
2 把：+10% × min(2张, 活跃槽) ≈ +10%~20% 额外功率 → 安全
3 把：+15% × min(3张, 活跃槽) ≈ +15%~45% 额外功率 → 中等
4 把：降传说前置 → 质变（不是数值问题，是机制问题）
```

**和部门投资缩放叠加检查：**
- 最极端情况：部门 Lv.3 (+16%) + 武器 3 把 (+15%) = 天赋/技能槽卡牌 +31%
- 一张"天赋槽·产品部·紧急上线"(攻速+35%) → 实际 +45.85% 攻速
- 从 0 攻速加上 45.85 → 65.4 → 超过 softCap 62 → 软上限触发
- **结论：叠加最大功率受现有 softCap 保护，无需新增上限。**

## 2.4 单张卡牌功率预算

### 2.4.1 卡牌稀有度功率等级

| 稀有度 | 功率预算（以天赋槽为基准）| 前置条件 | 本局可获数量 |
|--------|--------------------------|---------|------------|
| 普通 | 100 功率点 | 无 | 不限 |
| 稀有 | 150 功率点 | 同部门≥1 张 | 每个部门上限 1 张 |
| 传说 | 200 功率点 | 同部门≥3 张（或 2 张+4 把武器）| 整个本局 1 张 |

**功率点含义：** 普通卡天赋槽基准 = 1.0 单位效果。例如：
- +3% damageMult per card 级普通卡天赋槽 = 普通卡预算
- +5% damageMult 稀有卡天赋槽 = 稀有卡预算（150%）

### 2.4.2 功率分配到各槽位

同一张卡，在不同槽位的功率 = 稀有度功率 × 槽位系数：

例：产品部"紧急上线"（普通卡，100 功率点）

| 槽位 | 槽位系数 | 实际功率 | 效果示例 |
|------|---------|---------|---------|
| 天赋 | 1.0 | 100% | 攻速 +35% |
| 技能 | 0.8~1.0 | 80~100% | 暴击率 +10~15% |
| 努力 | 1.4 | 140% | 攻速 +50%，但每秒扣 1% HP |
| 人脉 | 0.7+0.1×N | 70~130% | 攻速 +25~45%（受其他卡影响） |
| 运气 | 0.4~3.0 | 40~300% | 5% 概率触发 3 秒攻速翻倍 |

## 2.5 10 把武器的功率基础值

每个武器在 Lv.1 时的 DPS 基准（约数，不精确）：

| 武器 | Lv.1 大致 DPS | 类型 | 风险等级 | 部门 |
|------|-------------|------|---------|------|
| 键盘 ⌨️ | 8-12 h/s × 方向限制 | 近战挥击 | 高（需近身）| 产品 |
| 马克笔 🖊️ | 6-8 h/s × 瞄准需要 | 精准射线 | 高（需瞄准）| 产品 |
| 咖啡 ☕ | 5-7 h/s 自动 | 自动射击 | 低 | 技术 |
| 计算器 🧮 | 4-5 h/s × 链 | 链电 | 低 | 技术 |
| 耳机 🎧 | 3-4 h/s × 光环 | 光环 | 极低 | 运营 |
| 保温杯 🫖 | 治疗为主 | 治疗 | 极低 | 运营 |
| 订书机 📎 | 6-8 h/s × 扇形 | 扇形弹幕 | 中 | 市场 |
| 报表 📊 | 4-5 h/s × 轨道 | 轨道 | 低 | 市场 |
| 便签 🟨 | 5-7 h/s × 陷阱 | 陷阱 | 中（需预判）| 综合 |
| 碎纸机 🗑️ | 7-9 h/s × 锥形 | 锥形绞碎 | 中 | 综合 |

**功率预算规则：**
- 高风险武器（键盘/马克笔）→ 基础 DPS 更高（因为玩家操作失误会丢失输出）
- 低风险武器（耳机/保温杯）→ 基础 DPS 更低（因为几乎不失误）
- 部门分布：产品部武器风险最高、技术部居中、运营部最低

## 2.6 协同系统的功率预算

### 2.6.1 属性 × 属性协同（10 种）

| 协同 | 功率 | 触发条件 | 设计理由 |
|------|------|---------|---------|
| 学以致用 | +5%/每张技能卡 | 天赋+技能均有卡 | 线性缩放，鼓励双修 |
| 天才加班 | 天赋×0.5, 努力×1.5 | 天赋+努力均有卡 | 转化型（牺牲稳定换爆发） |
| 师徒传承 | 技能 + 人脉卡数×20% | 技能+人脉均有卡 | 联动奖励 |
| 厚积薄发 | 累积值一次性释放 | 技能+运气均有卡 | 蓄力型（可叠但延迟收益） |
| 兄弟同心 | 努力代价分摊 | 努力+人脉均有卡 | 减损型 |
| 孤注一掷 | 努力代价×1.5, 运气×2 | 努力+运气均有卡 | 高风险型 |
| 天选之子 | 天赋 + 运气触发率比例 | 天赋+运气均有卡 | 混合型 |
| 贵人相助 | 运气触发时人脉翻倍 | 人脉+运气均有卡 | 触发型 |
| 精英推荐 | 天赋时激活人脉联动 | 天赋+人脉均有卡 | 随机激活型 |
| 苦练成才 | 技能叠加上限翻倍 | 技能+努力均有卡 | 成长型 |

**功率预算确保：每种协同的额外功率不超过 20% 总功率。** 经过 softCap 约束后实际更少。

### 2.6.2 部门 × 部门协同（10 种）

| 协同 | 功率 | 条件 | 限制 |
|------|------|------|------|
| 敏捷创新 | 暴击触发链电 | 技术+产品各≥1 | 不叠加伤害倍率，只加机制 |
| 稳定交付 | 防御状态链电翻倍 | 技术+运营各≥1 | 站立条件绑定 |
| 病毒传播 | 链电溅射范围伤害 | 技术+市场各≥1 | 溅射伤害 30% |
| 技术管理 | 链电资源成本减半 | 技术+综合各≥1 | 机制优化 |
| 快速上线 | 暴击时获小护盾 | 产品+运营各≥1 | 护盾上限 3 层 |
| 爆款策略 | 暴击击退+击退区域 | 产品+市场各≥1 | 击退伤害另算 |
| 产品立项 | 杀敌后 2s 全武器+20% | 产品+综合各≥1 | 条件触发，不恒常 |
| 标准运营 | 防御状态范围伤害全屏 | 运营+市场各≥1 | 站立条件绑定 |
| 全域管理 | 治疗量受护甲加成 | 运营+综合各≥1 | 线性映射 |
| 全面投放 | 拾取范围+100%+自动吸附 | 市场+综合各≥1 | 质变（非数值）|

**部门协同全部是机制型（非纯数值型），不直接叠加 damageMult/attackSpeed。** 这是和属性协同的最大区别。

## 2.7 禁止同时出现的组合

以下组合由于会产生混沌交互或超出预算，必须互斥：

| 禁止组合 | 理由 |
|---------|------|
| 努力槽 + 运气槽同时有"截止日期" | 即死概率 + 扣血代价 = 不可控死亡 |
| 同一部门传说卡 × 2 | 本局只有 1 张传说 |
| 天赋槽"技术突破" + 努力槽"敏捷开发"同时触发 | 链电暴击 + 扣血 + 攻速翻倍 = 预算溢出 |
| 全员持股 X 全员持股（重复）| 不可重复获取同卡 |
| 所有 5 个槽位同一部门 | 部门池限制：本局只出现 3 个部门，不可能 5 张同部门 |

**大部分预算问题由"本局只有 3 个部门出现" + "传说 1 张"自然解决。** 不需要额外写大量互斥代码。
