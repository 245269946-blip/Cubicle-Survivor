# Demo V1 武器 x 工牌形态方案

本文件记录新的武器形态基准。核心原则：先确认每把武器的基础拓扑，再让五个部门在同一拓扑上延展，而不是把一个部门效果硬套到所有武器上。

## 代表部门原则

每把武器的代表部门，必须把它的母题推到其他部门无法模仿的极致。玩家不是在选“哪个部门加成更好”，而是在选“我要把这件办公工具养成什么荒诞职场武器”。

| 武器 | 代表部门极致 |
| --- | --- |
| 马克笔 | 画线分裂 |
| 挂耳咖啡 | 续杯自动化 |
| 键盘 | 近身盾反输入 |
| 订书机 | 装订封锁线 |
| 降噪耳机 | 声波接力传播 |
| 保温杯 | 蓄热沸点释放 |
| 季度报表 | KPI 窗口审判 |
| 碎纸机 | 粉碎纸屑龙卷 |
| 即时贴 | 贴纸公告板阵地 |
| 财务计算器 | 审计账目结算 |

优先垂直切片：

- 马克笔：验证线性分裂拓扑。
- 保温杯：验证蓄力释放拓扑。
- 即时贴：验证布阵连线拓扑。

这三把先跑通后，再扩展到其余武器。

## 当前判断

这版比上一版更适合落地，原因是它先固定了每把武器的空间拓扑，再给部门附加不同触发规则。玩家能通过画面理解差异：线、点、环、场、节点、连线、蓄力、弹匣、护盾、标记，这些都比抽象“链电/扩散/成长”更直观。

三把垂直切片的价值：

- 马克笔负责证明“同一条线如何变成分裂、标记、反射、波纹、网格”。
- 保温杯负责证明“等待、蓄热、释放、空窗”这类节奏型武器能不能成立。
- 即时贴负责证明“提前布阵、区域连线、触发收获”这类规划型武器是否好玩。

后续实现时，不能先做全部矩阵。先把这三把做到战斗里肉眼可见，再决定其余七把是否需要合并、删减或换拓扑。
