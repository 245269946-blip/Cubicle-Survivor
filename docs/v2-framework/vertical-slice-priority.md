# V2 垂直切片优先级

## 先做三把

第一批只做马克笔、保温杯、即时贴，不铺满 10 把武器。

| 武器 | 验证主题 | 为什么先做 |
| --- | --- | --- |
| 马克笔 | 线性分裂 | 最直接验证“走位拉直线 -> 击中队列 -> 形态变化”的爽感。 |
| 保温杯 | 蓄力释放 | 验证慢启动、热量条、爆发窗口和空窗风险是否成立。 |
| 即时贴 | 布阵连线 | 验证陷阱、节点、连线、区域控制这种规划型玩法是否能被玩家看懂。 |

## 三把之间不要互相替代

马克笔是即时反馈型，玩家每次发射都能看见线性收益。

保温杯是节奏反馈型，玩家要看见热量积累、释放瞬间和释放后的空窗。

即时贴是延迟反馈型，玩家要先布置，再看敌人踩中、贴纸连线或区域成型。

这三种拓扑刚好覆盖 V2 体系的核心问题：玩家是否能在战斗里看懂自己的 Build 正在改变什么。

## 第一轮实现验收

马克笔：

- 基础形态必须是长射程贯穿线，不是短射线或贴图闪一下。
- 技术部分裂支线要有明确的“命中后分叉”过程。
- 产品部 P0 标记必须能在敌人身上看到标记、窗口、二次引爆。
- 运营部应急盾要能看到护盾积累和破盾反射。
- 市场部终点波纹要有线到面的转化。
- 行政部残留线交叉后生成网格，网格要明显限制敌人。

保温杯：

- 热量条、蓄热声/光、满热释放、释放后空窗必须完整。
- 产品部沸点爆发是标杆形态，释放瞬间要足够爽，但空窗必须真实存在。
- 运营部和行政部要偏容错/据点，不要抢产品部爆发定位。

即时贴：

- 贴纸落地、等待、触发必须有独立帧过程。
- 行政部公告板阵地是标杆形态，三点成区必须可读。
- 产品部手动/二次触发如果没有操作入口，第一版可以先做“玩家经过触发”。

## 不做的事

- 不先铺满所有 10 把武器。
- 不用纯文字解释形态差异。
- 不把部门效果做成一套跨武器通用数值模板。
- 不把五槽继续做成随机堆属性；五槽必须服务当前主武器形态。
