# 第 4 步：关卡考试逻辑 — 每关考什么

**日期：2026-06-22**
**前提：Build 剖面完成。现在按"考试"逻辑重排 14 关的敌人组合和压力曲线。**

---

## 4.0 考试设计原则

> **每关 = 一道考题。敌人不是堆数量，是出题。**
> **题目难度渐进，但类型不同——不是"更高的数值"，是"新的解题要求"。**
> **每道题都可以被至少 2 种 Build 解答，但不同 Build 的解题难度不同。**

---

## 4.1 14 关考试清单

### 第 1 关：漏洞潮 — 「你选好了吗」
- **考什么：** 基本输出能力（DPS 检测）
- **敌人：** 80% bug（基础杂兵）+ 20% change（快速骚扰）
- **配置：** 少量、慢速、低血量
- **各种 Build 的表现：**
  - 纯技栈：链电 2 跳够用 ✅
  - 产品冲刺：马克笔蓄力可以练手 ✅
  - 运营堡垒：伤害低需要多打几秒 ⚠️
  - 综合管理：陷阱预判练习 ✅
- **通过标准：** 只要你没挂机，都能过

### 第 2 关：需求变更 — 「你还跟得上吗」
- **考什么：** 移动战能力 + 多方向敌人处理
- **敌人：** 60% change（速度 118）+ 30% bug + 10% intern（更快）
- **配置：** 从四面八方来，考验转身和方向判断
- **各种 Build 的表现：**
  - 产品冲刺：键盘近战挥击随意转 ✅
  - 市场辐射：订书机扇形跟方向 ⚠️（方向判断失误覆盖不全）
  - 运营堡垒：耳机自动环绕，轻松 ✅
  - 纯技栈：咖啡自动瞄准 ✅
- **通过标准：** 不被 speed 118 的 change 群围死

### 第 3 关：会议轰炸 — 「你有空间感吗」
- **考什么：** 空间管理 + 减速抗性
- **敌人：** 70% meeting（中型，HP 48+，速度慢但血厚）+ 30% change
- **机制：** meeting 死后留下减速区域（2s，-30% 移动）
- **各种 Build 的表现：**
  - 运营堡垒：站桩不吃亏（本来就不动）✅
  - 产品冲刺：需要走位找后排 meeting → 被减速 ⚠️
  - 市场辐射：击退 meeting 不让近身 ✅
- **通过标准：** meeting 的血量成为第一个 DPS 墙

### 第 4 关：Deadline 冲刺 — 「守得住近身吗」
- **考什么：** 近身防御 + 爆发窗口
- **敌人：** 50% deadline（远程射击，伤害 15）+ 30% intern（高速近身）+ 20% bug
- **机制：** deadline 从远处射击，intern 高速冲脸 → 远近双重压力
- **各种 Build 的表现：**
  - 产品冲刺：冲过去先杀 deadline ✅
  - 运营堡垒：耳机光环 + 保温杯治疗撑住 ✅
  - 纯技栈：咖啡自动打最近 → 可能先打 intern 而 deadline 在射 ⚠️
  - 天选之子：运气不好 = 被 deadline 点死 ❌
- **通过标准：** 不被远程+近战双重压力打死

### 第 5 关：复盘压力 — 「输出跟上了吗」
- **考什么：** 综合 DPS 检验（第一道真正的坎）
- **敌人：** 40% bug + 20% change + 20% meeting + 20% emergency（精英）
- **机制：** 混合敌人种类 + 第一个精英群
- **各种 Build 的表现：**
  - 纯技栈：链电 4 跳开始清屏 ✅
  - 产品冲刺：半血以下截止日期激活 ✅
  - 运营堡垒：DPS 可能不够 → 被 emergency 压血线 ⚠️
- **通过标准：** 精英群处理能力
- **⚠️ 这是玩家反馈"可以挂机"的关——第 5 关不是终考，是期中考**

### 第 6 关：季度审判 — 「精英群你扛得住吗」
- **考什么：** 精英爆发处理
- **敌人：** 50% emergency（精英）+ 30% meeting + 20% alarm（高速高伤）
- **配置：** 精英密度最高的一关，同时出现 3-4 个 emergency
- **各种 Build 的表现：**
  - 产品冲刺：截止日期 +80% 对半血 → 逐个击杀 ✅
  - 敏捷创新：暴击链电双触发 ← 最优解
  - 运营堡垒：有防御但清得慢 → 可能被堆 ⚠️
- **通过标准：** 能否在被精英群压垮前逐一消灭 → **检验 Build 的单体输出**

### 第 7 关：紧急上线 — 「控制手段够吗」
- **考什么：** 高速敌人控制 + 远程压制
- **敌人：** 50% alarm（速度 86，伤害 9）+ 30% deadline（远程）+ 20% intern（极速 102）
- **机制：** 高速冲击 + 远程狙击 = 移动空间被压缩
- **各种 Build 的表现：**
  - 市场辐射：击退 alarm 不让近身 ✅
  - 综合管理：便签陷阱减速 alarm → 逐个处理 ✅
  - 产品冲刺：键盘挥击清近身 → 但处理不完远程 ⚠️
- **通过标准：** 有没有控制/减速手段处理高速群

### 第 8 关：跨组拉齐 — 「被围了能清场吗」
- **考什么：** 被包围后的清场能力
- **敌人：** 60% meeting（血牛围城）+ 25% audit（超重甲）+ 15% change
- **机制：** 从四个方向包围，meeting 形成肉墙，audit 在肉墙后
- **各种 Build 的表现：**
  - 纯技栈：链电穿透 → 完美 ✅（最优解）
  - 运营堡垒：站立 3 秒全屏脉冲 → 清 ✅
  - 产品冲刺：需要冲出一个口 → 风险 ⚠️
- **通过标准：** 清场/突围能力

### 第 9 关：财年封版 — 「家底够厚吗」
- **考什么：** 资源管理
- **敌人：** 40% bug + 20% change + 20% meeting + 20% manager（Boss 级）
- **机制：** 材料掉落减半（政策），manager 开始出现 → 需要之前积累的资源
- **各种 Build 的表现：**
  - 综合管理：留痕存档 + 经验加成 → 资源最充裕 ✅
  - 纯技栈：依赖升级 → 材料减半影响大 ⚠️
- **通过标准：** 是否有足够资源应对前半段的积累不足

### 第 10 关：审计追问 — 「续航还有吗」
- **考什么：** 持久战续航
- **敌人：** 50% audit（HP 极高）+ 30% meeting + 20% emergency
- **配置：** 大量血牛，战斗时间拉长到 50 秒
- **各种 Build 的表现：**
  - 运营堡垒：死不了 → 慢慢打 ✅
  - 产品冲刺：续航不够 → 被拖死？⚠️（需要足够输出）
  - 稳定交付：边打边养 ✅
- **通过标准：** 50 秒的长时间战斗能不能撑住

### 第 11 关：组织调整 — 「混合压力怎么应对」
- **考什么：** 复合题型——之前 3-10 关的混合
- **敌人：** 所有 8 种敌人混合，随机组合
- **机制：** 敌人类型完全随机，不能用一种解题方法
- **各种 Build 的表现：**
  - 综合管理：万能，什么都能打 ✅
  - 任何专精 Build：可能遇到克星 → 考验短板 ⚠️
- **通过标准：** Build 的综合完整性

### 第 12 关：灰度事故 — 「高速冲击下能守住吗」
- **考什么：** 极限速度 + 近身冲击
- **敌人：** 50% intern（极速 102）+ 30% alarm（速度 86）+ 20% deadline
- **机制：** 敌人速度全面加速 +20%，形成高速浪潮
- **各种 Build 的表现：**
  - 产品冲刺：攻速够快 → 挥得过来 ✅
  - 兄弟同心：代价分摊 → 不会暴毙 ✅
  - 运营堡垒：站桩光环 → 高速敌人突入 ⚠️
- **通过标准：** 攻击频率能不能覆盖高速敌群

### 第 13 关：年度述职 — 「最后一道综合题」
- **考什么：** 完整 Build 的最终验证
- **敌人：** 40% manager（Boss 级）+ 30% audit + 30% emergency
- **配置：** 数量虽少，但每个都是硬骨头
- **各种 Build 的表现：**
  - "所有 Build 的期末考试"——能到这里的都能打，但难易不同
- **通过标准：** 有没有在之前的 12 关里建立起完整体系

### 第 14 关：终局评审 — 「Boss 决战」
- **考什么：** Boss 斩杀 + 清杂兵的双线程
- **敌人：** 1 个终极 Boss + 持续刷新的杂兵（bug / change）
- **机制：** Boss 有多阶段（70%/40% HP 切换形态）
- **各种 Build 的表现：**
  - 产品冲刺：Boss 杀手 ✅（最优解）
  - 纯技栈：链电弹回打 Boss 有效 ✅
  - 运营堡垒：死不了但 Boss 打不死 → 可能超时 ⚠️

## 4.2 敌人功能职责映射

不只是"不同血量速度组合"，而是"不同功能问题"：

| 敌人 | 功能职责 | 出的考题 | 应对 Build 示例 |
|------|---------|---------|----------------|
| bug | 基础填充 | 基本 DPS | 任何 |
| change | 快速绕后 | 方向切换 | 产品/技术 |
| intern | 极限速度 | 攻击频率 | 产品/市场 |
| meeting | 减速肉盾 | 空间管理 | 运营/市场 |
| deadline | 远程狙击 | 近身清理 or 长手对抗 | 产品/技术 |
| emergency | 精英爆发 | 单体斩杀 | 产品/敏捷创新 |
| alarm | 高速高伤 | 控制手段 | 市场/综合 |
| audit | 超重甲 | 穿透/持续输出 | 技术/稳定交付 |
| manager | Boss 级 | 全面 Build 验证 | 产品/敏捷创新 |
| boss | 终极 | 完整体系 | 任何成形 Build |
