# Cubicle Survivor — 大厂个人属性 × 部门 构筑框架 v0.3

**设计核心：不是"你选了什么部门"，而是"你是一个什么样的人，在什么部门"。**

---

## 一、双轴系统

```
        部门（5 个）
        ─────────────────────────────
        技术  产品  运营  市场  综合
       ┌────┬────┬────┬────┬────┐
  天赋  │    │    │    │    │    │
       ├────┼────┼────┼────┼────┤
  技能  │    │    │    │    │    │
       ├────┼────┼────┼────┼────┤
  努力  │    │    │    │    │    │
       ├────┼────┼────┼────┼────┤
  人脉  │    │    │    │    │    │
       ├────┼────┼────┼────┼────┤
  运气  │    │    │    │    │    │
       └────┴────┴────┴────┴────┘

每张卡 = 一个部门
玩家把它放进一个属性槽
= 部门 × 属性的交叉效果
```

## 二、5 个属性槽（谁在做）

| 属性 | 大厂含义 | 效果风格 | 风格描述 |
|------|---------|---------|---------|
| 🧠 **天赋** | 天生的聪明 | 稳定增幅 | 效果可靠，无代价，但上限固定 |
| 🔧 **技能** | 硬实力/经验 | 可叠加/成长 | 随卡牌数量/等级提升而变强 |
| 💪 **努力** | 加班/拼命 | 高回报高代价 | 效果翻倍，但带持续代价（扣血/减速） |
| 🤝 **人脉** | 关系/抱团 | 跨卡联动 | 效果受其他槽位卡牌影响，联动触发 |
| 🎲 **运气** | 锦鲤/风口 | 低概率高上限 | 触发概率低，但触发=质变 |

**关键：5 个属性槽，玩家起始有 3 个空槽，Lv.5/10 各解锁 1 个。不是一开始就能放满。**

## 三、5 个部门（做什么）

| 部门 | 大厂含义 | 战斗风格 | 经典武器 | 为什么 |
|------|---------|---------|---------|--------|
| 💻 **技术** | 写代码/做架构 | 链电、AOE、不稳定高爆发 | 咖啡、计算器 | 提神写码=持续输出；算法=链式思维 |
| 📱 **产品** | 需求/迭代 | 攻速、暴击、高风险 | 键盘、马克笔 | 打字=快速交付；画线=精准需求 |
| 🛡️ **运营** | 稳定/保底 | 防御、续航、阵地 | 耳机、保温杯 | 降噪=不被干扰；续杯=长期续航 |
| 📢 **市场** | 投放/影响力 | 范围、击退、群体控制 | 订书机、报表 | 传播=扇形覆盖；汇报=全局影响力 |
| 🏢 **综合** | 人力/财务/行政 | 资源、全局加成、拾取 | 便签、碎纸机 | 归档=留痕；销毁=终极决策 |

## 四、25 张卡 × 5 属性 = 125 种交叉

以技术部"敏捷开发"为例：

| 敏捷开发 放哪 | 效果 | 风格体现 |
|-------------|------|---------|
| 天赋 | 主武每击杀 10 敌触发链电（3 跳） | 天生反应快，自然触发 |
| 技能 | 链电跳跃次数 = 2 + 拥有技术卡数量 | 技术越深，链越长 |
| 努力 | 链电触发后 3 秒内攻速翻倍，但期间每秒扣 1% 当前 HP | 加班换输出 |
| 人脉 | 链电可跳转到其他武器的目标，优先人脉槽中的武器 | 跨武器"介绍" |
| 运气 | 链电 8% 概率触发，但触发时跳跃次数 ×3 + 伤害翻倍 | 撞大运爆发 |

以产品部"截止日期"为例：

| 截止日期 放哪 | 效果 | 风格体现 |
|-------------|------|---------|
| 天赋 | 对 <50%血敌人伤害 +40% | 天生敏锐，抓到关键 |
| 技能 | 对 <50%血敌人伤害 +15%×产品卡数量 | 经验越丰富，越会抓时机 |
| 努力 | 对 <50%血敌人伤害 +80%，但每击杀自己扣 1% HP | 拼命赶 deadline |
| 人脉 | <50%血敌人被击中标记为"共享"，其他武器攻击该目标伤害 +20% | 拉人一起赶 |
| 运气 | <20%血敌人被击中 5% 概率即死 | 锦鲤赶 deadline 居然中了 |

以运营部"备份恢复"为例：

| 备份恢复 放哪 | 效果 | 风格体现 |
|-------------|------|---------|
| 天赋 | 每 30 秒自动回复 15% HP | 天生恢复力 |
| 技能 | 受击后 CD -2 秒，可叠加 CD 减免层数 | 越受挫恢复越快 |
| 努力 | 受伤时立刻回复 10%，但之后 5 秒内受到伤害 +30% | 打补丁的代价 |
| 人脉 | 回复 HP 时也回复周围友方/召唤物 | 互相照应 |
| 运气 | 8% 概率双倍回复 | 撞大运多回一口 |

## 五、双轴协同（属性 × 属性）

**不只是部门间有协同，属性组合也有协同：**

| 属性组合 | 协同名 | 效果 |
|---------|--------|------|
| 天赋+技能 | **学以致用** | 天赋槽中的卡获得技能槽中卡数量的伤害加成 |
| 天赋+努力 | **天才加班** | 天赋效果减半，努力效果翻倍（转化） |
| 技能+人脉 | **师徒传承** | 技能槽的卡效果 + 人脉槽卡数量的 20% |
| 技能+运气 | **厚积薄发** | 技能槽的卡累积未触发次数，切换运气槽时一次性爆发 |
| 努力+人脉 | **兄弟同心** | 努力槽扣血由人脉槽也承担一部分（分担代价） |
| 努力+运气 | **孤注一掷** | 努力槽代价翻倍，运气槽触发率翻倍 |
| 天赋+运气 | **天选之子** | 天赋槽效果 + 运气槽触发率的百分比 |
| 人脉+运气 | **贵人相助** | 运气触发时，人脉槽卡牌效果临时翻倍 |
| 天赋+人脉 | **精英推荐** | 天赋触发时，随机激活一个人脉槽的联动效果 |
| 技能+努力 | **苦练成才** | 技能槽可叠加层数上限翻倍（努力解锁上限） |

## 六、部门协同（部门 × 部门）

保留跨部门协同，来自 Hades：

| 协同名 | 条件 | 效果 |
|--------|------|------|
| 敏捷创新 | 技术 + 产品各≥1 | 暴击触发链电，链电触发暴击 |
| 稳定交付 | 技术 + 运营各≥1 | 链电在防御状态下伤害翻倍 |
| 病毒传播 | 技术 + 市场各≥1 | 链电的每个目标溅射范围伤害 |
| 技术管理 | 技术 + 综合各≥1 | 链电跳转消耗的资源减半 |
| 快速上线 | 产品 + 运营各≥1 | 暴击时获得小额护盾 |
| 爆款策略 | 产品 + 市场各≥1 | 暴击击退 + 击退出的伤害区域 |
| 产品立项 | 产品 + 综合各≥1 | 杀敌后短暂全武器伤害 +20% |
| 标准运营 | 运营 + 市场各≥1 | 防御状态下范围伤害扩散到全屏 |
| 全域管理 | 运营 + 综合各≥1 | 治疗量受护甲加成 |

| 同部门武器数 | 加成 |

## 八、Dead Cells 式投资缩放

```
部门投资等级 = 该部门拥有的卡牌数量（不管放在哪个属性槽）

Lv.1：基准
Lv.2：该部门所有卡效果 +8%           ← 2 张同部门
Lv.3：该部门所有卡效果 +16%          ← 3 张
Lv.4：该部门所有卡效果 +28%          ← 4 张
Lv.5：该部门所有卡效果 +42%          ← 5 张（极少见）
```

**三轴叠加示例：**
你有 3 张技术卡（投资 Lv.3 = +16%） + 2 把技术武器（+10%天赋/技能槽） = 天赋/技能槽中的技术卡效果 +26%

## 九、本局流程

```
开局前
  ├─ 选 1 把起始武器
  ├─ 选 1 个「入职部门」（工牌，该部门卡必定出现）
  └─ 从剩下 4 个部门中随机 2 个加入本局卡池
      → 本局 3 个部门的卡池

第 1-2 关
  ├─ 玩家有 3 个属性槽（天赋/技能/努力/人脉/运气中随机 3 个？还是固定？）
  ├─ 每次升级：3 选 1 卡牌，放入任意属性槽
  └─ 目标：填满初始 3 槽 → 理解本局的部门组合

第 3 关结束 → 商店 🛒
  ├─ 5 张随机卡牌（来自本局 3 部门）
  ├─ 可刷新 2 次（工分）
  └─ 可出售槽位中的卡换工分

第 4-5 关：解锁第 4 个属性槽（Lv.5）
  ├─ 稀有卡开始出现
  ├─ 微调卡牌槽位配置
  └─ 第一个协同可能触发（部门协同或属性协同）

第 6 关结束 → 商店 🛒（更高质量）

第 7-8 关：解锁第 5 个属性槽（Lv.10）
  ├─ 传说卡可能解锁
  ├─ 投资缩放明显
  └─ 武器 Lv.7 进化

第 9-10 关：终考
  └─ 5 槽满 + 多协同 = Build 巅峰
```

**关于属性槽解锁顺序：**
选项 A：天赋/技能/努力 → 人脉 → 运气（固定顺序，渐进式复杂）
选项 B：随机 3 个开局 → Lv.5 自选 1 个 → Lv.10 自选最后 1 个（给玩家选择权）

**建议用 B。** 让"我怎么选属性槽"本身也是 Build 决策的一部分。

## 十、开局时的属性选择

```
开局前：
  选择入职部门（工牌）→ 确定 1 个部门的卡本局出现
  选择 3 个起始属性槽 → 从 5 个中选 3 个
    例：选 天赋 + 技能 + 人脉 = 不走"努力"和"运气"路线
       偏稳定流，靠天赋+技能打底，靠人脉扩上限
  
  选择哪些属性不选和选择部门一样重要：
  - 不要努力 = 没有爆发力，但没有代价
  - 不要运气 = 没有翻盘点，但稳定可控
  - 不要人脉 = 没有协同爆发，但每张卡独立变强
```

## 十一、和现有代码的关系

### 数据量
- 25 张卡 × 5 属性槽 = 125 种效果 × 约 2 行描述 = ~250 行配置
- 10 种属性协同 + 10 种部门协同 = 20 条规则
- 可管理

### 要删
- 路线系统（routes）
- 职业加成（weaponClassBonuses）
- 现有隐藏协同
- 通用词条升级系统

### 要改
- 升级面板 → 部门卡选择
- 武器数据结构 → 加部门标签
- 道具系统 → 降级为通用被动

### 要新建
- 属性槽系统（5 属性 + 解锁逻辑 + 拖拽换位）
- 25 张卡数据（部门 × 属性 × 稀有度）
- 部门投资缩放
- 双轴协同检测（属性×属性 + 部门×部门）
- 武器套装检测
- 商店系统（每 3 关）
- 开局属性选择 + 入职部门选择 UI

### 保留
- 武器基础数据 + 操作方式
- 敌人/关卡/材料/经验
- softCap 系统
- 战斗循环
