## 1.1 伤害公式（锁）

```
hitDamage(base) = base × getDamageMult() × (暴击 ? 1.85 : 1)
continuousDamage(base) = base × getDamageMult() × (1 + crit × 0.006)

getDamageMult():
  raw = player.damageMult + 部门投资加成 + 属性协同加成 + 武器套装加成
  return softCap(raw, 1.82, 2.18, 0.35)
```

**新映射：**
- `player.damageMult` ← 卡牌效果（如产品部"紧急上线"放技能槽 +0.15）
- 部门投资加成 ← Dead Cells 式缩放（3 张技术卡 = +0.16）
- 属性协同加成 ← 属性×属性协同（如"天才加班"：努力槽效果翻倍）
- 武器套装加成 ← Brotato 式（2 把同部门武器 = 该部门卡 +10%）

**锁死项：**
| 参数 | 值 | 原因 |
|------|---|------|
| SOFT_CAP | 1.82 | 已验证 1-14 关平滑 |
| HARD_CAP | 2.18 | 防止数值崩溃 |
| tail | 0.35 | softCap 后增长率 |
| 暴击倍率 | 1.85× | 固定，不叠 |
| 暴击上限 | 75% | 硬上限 |

## 1.2 攻速公式（锁）

```
cooldown(base) = max(0.18, base × 100 / (100 + max(-60, effectiveAS)))

effectiveAS = softCap(rawAS, 62, 92, 0.34)
rawAS = player.attackSpeed + 部门投资加成 + 武器套装加成

addPlayerAttackSpeed(amount):
  scaled = current ≥ 62 ? amount × 0.42 : amount
```

**锁死项：**
| 参数 | 值 |
|------|---|
| SOFT_CAP | 62 |
| HARD_CAP | 92 |
| tail (softCap) | 0.34 |
| tail (add) | 0.42 |
| cooldown floor | 0.18s |

## 1.6 敌人血量成长（重写，不改数值）

**当前公式：**
```
healthMult = 1 + stage×0.14 + (stage-1)²×0.028 + max(0,stage-6)×0.09 + max(0,stage-8)²×0.024 + (stage≥8 ? stage×0.025 : 0)
```
4 项叠加，难调。建议简化但不改数值曲线。

**简化方案（纯重构，不改数）：**
```
healthMult = 1 + stage×0.22 + (stage-1)²×0.018 + max(0,stage-7)×0.14

Stage 1:  1.22x  (原 1.14x, 轻微上调前两关)
Stage 5:  2.36x  (原 2.39x)
Stage 8:  4.52x  (原 4.43x)
Stage 10: 6.08x  (原 6.12x)
Stage 14: 9.48x  (原 9.52x)
```
与每个 stage 的最大误差 <3%。可丢弃原 6 项式。

## 1.9 新框架下新增的数值来源

当前所有公式中 `getDamageMult()` / `getRawAttackSpeed()` 等会新增以下来源：

| 新增来源 | 影响公式 | 影响幅度设计 |
|---------|---------|------------|
| 卡牌直接效果 | damageMult / attackSpeed / crit / range 等 | 单张卡 0.03~0.20 不等 |
| 部门投资缩放 | 同部门所有卡效果 × (1 + tier%) | tier 2~5: +8%~+42% |
| 武器套装加成 | 同部门武器 2~4 把 | +10%~+35%（仅限特定槽） |
| 属性协同 | 属性 × 属性 10 种协同 | 各自独立公式 |
| 部门协同 | 部门 × 部门 10 种协同 | 条件触发式（非恒常加成） |

**这些来源全部走现有 softCap。** 新代码注入到 `getDamageMult()` 等函数的 raw 计算阶段即可。
