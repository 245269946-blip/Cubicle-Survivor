# 第 3 步：Build 长短板 — 10 种典型 Build 的完整剖面

**日期：2026-06-22**
**前提：能力预算表已定。现在给每种典型 Build 写清：爽点、强项、弱点、克制谁、怕谁、成型时机、不能获得什么能力。**

---

## 3.0 Build 不是"选路线"，是"部门 × 属性 × 武器"的三轴组合

```
Build = 主要部门（1-2个）× 活跃属性槽（3-5个）× 武器（2-6把）
```

10 个典型 Build 覆盖主流组合。每个都带着"长板"和"短板"，不设全能 Build。

---

## 3.1 纯技栈 — "算法碾压"

```
部门：技术 🔥（主）+ 任意副部门
属性：天赋/技能（核心），回避努力（代价和链电节奏冲突）
武器：咖啡 + 计算器
```

### 爽点
- 链电从 2 跳到 8 跳，"一个敌人触发，半个屏幕遭殃"
- 技术投资 Lv.3 后每张技术卡都亮起来，"越投资越猛"
- 计算器 Lv.7 进化 → 量子计算：A→B→A 弹回，单体 BOSS 变成链电回旋加速器

### 强项
- 群体清屏：链电天然 AOE，敌人越多链越长
- 成长加速度：部门投资缩放 + 技能槽成长，中期开始碾压
- 连锁反应：一个暴击触发链电 → 链电清小兵 → 清完触发敏捷开发 → 再链电

### 弱点
- 单体 BOSS：链电伤害分散，打 BOSS 不如产品 Build
- 需要热身：Lv.1-2 关伤害低，链电只 2 跳
- 怕打断：移动中被包围 → 链电目标选择混乱
- **续航差：技术部门几乎没有治疗/防御卡**

### 可以同时获得
- 产品部副部门 → 敏捷创新（暴击触发链电）
- 运营部副部门 → 稳定交付（防御状态链电翻倍）

### ❌ 不能同时获得
- **努力槽的扣血效果**（和链电节奏冲突，扣血速率不可控）
- **运气槽的巨大方差**（链电需要稳定性，不是赌博）
- 站桩类光环（耳机/保温杯在纯技栈中只能当第 5-6 武器，没有部门加成）

### 成型时机
- 第 2 关：咖啡+计算器齐，链电起步
- 第 4 关：技术投资 Lv.2，链电 4 跳，开始清屏
- 第 7 关：技术投资 Lv.3，计算器 Lv.7，成形

## 3.2 产品冲刺 — "Deadline 即是战斗力"

```
部门：产品 ⚡（主）
属性：努力/技能（核心），回避天赋（太稳不够刺激）
武器：键盘 + 马克笔
```

### 爽点
- 努力槽"截止日期"→ 对半血以下伤害 +80%，"疯狂赶 Deadline"
- 键盘近战挥击 + 马克笔蓄力穿透 → 操作双线，"身法决定输出"
- 产品发布传说卡 → 暴击爆炸连锁，"一个暴击炸掉半个经理办公室"

### 强项
- 精英/Boss 斩杀：半血以下伤害放大器
- 爆发窗口：努力槽 + 产品发布 + KPI 考核 = 连杀狂潮
- 攻速滚雪球：攻速上去后键盘挥动 + 马克笔蓄力交替

### 弱点
- 续航极差：每击杀扣血 1%，长期战斗被拖死
- 怕远程群：没有防御手段，多个 Deadline 同时射击→走位空间被压缩
- **操作门槛最高：键盘方向 + 马克笔鼠标瞄准同时进行**
- 武器投资集中：键盘和马克笔都需要 Lv.7 才发挥

### ❌ 不能同时获得
- 天赋槽的稳定效果 → 选了努力槽就放弃了平推
- 运气槽的赌博（产品 Build 爆发已经有节奏，再加运气会无法预判）
- 运营养生流（保温杯/耳机和"冲刺"矛盾）
- 综合管理流（便签陷阱和键盘冲锋方向冲突）

### 成型时机
- 第 1-2 关：确定方向
- 第 3-4 关：稀有卡"截止日期"出现 → 斩杀线启动
- 第 6-7 关：键盘 Lv.7 进化 + 产品发布传说 → 完全体

## 3.3 运营堡垒 — "我不倒，你就赢不了"

```
部门：运营 🛡️（主）
属性：天赋/人脉（核心），回避运气
武器：耳机 + 保温杯
```

### 爽点
- 免责声明传说卡 → 致命伤害锁定 1HP + 3 秒无敌，"每次都是死里逃生"
- 耳机站立 3 秒触发全屏脉冲 → 清场，"闭嘴开会"
- 保温杯 Q 键蒸汽爆发 → "全公司最暖的 HR"
- 备份恢复在天赋槽 → 每 30 秒自动回 15%，几乎没有血量焦虑

### 强项
- 死不了：多层防御叠加（护甲 + 闪避 + 治疗 + 锁定 1HP）
- 站桩输出：耳机光环半径 ×1.5 + 报表轨道 +2，站立 3 秒 = 阵地完成
- 容错率最高：适合新手和"不想操作想放松"的玩家

### 弱点
- 输出低：防御向 Build，DPS 是产品 Build 的 40-50%
- 怕时间压力：无限模式下的时间压力 → 防御再强也打不完
- 怕无视护甲的敌人（当前游戏无，但为将来留设计空间）
- **移动就掉输出：站立站桩 = 不走位 = 容易被集火**

### ❌ 不能同时获得
- 努力槽 → 努力槽扣血和运营哲学冲突（"稳定"不能"拼"）
- 产品部的斩杀效果 → 运营不追求输出
- 键盘冲锋方向 → 耳机/保温杯不契合

### 成型时机
- 第 1-3 关：耳机+保温杯齐，天赋槽备份恢复开始回血
- 第 5 关：运营投资 Lv.2，流程审批 + 备份恢复同时生效
- 第 8 关：免责声明传说 + 耳机 Lv.7 = 死不了

## 3.4 市场辐射 — "我的工位，我的规则"

```
部门：市场 📢（主）
属性：人脉/技能（核心），回避努力
武器：订书机 + 报表
```

### 爽点
- 报表轨道包围全身，"我在哪，哪就是安全区"
- 订书机扇形覆盖 → 方向控制精确，"往那边开会的人全被订在墙上"
- 全面投放协同 → 拾取范围翻倍 + 自动吸附，"什么都不用捡，它们自己过来"
- 爆款策略协同 → 暴击击退 + 击退区留下伤害，"把人推出门"

### 强项
- 范围控制：订书机扇形 + 报表轨道 = 双环覆盖
- 击退安全感：敌人永远近不了身
- 拾取效率：全场道具自动吸附 → 升级速度最快
- 阵营建设：适合后期关卡（敌人多、需要空间）

### 弱点
- Boss 战：击退对 Boss 效果打折，失去主要控制手段
- DPS 中等：没有斩杀也没有链电，纯面伤
- 怕被包围后残血 → 没有强力恢复手段
- **高速敌人突破击退阈值 → 突破防线后措手不及**

### ❌ 不能同时获得
- 产品部的暴击爆炸 → 市场更需要稳定覆盖，不需要爆发
- 努力槽 → 击退已有足够安全边际，不需要代价换爆发
- 键盘近战 → 击退和近战冲突

### 成型时机
- 第 2 关：订书机 + 报表齐
- 第 4 关：人脉槽开始联动，拾取范围扩大
- 第 7 关：全面投放协同 + 报表 Lv.7 = 7 轨道全屏

## 3.5 综合管理 — "流程到位，自然通关"

```
部门：综合 🏢（主）+ 任意
属性：技能/运气（核心）
武器：便签 + 碎纸机
```

### 爽点
- 便签陷阱布置 + 碎纸机锥形绞碎 → "先挖坑，再推进去"
- 全自动办公传说 → 12 秒自动释放主武 Lv.3 攻击，"AI 取代了我的工作"
- 运气槽的赌注 → 8% 概率双倍效果 → "撞大运了！"
- 晨会（通用槽）→ 多 1 个升级选项，"多一个选择权就是多一份胜算"

### 强项
- 万能：什么关都能打（陷阱打群、碎纸机打单）
- 资源最优：SOP 标准减冷却、留痕存档加经验、自动巡检铺陷阱
- 反 Boss：碎纸机锥形专注一个方向 = 单体伤害仅次于产品 Build

### 弱点
- 无特长：没有极致的群伤（不如技术链电）也没有极致的生存（不如运营堡垒）
- 碎纸机锥形方向判断错误 → 浪费输出窗口
- 陷阱预判失败 → 白费布局时间
- **综合部门卡的本局出现机会分散到 5 个属性槽，难专精**

### ❌ 不能同时获得
- 产品部的暴击爆炸 → 风格不匹配
- 运气槽 + 努力槽同时 → 方差太大无法控制

### 成型时机
- 第 1-2 关：便签+碎纸机齐
- 第 4 关：晨会在通用槽 → 选择权增加
- 第 8 关：全自动办公传说 → 自动化

## 3.6 敏捷创新（技术+产品） — "写了就上线，上线就爆炸"

```
部门：技术 🔥 + 产品 ⚡
属性：技能/努力（核心）
武器：咖啡 + 键盘（或马克笔）
```

### 爽点
- 敏捷创新协同 → 暴击触发链电 + 链电触发暴击 = 双向正反馈
- 产品发布暴击爆炸 + 技术突破链电弹回 = "屏幕爆炸"
- 努力槽两人的效果同时翻倍 → 代价也翻倍 → "真·拼命"

### 强项
- 爆发天花板最高
- 双向协同 → 暴击率和链电跳跃双重增长
- 适合有自信的玩家（"我能控血"）

### 弱点
- 代价太重：努力槽双倍代价 → "暴毙风险最高"
- 没防御：技术和产品都没生存能力
- 前置要求高：需要 4 张卡（技术 2+ 产品 2）

### ❌ 不能同时获得
- 运营部的任何防御卡 → 浪费槽位和部门池
- 天赋槽 → 要的就是爆发，不要稳

## 3.7 稳定交付（技术+运营） — "边打边养"

```
部门：技术 🔥 + 运营 🛡️
属性：天赋/技能（核心）
武器：咖啡 + 耳机
```

### 爽点
- 稳定交付协同 → 站立时链电伤害翻倍，"我站着，你来打我"
- 耳机提供安全区 → 咖啡在安全区内从容输出
- 两个部门都有"成长中变强"的哲学 → 越打越硬

### 强项
- 攻守平衡最佳
- 站立 = 输出 + 防御同步触发
- 容错率高，适合中手

### 弱点
- 机动性差：靠站桩，遇高速突破型敌人要移动 → 失去加成
- DPS 上限低于敏捷创新
- 需要两个部门的卡各两张 → 成型窗口长

### ❌ 不能同时获得
- 努力槽 → 和"养"冲突
- 运气槽 → 不需要赌

---

## 3.8 快速上线（产品+运营） — "又莽又硬"

```
部门：产品 ⚡ + 运营 🛡️
属性：天赋/努力（核心）
武器：键盘 + 保温杯
```

### 爽点
- 快速上线协同 → 暴击时获得护盾（上限 3），"杀了人还加盾"
- 键盘冲锋吸血 + 保温杯爆发治疗 → "打不死的小强"
- 合规审查 × 截止日期 → 杀了低血目标 + 清负面 = 越杀越干净

### 强项
- 生存 + 输出双修
- 暴击护盾机制 → 越打越安全
- 保温杯蒸汽爆发 → 既可以当治疗也可以当输出

### 弱点
- 两部门各需要卡 → 槽位紧张
- 护盾上限 3 层 → 不能完全替代防御
- 键盘需要近身 → 和保温杯的站立蓄能有冲突

### ❌ 不能同时获得
- 运气槽 → 护盾需要可预测性

---

## 3.9 天选之子（天赋+运气） — "天生锦鲤"

```
属性：天赋 + 运气（槽位组合，不是部门组合）
武器：不限
```

### 爽点
- 天选之子协同 → 天赋槽效果 + 运气触发率加成
- 运气触发时天赋槽效果也翻倍 → "双倍锦鲤"
- 低概率高回报 → "这把我赌到了！"

### 强项
- 上限极高
- 天赋槽提供下限保障（不会完全崩）
- 适合"就赌这一把"的心态

### 弱点
- 下限灾难：赌不到就是白板
- 触发不可控 → 关键时候哑火
- **不适合排位/冲关**（不确定性强）

### ❌ 不能同时获得
- 努力槽 → 已经够了不确定，再加代价会崩
- 人脉槽 → 天赋+运气已是"孤独的天才"

## 3.10 兄弟同心（努力+人脉） — "一起拼命"

```
属性：努力 + 人脉（槽位组合）
武器：不限，但需要同部门的多个武器
```

### 爽点
- 兄弟同心协同 → 努力槽的扣血代价由人脉槽分担
- 人脉槽联动人数越多 → 努力槽效果越强且代价越低
- "全组一起加班，没人倒下"

### 强项
- 努力槽的高输出代价被分摊
- 人脉越多越安全
- 适合和多武器 Build 搭配

### 弱点
- 需要至少 3 个槽有卡才能触发分担
- 初期效果不强（人脉少时分担弱）
- **团队型 → 需要"养人脉"，无法独狼**

### ❌ 不能同时获得
- 天赋槽 → 团队不需要天才，需要能一起拼的
- 运气槽 → 靠运气的不靠谱
