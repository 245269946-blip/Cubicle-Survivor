**HUD 布局说明：**

| 位置 | 内容 | 说明 |
|------|------|------|
| 顶部中央 | 关卡名 + 计时 | 显示"第N关"和叙事标题 |
| 左上角 | 武器栏 | 当前拥有的武器 + 等级（图标+等级号），Lv.7 金色边框 |
| 左侧 | HP 条 | 垂直或水平，显示数字百分比 |
| 右上角 | 资源 | 材料(📦) / 工分(💎) / 经验(💰) |
| 底部横条 | 属性槽 | 当前激活的属性槽 + 槽中卡牌图标和名称 |
| 最右下 | 提示 | 快捷键提示：Tab 统计面板、Q/主动技能 |

**属性槽交互：**
- 已解锁的槽 → 显示卡牌图标 + 名称（如 🧠 敏捷开发）
- Hover → 显示该卡在当前槽位的详细效果
- 槽位可拖拽换位（交换两张卡的位置 → 触发"重新分配"效果）
- 未解锁槽 → 灰显 🔒 + 解锁等级提示

**武器栏细节：**
- 武器图标 + Lv 号（如 ☕Lv4）
- Lv.7 → 金色边框 + 进化图标
- 当前正在攻击的武器 → 微微发光

## 七、界面 6：升级面板

```
┌──────────────────────────────────────┐
│  第 4 关 · 升级！                    │
│                                      │
│  ┌──────────┐ ┌──────────┐         │
│  │ 🧠 敏捷  │ │ 🔧 持续  │         │
│  │ 开发     │ │ 集成     │         │
│  │ [技术]·普│ │ [技术]·稀│         │ ← 3 选 1（晨会可 +1）
│  │ 链电触发 │ │ CD 缩减  │         │
│  │ 25%→伤害│ │ 击杀 5 ↓ │         │
│  └──────────┘ └──────────┘         │
│  ┌──────────┐                      │
│  │ 📈 攻速  │                      │
│  │ 通用升级  │                      │ ← 非卡牌选项
│  │ +8% AS  │                      │
│  └──────────┘                      │
│                                      │
│  [ 点击选择 ]                        │
│                                      │
└──────────────────────────────────────┘
```

**选项组成：**

每次升级 3 个选项（晨会 +1），选项组成：
- 2 个来自本局部门池的随机卡牌（稀有度依关卡）
- 1 个通用属性（攻速/射程/护甲/移速/伤害——随机）
- 晨会在综合槽 → 多 1 张卡牌选项

**卡片显示：**
- 左上角 → 属性槽图标（玩家需要决定放进哪个槽）
- 右上角 → 部门标签 + 稀有度颜色（白/蓝/紫/金）
- 中间 → 卡名 + 在当前哪些可见槽位中的效果简报
- 如果全槽未解锁 → 显示"解锁后可放入"

**稀有度颜色：**
- 普通 → 白色边框
- 稀有 → 蓝色边框
- 传说 → 金色边框 + 光效
