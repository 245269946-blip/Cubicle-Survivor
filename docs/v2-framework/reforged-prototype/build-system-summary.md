# 工位幸存者 Build 体系机制汇总

**版本：v0.3 | 日期：2026-06-22 | 覆盖：全局**

---

## 一、双轴框架：属性 × 部门

```
Build = 属性配置 (你是谁) × 部门配置 (你在哪个圈子)

属性轴 (纵向)：决定"能力风格"
  ├─ 🧠 天赋：稳定基线，无代价
  ├─ 🔧 技能：可成长，越投入越强
  ├─ 💪 努力：高回报带负面代价
  ├─ 🤝 人脉：依赖联动，越多越强
  └─ 🎲 运气：低概率高上限

部门轴 (横向)：决定"能力池"
  ├─ 🔥 技术：链电/连锁 → 清屏
  ├─ ⚡ 产品：暴击/斩杀 → 爆发
  ├─ 🛡️ 运营：护甲/治疗 → 续航
  ├─ 📢 市场：范围/击退 → 空间控制
  └─ 🏢 综合：资源/冷却 → 效率

每一张卡同时拥有：1 个属性标签 (放哪个槽) + 1 个部门标签 (属于哪个圈子)
```

## 二、开局：随机起点 + 确定性锚点

### 2.1 入职测评（属性槽）

```
系统从 5 个属性槽中随机抽 3 个展示给玩家

玩家选项：
  ✅ 接受 → 以这 3 个属性为起点
  🔄 重投 → 消耗 1 工分，重新随机（限 1 次）

心理设计：
  不说"你缺什么"，说"你突出什么"
  灰色待发展领域不是"不足"，是"还没测完"

后续解锁：
  Lv.5 → 从剩余 2 个属性中自选 1 个（第 4 槽）
  Lv.10 → 剩余 1 个自动解锁（第 5 槽全部激活）
```

### 2.2 工牌选择（部门池）

```
玩家从 5 个部门中选 1 个作为"工牌部门"
系统从剩余 4 个中随机补 2 个 → 本局部门池 = 3 个部门

部门的含义：
  - 所选工牌部门的卡牌出现率偏高（+40% 加权）
  - 本局只会出现这 3 个部门的卡牌
  - 部门协同（跨部门）仅在这 3 个部门间触发

保护机制：
  最近 3 局未出现的部门 → 随机池权重 ×2
```

### 2.3 起始武器

```
4 选 1：
  ├─ 2 把工牌部门的归属武器（标注"推荐"）
  └─ 2 把随机部门池中的武器

武器部门归属：
  键盘⌨️→产品 | 马克笔🖊️→产品 | 订书机📎→产品·综合
  咖啡☕→技术 | 计算器🧮→技术 | 便签🟨→技术·综合
  耳机🎧→运营 | 保温杯🫖→运营 | 报表📊→市场 | 碎纸机🗑️→运营·市场

同一关卡中，后续武器由武器工坊发放（第4关起概率触发，第9关起必出）
```

## 三、卡牌系统：25 张卡 × 5 槽 = 125 种效果

### 3.1 卡牌结构

```
每张卡 = {
  名称, 部门标签, 稀有度 (普通/稀有/传说),
  effects: { 天赋: {...}, 技能: {...}, 努力: {...}, 人脉: {...}, 运气: {...} },
  exclusions: [{ 互斥规则 }],
  prerequisite: { 获取前置 }  // 仅稀有/传说
}
```

### 3.2 卡牌分布

| 部门 | 普通 ×2 | 稀有 ×2 | 传说 ×1 |
|------|---------|---------|----------|
| 🔥 技术 | 敏捷开发、版本迭代 | 代码重构、持续集成 | 技术突破 |
| ⚡ 产品 | 紧急上线、快速迭代 | 截止日期、KPI考核 | 产品发布 |
| 🛡️ 运营 | 流程审批、备份恢复 | 合规审查、免责声明 | 全栈运营 |
| 📢 市场 | 品牌影响、渠道推广 | 病毒营销、爆款策略 | 全域投放 |
| 🏢 综合 | 晨会、SOP标准 | 留痕存档、自动办公 | 组织架构调整 |

### 3.3 同卡异位：一张卡在不同属性槽的效果完全不同

以"截止日期"[产品·稀有] 为例：

| 槽位 | 效果 |
|------|------|
| 🧠 天赋 | 对 <50% HP 敌人伤害 +40%（稳定斩杀） |
| 🔧 技能 | 伤害 +20% + 产品卡数 ×7%（随成长变强） |
| 💪 努力 | 伤害 +80%，击杀扣 1% HP（高风险高回报） |
| 🤝 人脉 | 低血目标标记共享，所有武器伤害 +15%（团队输出） |
| 🎲 运气 | <20% HP 敌人 5% 即死，Boss ×3 伤害（赌徒爆发） |

### 3.4 稀有度与获取条件

```
普通卡（10张）：无前置，任何升级即可出现
稀有卡（10张）：同部门已有 ≥1 张卡时可能出现
传说卡（5张）： 同部门已有 ≥3 张卡时可能出现，本局仅 1 张

稀有度按关卡滚动：
  第 1-2 关：仅普通
  第 3-5 关：稀有 20%
  第 6-8 关：稀有 35%，传说 5%
  第 9-11 关：稀有 50%，传说 10%
  第 12-14 关：稀有 60%，传说 15%

一局期望：15-18 张卡，其中稀有 3-5 张，传说 1 张
```

### 3.5 互斥规则

| 规则 | 例子 | 原因 |
|------|------|------|
| 槽位互斥 | "敏捷开发"不可同时放入努力+运气 | 链电压差过大 + 代价不可控 |
| 跨卡互斥 | "免责声明" + "备份恢复"不可同在天赋槽 | 伤害延迟 + 自动回复 = 近乎无敌 |
| 传说互斥 | 本局最多 1 张传说 | 保证质变稀有性 |
| Build 自然互斥 | 开局没抽到努力槽 → 整局无法选努力卡 | 不是惩罚，是"你定义了你是谁" |

## 四、部门投资缩放

### 4.1 部门深度

```
同部门卡数量 → 部门效果倍率：
  2 张 → ×1.2
  3 张 → ×1.4
  4 张 → ×1.7
  5 张 → ×2.0
```

### 4.2 武器套装（Brotato 式）

```
同部门武器数量 → 套装加成：
  2 把技术武器 → 链电伤害 +15%
  3 把技术武器 → 链电跳转 +50%，伤害 +30%
  2 把产品武器 → 暴击伤害 +20%
  3 把产品武器 → 暴击率 +10%，暴击伤害 +40%
  2 把运营武器 → 护甲 +2，回复 +10%
  3 把运营武器 → 护甲 +5，回复 +25%
  2 把市场武器 → 范围 +15%，击退 +20%
  2 把综合武器 → 经验 +15%，冷却 -10%
```

两个属性槽各有 ≥1 张卡时自动激活。

| 协同 | 触发 | 效果 | 隐藏? |
|------|------|------|-------|
| 学以致用 | 天赋+技能 | 天赋槽效果 + 技能卡数×5%（上限+25%） | |
| 天才加班 | 天赋+努力 | 天赋减半 → 努力翻倍（Tab切换） | |
| 师徒传承 | 技能+人脉 | 技能槽效果 + 人脉卡数×7%（上限+35%） | |
| 厚积薄发 | 技能+运气 | 技能蓄力满100 → 运气下次必触发×3 | |
| 兄弟同心 | 努力+人脉 | 努力代价由人脉分担40% | |
| 孤注一掷 | 努力+运气 | 代价×1.5，触发概率×2 | |
| 天选之子 | 天赋+运气 | 天赋效果 ×(1+运气触发率×50%) | 🔒 |
| 贵人相助 | 人脉+运气 | 运气触发时随机人脉卡×2（5s） | |
| 精英推荐 | 天赋+人脉 | 天赋触发15%激活人脉联动 | 🔒 |

### 5.2 部门协同（10 种）→ 第 6 关起激活

两个部门各有 ≥1 张卡时自动激活。

| 协同 | 触发 | 效果 |
|------|------|------|
| 敏捷创新 | 技术+产品 | 暴击↔链电双向反馈（40%概率） |
| 稳定交付 | 技术+运营 | 站立时链电伤害 ×1.5 |
| 病毒传播 | 技术+市场 | 链电弹跳目标周围溅射（60px/30%） |
| 技术管理 | 技术+综合 | 链电 CD 减半，伤害 -20% |
| 快速上线 | 产品+运营 | 暴击获护盾（上限3层/15吸收） |
| 爆款策略 | 产品+市场 | 暴击击退+路径留口碑区域伤害 |

| 全域管理 | 运营+综合 | 治疗/回复 + 护甲 ×3% | 🔒 |
| 全面投放 | 市场+综合 | 拾取+100%，自动吸附 |

## 六、关卡 × 机制时间线

```
入职（开局前）
  ├─ 测评 → 抽 3 属性槽
  ├─ 工牌 → 选 1 部门 + 随机 2
  └─ 武器 → 4 选 1

试用期（第 1-5 关）
  ├─ 1-2 关：只有普通卡
  ├─ 3 关：商店 ①（4 张卡，稀有 30%）
  ├─ 4 关：稀有卡 20% 出现，武器工坊 50% 触发
  └─ 5 关结束：Lv.5 → 解锁第 4 属性槽（自选）

转正期（第 6-9 关）
  ├─ 6 关：部门协同可触发，商店 ②（5 张卡，稀有 40%）
  ├─ 7 关：传说卡 5% 可能掉落
  ├─ 8 关：属性协同可触发
  └─ 9 关：商店 ③（5 张卡，稀有 50%），工坊 100%

老员工（第 10-13 关）
  ├─ 10 关结束：Lv.10 → 解锁第 5 属性槽
  ├─ 11 关：混合题型
  ├─ 12 关：敌人增速 +20%
  └─ 13 关：期末考试

终局（第 14 关）
  └─ Boss 多阶段 → 通关！
```

## 七、负面设计清单

### 7.1 主动负面（选了就要承受，但正面更猛）

| 来源 | 代价 | 收益 |
|------|------|------|
| 努力槽·敏捷开发 | 每秒扣 1% HP | 攻速 +60% |
| 努力槽·截止日期 | 击杀扣 1% HP | 低血伤害 +80% |
| 努力槽·合规审查 | 3s 护甲归零 | 伤害 +30% |
| 努力槽·免责声明 | 队列清空扣 5% | 1.5s 快速审批 |
| 努力槽·病毒营销 | 扩散标记到期扣血 | 扩散速度 ×2 |
| 关卡间·替同事顶班 | 怪物 +25% | 材料 +35% |
| 关卡间·系统更新 | 15s 不能攻击 | 材料 +6 + 护甲 +3 |

### 7.2 隐性限制（A 和 B 不能同时拥有）

- "免责声明" + "备份恢复" 不能同时在天赋槽 → 近乎无敌
- "截止日期" 不能同时放在努力+运气槽 → 即死+扣血混沌
- "全域投放" + "品牌影响" 不可同时拥有 → 全屏+击退=无交互
- 本局最多 1 张传说
- 开局没抽到某属性 → 整局无法选该属性槽卡牌

## 八、功率预算

### 8.1 属性槽功率系数

```
🧠 天赋：×1.00  (基准，无代价)
🔧 技能：×0.80  (起步) → ×1.00 (同槽5张卡时满)
💪 努力：×1.40  (代价换高功率)
🤝 人脉：×0.70  (起步) → ×1.30 (同槽5张卡时满)
🎲 运气：×0.40  (起步) → ×3.00 (同槽5张卡时，仅影响触发率/上限)
```

### 8.2 总功率上限

```
所有来源最终走现有 softCap 系统：
  DAMAGE_MULT_SOFT_CAP  = 1.82
  DAMAGE_MULT_HARD_CAP  = 2.18
  ATTACK_SPEED_SOFT_CAP = 62

部门投资缩放 × 武器套装 × 属性槽系数 × 卡牌效果
→ 所有路径最终被 softCap 钳制
→ 不会出现数值崩溃
```

  ├─ 关卡、死因、本局时长

## 十、一局玩家体验完整轨迹

```
1. 主菜单 → 点"开始工作日"
2. 入职测评 → 看到 🧠💪🎲 三个属性突出，🔥 确认
3. 工牌选择 → 选 🏢 综合部，系统补 📢市场 + 🔥技术
4. 武器选择 → 4 把中选 ☕咖啡
5. 第 1 关 → 只有普通卡出现（技术/市场/综合三部门）
6. Lv.2 升级 → 3 选 1：敏捷开发(技术)/品牌影响(市场)/攻速+8%
7. 放入天赋槽 → 天赋·敏捷开发：击中 25% 链电
8. Lv.3 升级 → 稀有卡出现！持续集成(技术·稀有) → 放入技能槽
9. 第 3 关结束 → 商店！买到渠道推广(市场·普通) → 放入人脉槽
10. Lv.5 → 解锁第 4 槽！选"努力"→ 可以选高风险高回报卡了
11. 第 6 关起 → 激活"敏捷创新"协同（技术+产品？不对，本局没产品部）
    → 但技术+综合触发"技术管理"：链电 CD 减半！
12. 第 8 关起 → 天赋+技能触发"学以致用"：天赋效果 +5~25%
13. Lv.10 → 最后一槽运气自动解锁
14. 第 14 关 → Boss 多阶段 → 通关！
15. 复盘 → 伤害分布 + Build 评分 + 优化建议
```
