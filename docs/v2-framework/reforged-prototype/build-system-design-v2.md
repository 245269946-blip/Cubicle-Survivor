# 工位幸存者 v0.3 重构设计文档（修订版）

**日期：2026-06-22 | 基于社区批判意见深度修订**

---

## 修订说明

本版相对于初版的核心变更：

| 初版 | 修订版 | 原因 |
|------|--------|------|
| 125 个独立卡牌效果 | 25 张卡 × 3+1 模板，约 100 个变体 | 降低调参成本，消除 dead pick |
| 属性×部门双轴平权 | 部门主轴 + 属性副轴 | 玩家一眼知道"我是什么流派" |
| 部门投资 ×1.2~2.0 线性放大 | 阶段里程碑 + 协作任务 | 消除"无脑同色堆叠"最优解 |
| 23 种协同 | 8 种协同，隐藏后置 | 降低认知负担 |
| 14 关离散 | 5 阶段 20 分钟 | 单局时长控制在复玩阈值内 |
| 开局 3 层选择 | 新手版 1 步 / 进阶版 3 步 | 降低首次体验门槛 |

## 一、主轴：部门 = Build 派系

### 1.1 部门定义

```
部门决定"我这局玩什么流派"——这是玩家最先理解、最直观的标识。

部门    玩家理解            战斗表现          代表武器
────────────────────────────────────────────────────────
🔥技术  高频/自动化/链式    弹幕→连锁→清屏    ☕咖啡 ⌨️键盘
⚡产品  爆发/斩杀/窗口      暴击→爆发→秒杀    🖊️马克笔 📎订书机
🛡️运营  生存/续航/阵地      护盾→回复→持久    🎧耳机 🫖保温杯
📢市场  扩散/传播/范围      AoE→感染→控制    📊报表 🗑️碎纸机
🏢综合  资源/效率/泛用      经济→冷却→灵活    🟨便签 (共享)

玩家看到部门名，听见一句话概括，看见一把武器——三秒内理解流派方向。
```

### 1.2 部门 ≠ 固定角色定位

一个关键区分：

> 不是"技术部=法师，运营部=坦克"，而是"技术部=链电机制，运营部=续航机制"。
> 同一部门可以打出完全不同的风格，取决于你选的武器 + 属性倾向。

```
例如技术部：
  选☕咖啡 + 专注属性 → 精准狙击型（弹幕瞄准链电）
  选⌨️键盘 + 执行力属性 → 近战狂战士型（挥砍触发链电）
  选🟨便签 + 摸鱼属性 → 陷阱布阵型（地雷触发链电）

重点：部门决定"你有什么机制"，属性决定"你怎么用这个机制"。
```

## 二、副轴：属性 = 风格修饰

### 2.1 属性定义

```
属性 6 个（MVP），不承担完整流派，而是提供风格偏向。

属性      方向          一句话              适用部门
──────────────────────────────────────────────────
执行力    直接伤害      硬怼，不绕弯子      技术/产品
专注      暴击/单体     精准打击            产品/技术
抗压      生存/续航     扛得住              运营/综合
摸鱼      闪避/资源     省力但高效          综合/运营
表达力    范围/扩散     铺开来打            市场/技术
社交      召唤/协同     大家一起上          综合/市场
```

### 2.2 属性的核心约束

```
- 开局自动分配（新手版）或随机 2+1 自选（进阶版）
  不是"给你 6 个任选"，而是"给你 2 个确定的 + 1 个可选的"

- 属性不独立产生效果，它修饰卡牌和武器
  执行力不是 +10% 攻击力，而是"放在执行力槽的卡牌，其伤害效果被放大"
```

## 三、开局：分层设计

### 3.1 新手版（默认，前 3 局）

```
一步选择 → 立刻进战斗

  选择身份（工牌）：
  ┌─────────────────────────────────────┐
  │ 🔥 技术实习生                        │
  │    自动属性：专注 + 执行力            │
  │    推荐武器：☕ 挂耳咖啡               │
  │    一句话：弹幕扫射，链电清屏         │
  │                                      │
  │ ⚡ 产品打工人                        │
  │    自动属性：执行力 + 表达力           │
  │    推荐武器：🖊️ 马克笔                │
  │    一句话：蓄力贯穿，暴击秒杀         │
  │                                      │
  │ 🛡️ 运营老兵                          │
  │    自动属性：抗压 + 社交              │
  │    推荐武器：🎧 降噪耳机              │
  │    一句话：阵地防守，稳扎稳打         │
  │                                      │
  │ 📢 市场新人                          │
  │    自动属性：表达力 + 社交            │
  │    推荐武器：📊 季度报表              │
  │    一句话：轨道环绕，范围感染        │
  └─────────────────────────────────────┘
```

### 3.2 进阶版（通关 3 次后解锁）

```
三步选择：

  第一步：入职测评
  ├─ 随机抽 2 个属性（不可改）
  └─ 从剩余 4 个中自选 1 个（你的决定）
  
  第二步：工牌部门
  ├─ 5 个部门任选 1 个（你的决定）
  └─ 系统随机补 2 个 → 本局部门池 = 3 个
  
  第三步：起始武器
  ├─ 2 把工牌部门武器 + 2 把随机
  └─ 4 选 1（你的决定）

开局后玩家能说一句话：
  "这局我是 🛡️运营部 的 抗压+社交 型，起手 🎧降噪耳机。"
```

### 3.3 不确定性锚点

```
新手版：玩家只做 1 个选择 → 身份感 + 快速开打
进阶版：玩家做 3 个选择 → 自主构筑 + 可控变量

锚点逻辑：
  - 工牌部门 → 玩家选的，确定的
  - 2 个固件属性 → 系统给的，不可控（但只有 2 个）
  - 1 个自选属性 → 玩家选的
  - 武器 → 玩家选的
  → 4 个变量中，3 个玩家可控 + 1 个系统给 → 既有决策感，又有适应感
```

## 四、卡牌系统：3+1 模板

### 4.1 核心理念

```
同一张卡有 5 个可放置槽位，但不是 5 个独立效果。

一张卡 = 一个固定主题 + 一个部门标签 + 一个稀有度
槽位 = 决定这张卡在"这一局"里发挥什么功能角色

槽位不是"身份"，是"使用方式的开关"
```

### 4.2 五槽模板系统

```
所有 25 张卡统一遵循此模板：

位置 1 — 输出槽
  所有卡放这里都转化为伤害/攻击效果
  → 保证玩家选任何卡都有"提高杀敌能力"的兜底选项

位置 2 — 生存槽
  所有卡放这里都转化为防御/回复效果
  → 保证玩家感觉输出够了时可以转向生存

位置 3 — 资源槽
  所有卡放这里都转化为经验/冷却/材料经济效果
  → 保证"资源流"玩法永远存在

位置 4 — 机制槽（部门专属）
  技术卡 → 改变触发频率/连锁方式
  产品卡 → 暴击/窗口爆发条件
  运营卡 → 叠层/持续回复机制
  市场卡 → 范围/传播/感染机制
  综合卡 → 泛用机制强化
  → 每个部门的独特风味在这里体现

位置 5 — 代价槽
  效果为输出槽的 1.5~2×，但附带代价
  → 高风险高回报，不是必选，是"玩法倾向"
```

### 4.3 一张卡的完整示例

```
"敏捷开发" [技术部] [普通]

┌────────┬──────────────────────────────────────────┐
│ 输出槽 │ 击中 25% 触发链电，跳 2 次，伤害 12       │
│ 生存槽 │ 链电每次跳转回血 2 HP                     │
│ 资源槽 │ 链电击杀额外 +3 经验                      │
│ 机制槽 │ 链电跳转次数 = 2 + 技术卡总数              │
│ 代价槽 │ 链电伤害 ×3，跳转 ×2，每秒扣 1% 当前 HP   │
└────────┴──────────────────────────────────────────┘

玩家看到的是：同一张卡在不同位置做不同的事。
不是 5 个完全不同的技能，而是同一个主题的 5 种变化。
```

### 4.4 稀有度梯度（3 级）

```
普通（10 张）：无前置，任何升级均可能出现
  功率基准：1×
  
稀有（10 张）：同部门已有 ≥1 张卡时出现
  功率基准：1.4×
  获取时机：第 3 关起（20%概率，逐步提升到 60%）
  
传说（5 张）：同部门已有 ≥3 张卡时出现，本局仅 1 张
  功率基准：2×（但作用范围受限，不做全局倍率）
  获取时机：第 7 关起（5%→15%）
  特殊规则：
    - 传说不做纯数值放大（避免"拿到传说=赢了"）
    - 传说改机制/改规则（如"链电改为同时击中5个最近敌人"）
    - 一局最多 1 张传说
```

## 五、部门投资：阶段里程碑 + 协作任务

### 5.1 阶段里程碑（替代 ×1.2~2.0 倍率）

```
同部门卡 2 张：部门基础协同激活
  例：技术 2 张 → 链电伤害 +10%

同部门卡 3 张：部门机制强化
  例：技术 3 张 → 链电可跳转回已击中目标

同部门卡 4 张：部门终局套装
  例：技术 4 张 → 链电触发率翻倍

满部门（5 张+）：不会再有额外奖励
  → 释放信号：你可以去追其他部门了
```

### 5.2 协作任务（引导混合部门）

```
第 3 关：跨部门协作提案（随机触发，60%概率）

  例："技术部想和市场部联合发布一个功能"
  → 若玩家 [≥1 技术卡 + ≥1 市场卡] → 获得 1 张免费卡（随机部门）
  → 若玩家不满足 → 无损失，任务不显示，不影响后续

第 6 关：跨部门资源置换（40%概率）

  例："运营部向综合部借调一个人"
  → 若玩家 [≥1 运营卡 + ≥1 综合卡] → 商店本次半价
  → 不满足 → 无影响

第 9 关：跨部门应急响应（30%概率）

  例："产品部的 P0 故障需要技术部救火"
  → 若玩家 [≥1 产品卡 + ≥1 技术卡] → 全武器 CD 刷新 + 15s 增益（伤害 +25%）
  → 不满足 → 无影响

设计要点：
  - 协作任务只在玩家当前"不满足条件"时给提示
    满足自动触发，不满足看不到 → 零负担
  - 奖励是有吸引力的但不强制 → 玩家不会觉得"我必须混合"
  - 全部堆同部门 → 永远触发不了协作任务
    → 这不是惩罚，是"你错过了这条线的额外奖励"
```

### 5.3 武器套装（保留，简化）

```
同部门武器 ≥2 时触发套装（不是每多一把都叠，只触发一次）：

  技术 2 武：链电伤害 +15%
  产品 2 武：暴击伤害 +20%
  运营 2 武：护甲 +2，回复 +10%
  市场 2 武：范围 +15%

取消 3 武套装 → 减少同色堆叠激励
```

## 六、协同系统：8 种（MVP）

### 6.1 部门协同（4 种）

```
触发条件：拥有两个部门的卡牌各 ≥1 张 + 第 6 关起

1. 敏捷创新（技术+产品）
   暴击 30% 触发链电 / 链电 30% 附加暴击

2. 爆款策略（产品+市场）
   暴击击退 40px，路径留 3s 伤害区域（暴击伤害 ×30%）

3. 标准运营（运营+市场）
   站立时范围伤害覆盖全屏 ×0.6

4. 全面投放（市场+综合）
   拾取范围 ×2，材料自动吸附

原则：
  - 部门协同只做机制联动，不做数值叠加
  - 保证每个部门至少参与 1 个协同
  - 效果能让玩家明显感知"有什么不一样了"
```

### 6.2 属性协同（4 种）

```
触发条件：两个属性槽各有 ≥1 张卡 + 第 8 关起

1. 学以致用（执行力+专注）
   执行力槽效果 + 专注槽卡数×5%（上限 +20%）

2. 兄弟同心（抗压+社交）
   抗压槽负面效果由社交槽分担 30%

3. 厚积薄发（摸鱼+专注）
   摸鱼槽蓄力满 100 → 专注槽下次暴击 ×2

4. 孤注一掷（表达力+执行力）
   表达力代价 ×1.3 → 执行力正面效果 ×1.5

原则：
  - 属性协同做"用面板可视的联动"
  - 不做 10 种是为了让每一种都有空间做深
```

### 6.3 协同面板（HUD 常驻）

```
右上角小面板，始终可见但不占视觉焦点：

  ┌─── 协同 ─────────────┐
  │ 🔥技术 2/3 ▸ 技术套装 │  ← 已激活
  │ ⚡产品 1/3 ▸ 产品套装 │  ← 未激活
  │ ? ▸ 技术×产品  1/2   │  ← 差 1 张产品卡
  │                        │
  │ 🧠执行力+专注 ○ 已激活  │
  │ 🛡️抗压+社交   ○ 未激活 │  ← 灰显
  └────────────────────────┘
```

## 七、武器进化与 Build 联动

### 7.1 核心改变

```
旧：武器 Lv.7 自动进化 A/B 二选一（与 Build 无关）
新：武器 Lv.7 时检查当前装备的卡牌，自动匹配进化方向

每把武器有 3-4 条进化路线，由你的 Build 自动决定走哪条。
```

### 7.2 示例：咖啡 ☕ Lv.7 进化

```
条件：你的卡牌/部门构成 → 进化方向

条件 A：拥有 ≥2 张技术部卡
  → 进化「意式浓缩」：弹幕数 +50%，弹速 ×1.5
     叙事："你终于配了台正经咖啡机"

条件 B：拥有 ≥2 张运营部卡
  → 进化「保温壶」：弹幕变轨道环绕，击中回血 3
     叙事："续杯自由——运营的终极特权"

条件 C：拥有 ≥1 技术卡 + ≥1 产品卡
  → 进化「Deadline 特饮」：弹幕击中标记 Debuff，标记叠加触发暴击
     叙事："通宵三天的结晶"

默认（上述均不满足）：
  → 进化「速溶咖啡」：弹幕数 +20%，弹速 +15%
     叙事："凑合喝吧"
```

### 7.3 设计原则

```
- 每个部门至少能触发 2 把武器的进化
- 进化不止改数值，改机制/视觉效果/音效
- 跨部门进化 > 同部门进化 > 默认进化（鼓励混合）
- 默认进化保底，不让你卡住
```

## 八、关卡：5 阶段 20 分钟

### 8.1 阶段结构

```
入职期（3 分钟，连续波次）
  叙事："第一天上班，工位上全是 Bug。"
  机制：基础怪，第 1 次升级（3 选 1 普通卡）
  考核：会走位就不会死

试用期（5 分钟，连续波次）
  叙事："第三周了，Leader 开始给你派独立任务。"
  机制：敌人数和血量提升，第 3 关末触发商店
  考核：有基础输出方向

转正期（5 分钟，连续波次）
  叙事："转正答辩就在下周。你做 PPT 了吗？"
  机制：精英怪出现，部门协同激活（第 6 关）
  考核：主 Build 成型，能处理混合压力

老员工（4 分钟，连续波次）
  叙事："年底了。年会被安排在周四晚上加班后。"
  机制：敌人增速 +20%，属性协同激活（第 8 关），协作任务
  考核：Build 完整度，能否应对加速敌人

终局（3 分钟，独立 Boss 战）
  叙事："CEO 推门走进会议室。他看着你的 PPT，问了一个问题……"
  机制：Boss 多阶段战斗
  考核：Build 最终验证
```

### 8.2 节奏控制

```
约 20 分钟一局：
  ├─ 0-3min：战斗（入职期）
  ├─ 3min：升级/商店（试用期起点）
  ├─ 3-8min：战斗（试用期）
  ├─ 8min：升级/商店（转正期起点）
  ├─ 8-13min：战斗（转正期）
  ├─ 13min：升级/事件（老员工起点）
  ├─ 13-17min：战斗（老员工）
  ├─ 17min：最后一次升级/商店
  └─ 17-20min：Boss 战（终局）

关键：每个阶段结束时一定有明确的升级/选择节点，
但不每关都停（保留战斗流畅感）。
```

## 九、选卡预览：DPS 近似估算

### 9.1 选卡界面增强

```
升级面板上每张卡显示：

  ┌──────────────────────────────────┐
  │ "敏捷开发" [技术] [普通]         │
  │                                  │
  │ 位置预览：                       │
  │ ├─ 输出槽：链电 25% 跳2 伤12    │
  │ ├─ 生存槽：链电跳转回血2         │
  │ ├─ 资源槽：链电击杀+3经验        │
  │ ├─ 机制槽：跳转+技术卡数         │
  │ └─ 代价槽：×3伤×2跳 扣血1%/s   │
  │                                  │
  │ 放入输出槽预估：                 │
  │   你的 ☕咖啡 链电 DPS 贡献 ≈ 15  │
  │   总 DPS 变化：12→14 (+17%)      │
  │                                  │
  │ ⚠ 互斥提醒：                     │
  │   代价槽不可与"代码重构"共存      │
  └──────────────────────────────────┘

不是精确计算，是近似估算。误差 ±20% 可接受。
目的：让玩家选卡时有"这张卡对我到底有没有用"的直觉。
```

### 9.2 预览要避免的

```
❌ 不要：只显示抽象数值 → "伤害 +8%，攻速 +3%"
❌ 不要：过于精确 → "DPS 14.273→16.154，提升 13.18%"
❌ 不要：所有卡看起来一样 → "每张都加伤害"

✅ 要：告诉玩家"你的具体哪把武器会因此有什么变化"
✅ 要：大概 + 方向 → "+17%，主要来自链电触发"
✅ 要：差异化 → 输出槽加伤害、生存槽加续航、资源槽加速成长
```

## 十、负面与约束体系

### 10.1 三层约束

```
第 1 层：主动负面（玩家选的，有正面对应）
  ├─ 代价槽：所有卡放代价槽都有 1.5-2× 功率 + 明确代价
  ├─ 关卡事件：替同事顶班（敌人+25%，材料+35%）、系统更新等
  └─ 规则：代价 = 功率加成，代价是显性文字，不是隐性数值衰减

第 2 层：隐性限制（不显示但感觉不到）
  ├─ 互斥规则：某些卡 + 某些槽不能共存（生成时直接排除）
  ├─ 传说限 1 张
  └─ 规则：互斥只在选卡时提示，不做成"隐藏规则"

第 3 层：softCap 钳制（完全不暴露给玩家）
  ├─ DAMAGE_MULT_SOFT_CAP = 1.82（超过后每点效率 -50%）
  ├─ DAMAGE_MULT_HARD_CAP = 2.18
  ├─ ATTACK_SPEED_SOFT_CAP = 62
  └─ 规则：只在复盘时可能提及，平时完全不可见
```

### 10.2 互斥规则（简化版）

```
第一版只做 3 类显性互斥：

1. 传说限 1
2. 同槽互斥：一张卡不能放两个不同的槽（废话，但需要写出来）
3. 跨卡代价槽互斥：
   - "免责声明"(运营) 的代价槽 + "备份恢复"(运营) 不能同时激活
     → 延迟伤害 + 自动回复 = 无限容错
   - "全域投放"(市场) 的代价槽 + "品牌影响"(市场) 的代价槽不能同时激活
     → 全屏击退 = 零交互

其他所有互斥 → v0.4 按数据决定要不要加。
```

## 十一、终局复盘

### 11.1 三层递进

```
第一层：事实（自动生成，无评判）
  ├─ 武器伤害占比（柱状图）
  ├─ 各卡牌贡献排序
  ├─ 部门投资分布
  ├─ 触发协同列表
  ├─ 死亡原因 / 通关时长
  └─ Boss 战输出

第二层：身份识别（一句话总结）
  "你是 🛡️运营部 的 抗压·社交 型，核心输出来自 🎧耳机 + 报表。"

第三层：可选方向（建议 ≠ 正确答案）
  ├─ "你的输出集中在耳机轨道，近身怪靠报表处理。建议下次尝试
  │   运营+技术混合 → 给近身报表加链电清屏能力。"
  ├─ "你堆了 4 张运营卡，部门投资已满。第 5 张运营卡几乎没有增量。
  │   下次可以投资综合部获得冷却和资源加成。"
  └─ "你的抗压槽效果很强，但后期 Boss 无视护甲。建议在转正期
      补一张输出槽卡应对终局。"

表述方式：
  - 用"你做了 X"，不用"你应该做 Y"
  - 用"下次可以尝试"，不用"正确答案是"
  - 每个建议附带"为什么"→ 帮助玩家理解系统
```

### 11.2 评分系统

```
不搞 A/B/C 等级，用一句话称号：

根据部门投资深度 + 协同触发数：
  纯色 5 张同部门 → "技术专家"
  2 部门混合 → "跨界精英"  
  3 部门混合 → "全能选手"
  传说卡触发 → "突破极限"

根据关卡进度：
  死在第 1-2 阶段 → "新人磨合期"
  死在第 3 阶段 → "转正边缘"
  死在第 4 阶段 → "资深老员工"
  通关 → "年度最佳员工"
  无伤通关 → "传奇员工"（隐藏）

称号 + 身份识别的组合：
  "你是 跨界精英 运营部，死在了 转正边缘。"
  → 一句话传达所有信息，同时暗示"你差一点就转正了" → 激起重开动机
```

## 十四、Build 长短板图谱

> **本章目的**：为每个部门绘制完整的"克敌制胜图谱"。
> 玩家知道自己在玩什么，设计者知道每个 Build 应该在哪爽、在哪难受。
> **原则**：每个 Build 必须有明显的强项和弱项。完美的 Build = 无聊的 Build。

### 14.1 🔥 技术部 — 链电工程师

**战斗身份**：弹幕扫射 → 链电触发 → 连锁清屏
**进攻方式**：高频攻击触发链电，通过敌人集群间的跳转造成指数级清屏
**防守方式**：依赖走位和杀敌速度——消灭敌人就是最好的防御

#### 爽点
- 链电第一次跳到第 3+ 个敌人时，满屏电光
- 攻速堆起来后弹幕密度像暴雨——"我这台咖啡机是不是接水管了"
- 配合键盘近战时，贴脸挥砍触发链电的打击感
- 后期一个链电清半个屏幕的满足感

#### 强项
| 场景 | 表现 |
|------|------|
| 密集敌人集群 | ⭐⭐⭐⭐⭐ 链电跳转越跳越猛 |
| 多波次连续出怪 | ⭐⭐⭐⭐ 高频攻击持续触发 |
| 快速清场计时关卡 | ⭐⭐⭐⭐ 清屏速度最快 |
| 配合减速/控制道具 | ⭐⭐⭐⭐ 敌人聚得越紧，链电越强 |

#### 弱点
| 场景 | 表现 |
|------|------|
| 单个 Boss/精英 | ⭐⭐ 链电跳不起来，只剩基础弹幕 |
| 分散站位的敌人 | ⭐⭐ 链电够不到，弹幕追不上 |
| 需要精准点杀 | ⭐⭐ 无法控制链电跳转目标 |
| 自身体力续航 | ⭐ 没有任何自带回复，纯靠走位 |

#### 克制关系

**技术部克制**：
- 🐛 Bug 集群（密集出怪，链电最佳环境）
- 📅 Deadline 冲刺波（大量敌人同时涌来）
- 👥 召唤型精英（本体+召唤物 = 更多跳转节点）

**技术部被克制**：
- 👔 Boss 单挑（链电无跳转目标）
- 🏃 高速冲锋怪（弹幕追不上，链电触发率下降）
- 🛡️ 链电抗性敌人（设计预留，v0.4+）

#### 天生无法获得

```
技术部固件限制：
  ❌ 暴击爆发伤害 —— 高频低伤，没有"一发入魂"
  ❌ 自我回复 —— 链电击杀 ≠ 回血（除非装了生存槽卡）
  ❌ 防御阵地 —— 没有"站定不动就安全"的机制
  ❌ 精准单点 —— 链电自动跳转，无法指定目标
  ❌ 控制效果 —— 链电不能减速/定身/击退敌人
```

#### 推荐混搭
- **+⚡产品** → 链电暴击双向联动（`dept_tech_product` 协同），最强清屏+斩杀
- **+🏢综合** → CD 缩减 + 经验加速，让链电更频繁触发
- **+📢市场** → 链电 + 范围扩散 = 全屏电（但协同需到 v0.4）

#### 玩家画像
> "不想瞄准，不想站桩，就想看着屏幕自己清干净。"
> 适合喜欢高速战斗、追求视觉爽感的玩家。

---

### 14.2 ⚡ 产品部 — 暴击产品经理

**战斗身份**：精准蓄力 → 暴击触发 → 爆发斩杀
**进攻方式**：控制攻击窗口/蓄力节奏，在最佳时机打出致命伤害
**防守方式**：击杀恢复 + 斩杀回血——杀得快就是活得久

#### 爽点
- 暴击跳大字的瞬间，数字三位数起步
- 斩杀阈值触发时精英直接蒸发——"你的 KPI 不达标"
- 马克笔蓄力贯穿一排敌人，全部暴击的连爆声
- Boss 血量从 30% 到 0% 的一秒

#### 强项
| 场景 | 表现 |
|------|------|
| Boss 战 / 精英 | ⭐⭐⭐⭐⭐ 暴击+斩杀双重爆发 |
| 高血量单体 | ⭐⭐⭐⭐⭐ 马克笔贯穿+暴击=秒杀 |
| 窗口爆发检查点 | ⭐⭐⭐⭐⭐ Kill Streak 机制天生匹配 |
| 混合压力（少精英+多小怪） | ⭐⭐⭐ 可以点掉精英再清理 |

#### 弱点
| 场景 | 表现 |
|------|------|
| 海量小怪涌来 | ⭐⭐ AoE 能力弱，逐个点杀来不及 |
| 高速移动敌人 | ⭐⭐ 蓄力/瞄准需要窗口，太快的打不中 |
| 防御/续航 | ⭐⭐ 玻璃大炮，被围就跪 |
| 持续输出 | ⭐⭐ 爆发后有空窗期 |

#### 克制关系

**产品部克制**：
- 👔 Boss / 💼 精英（高血量单体 = 暴击的最佳靶子）
- 🐢 慢速高血怪（给你充分蓄力时间）
- 🔄 阶段性爆发检查（KPI 考核 / Kill Streak 机制匹配）

**产品部被克制**：
- 🐛 密集小怪潮（AoE 不足，被数量压垮）
- 🏃 高速闪避怪（蓄力期移动 = 射偏）
- 🛡️ 高频护甲刷新（暴击被吸收，节奏被打乱）

#### 天生无法获得

```
产品部固件限制：
  ❌ 全屏清场能力 —— 精准打击，不是地图炮
  ❌ 被动自动输出 —— 需要操作蓄力和瞄准
  ❌ 防御叠加 —— 护甲/回复手段极度有限
  ❌ 持续 dps —— 节奏是"蓄力→爆发→装填"，不是"一直射"
  ❌ 链电/连锁伤害 —— 暴击是单点，不会感染传播
```

#### 推荐混搭
- **+🔥技术** → 链电暴击联动，补上产品最缺的 AoE 清屏
- **+🏢综合** → 冷却缩减让爆发窗口更多
- **+📢市场** → 暴击击退+路径伤害（`dept_product_marketing`），补群控

#### 玩家画像
> "我想看到那个数字跳出来。我想一枪秒了 Boss。"
> 适合喜欢操作感、享受高风险高回报的玩家。

### 14.3 🛡️ 运营部 — 阵地老兵

**战斗身份**：护盾积累 → 持续回复 → 站桩不死
**进攻方式**：依赖轨道武器和光环持续输出，靠"站住了就赢了"
**防守方式**：全游戏最强——护甲/回复/延迟伤害/无敌帧

#### 爽点
- 满血站在怪堆里，血条纹丝不动
- 延迟伤害机制——"受伤了？三秒后再说"
- 合规审查的"清除所有负面+4s 免伤"——"我审过了，没问题"
- 低血量触发无敌+回血 30%——"还有加班补贴"

#### 强项
| 场景 | 表现 |
|------|------|
| 长时间消耗战 | ⭐⭐⭐⭐⭐ 回血比掉血快 |
| 站桩防守关卡 | ⭐⭐⭐⭐⭐ 天生阵地 |
| 高伤害低频攻击的敌人 | ⭐⭐⭐⭐ 延迟伤害 + 回复容错 |
| 多精英持续施压 | ⭐⭐⭐⭐ 护甲共享光环保护全队 |

#### 弱点
| 场景 | 表现 |
|------|------|
| 输出检查（限时击杀） | ⭐⭐ 火力最低的部门 |
| Boss 狂暴/无限成长 | ⭐⭐ 回复追不上无限伤害 |
| 被强制位移/击退 | ⭐⭐ 阵地一破就难受 |
| 需要快速走位的机制 | ⭐⭐ 腿短，不适合跑酷 |

#### 克制关系

**运营部克制**：
- 🗡️ 高伤低频怪（一次大伤害 → 延迟/回复吃掉）
- ⏱️ 持久战关卡（越拖运营越强）
- 🎯 弹幕型 Boss（多段低伤 = 运营最喜欢的伤害类型）

**运营部被克制**：
- ⚡ 狂暴型 Boss（伤害无限增长，回复最终跟不上）
- 🚫 治疗削减/禁疗敌人（设计预留）
- 💨 强制走位机制（阵地需要时间铺设）
- 💣 真伤/穿甲敌人（护甲无效化）

#### 天生无法获得

```
运营部固件限制：
  ❌ 高爆发伤害 —— 全游戏最低火力部门
  ❌ 链电/连锁 —— 不传播，不跳转
  ❌ 快速清屏 —— 光环 dps 有上限
  ❌ 暴击体系 —— 运营不讲"惊喜"，只讲"稳定"
  ❌ 攻击速度加成 —— 运营的节奏是慢的
  ❌ 精准单点 —— 大部分伤害是光环/轨道/范围
```

#### 推荐混搭
- **+🔥技术** → 补伤害（链电 + 续航 = 站得住还打得动）
- **+📢市场** → 站桩全屏伤害（`dept_ops_marketing` 协同）
- **+🏢综合** → 资源流 + 防御 = 越打越富

#### 玩家画像
> "我不想死。让我站住，我就赢了。"
> 适合稳健型玩家，享受"你打不动我"的从容。

### 14.4 📢 市场部 — 范围传播者

**战斗身份**：轨道环绕 → 范围扩散 → 全屏感染
**进攻方式**：用轨道武器和锥形 AoE 铺开伤害面，通过病毒扩散和击退控制场面
**防守方式**：击退 + 范围控制——敌人进不来就是最好的防御

#### 爽点
- 报表轨道转起来后，敌人走到哪都掉血
- 病毒营销扩散标记——"感染全办公室"
- 爆款策略 15 杀触发双倍伤害——"刷屏时刻"
- 全域投放的全屏伤害——"这封全员邮件抄送了所有人"

#### 强项
| 场景 | 表现 |
|------|------|
| 密集敌人集群 | ⭐⭐⭐⭐⭐ AoE 之王 |
| 被包围 | ⭐⭐⭐⭐⭐ 轨道 + 扩散 = 全方位 |
| 移动中持续输出 | ⭐⭐⭐⭐ 轨道跟你走 |
| 控制/推离 | ⭐⭐⭐⭐ 击退机制完整 |

#### 弱点
| 场景 | 表现 |
|------|------|
| Boss / 精英 | ⭐⭐ AoE 摊薄，单体 dps 不足 |
| 站桩定点输出 | ⭐⭐ 轨道需要敌人进入范围 |
| 分散站位的敌人 | ⭐⭐ 轨道覆盖有限 |
| 自身硬度 | ⭐⭐ 所有回复靠击退/扩散击杀回血 |

#### 克制关系

**市场部克制**：
- 🐛 海量小怪（轨道 AoE 的最佳画布）
- 🔄 包围型出怪（轨道 360° 全覆盖）
- 🏃 冲锋怪（击退硬直打断冲锋）

**市场部被克制**：
- 👔 Boss（单体伤害不足）
- 🛡️ 高护甲精英（AoE 低伤被护甲克制）
- 🎯 远程狙击怪（轨道打不到远处敌人）
- 💨 高速穿过轨道区（待得短 = 伤害少）

#### 天生无法获得

```
市场部固件限制：
  ❌ 单体爆发 —— AoE 摊薄，没有"一拳超人"
  ❌ 精准点杀 —— 不能指定"先打谁"
  ❌ 暴击体系 —— 扩散不讲暴击，讲感染
  ❌ 链电/连锁 —— 不是跳转，是"感染蔓延"（不同机制）
  ❌ 高护甲/防御 —— 击退是防御手段，不是硬扛
  ❌ 资源效率 —— 市场不讲经济，讲"铺量"
```

#### 推荐混搭
- **+⚡产品** → 暴击击退+路径伤害（`dept_product_marketing`），补上单体能力
- **+🛡️运营** → 站桩全屏（`dept_ops_marketing`），最强阵地 AoE
- **+🏢综合** → 自动吸附拾取（`dept_marketing_general`），经济起飞

#### 玩家画像
> "我不想瞄准任何东西。让我走一圈，屏幕清干净。"
> 适合喜欢轻松操作、享受"铺场覆盖"的玩家。

### 14.5 🏢 综合部 — 资源操盘手

**战斗身份**：经济加速 → 冷却堆叠 → 灵活适配
**进攻方式**：靠更快的升级和更短 CD 换取量和质的双重优势
**防守方式**：比其他部门升级更快 = 更早拿到关键卡 = 变相防御

#### 爽点
- 比别人多一个升级选项——"我有晨会"
- CD 缩减叠到 -50%，技能像不要钱一样甩
- 经验加成的滚雪球——"我 10 级时你们才 7 级"
- 组织架构调整免费重分槽位——"部门重组，全部重来"

#### 强项
| 场景 | 表现 |
|------|------|
| 经验/成长速度 | ⭐⭐⭐⭐⭐ 升级最快 |
| CD 缩减/技能频率 | ⭐⭐⭐⭐⭐ 技能不断 |
| 道具/材料获取 | ⭐⭐⭐⭐ 拾取范围+掉落加成 |
| 灵活性/适配性 | ⭐⭐⭐⭐⭐ 可以和任何部门混搭 |

#### 弱点
| 场景 | 表现 |
|------|------|
| 独立输出 | ⭐ 没有自成一派的伤害机制 |
| 独立防御 | ⭐ 没有护甲/回复天赋 |
| 前期战斗力 | ⭐⭐ 经济优势需要时间兑现 |
| 单一敌人场景 | ⭐⭐ 泛用 = 不专精 |

#### 克制关系

**综合部克制**：
- ⏱️ 长时间关卡（经济成长曲线最终超越所有部门）
- 🎭 混合敌人编排（泛用性带来适应性）
- 🛒 商店依赖型打法（更多材料 = 更多购买）

**综合部被克制**：
- ⚡ 前期高压（还没成长就被压死）
- 📉 资源限制关卡（经验/掉落被减半）
- 💀 一击必杀机制（升级再快也扛不住一刀）

#### 天生无法获得

```
综合部固件限制：
  ❌ 独立伤害机制 —— 没有"综合部专属伤害类型"
  ❌ 独立防御体系 —— 没有护甲/回复天赋
  ❌ 链电/暴击/扩散/AoE —— 不产出任何专属攻击机制
  ❌ 爆发窗口 —— 综合部不讲"关键时刻"，讲"一直在线"
  ❌ 阵地/控制 —— 不站桩、不击退、不铺场

综合部的能力全部靠"从其他部门借"——用经济换武器。
```

#### 推荐混搭
- **+🔥技术** → 高频 CD + 链电 = 无限链电
- **+⚡产品** → CD 缩减让爆发窗口更频繁
- **+🛡️运营** → 经济加速补运营的慢节奏
- **+📢市场** → 自动吸附 + 拾取范围放大（`dept_marketing_general`）

#### 玩家画像
> "我不玩某个流派。我玩的是'比别人强'。"
> 适合喜欢经济运营、享受"滚雪球"感觉的玩家。

### 14.7 Build 的反模式（新手陷阱）

> **以下 Build 方向会使游戏体验显著下降，设计者有意不阻止（让玩家自己发现），但应在此标注。**

#### 反模式 1：纯运营无输出
```
症状：5 张运营卡全放生存/资源槽，无任何伤害投资
结果：能扛到老员工期，但 Boss 战必死（输出不足→狂暴→死亡）
为什么允许：让玩家体验"光扛不出"的教训
如何避免：运营至少带 1 把非运营武器，或混搭 2 张技术卡
```

#### 反模式 2：全代价槽
```
症状：每张卡都放代价槽，追求 1.5-2× 功率
结果：互斥规则阻止了大部分，但即便通过了也会被多重代价压垮
为什么允许：代价槽设计已有互斥保护，剩下的让玩家自己体会
```

#### 反模式 3：四散投资
```
症状：5 个部门各 1 张卡
结果：没有任何里程碑（需要 ≥2 张），所有投资倍率 = 1.0，协同都不触发
为什么允许：协作任务会给提示（"差 1 张技术卡"），间接引导收敛
```

#### 反模式 4：纯传说追逐
```
症状：不停刷新选卡池，只等传说卡出现
结果：传说一局只出 1 张（5%→15%概率），浪费太多刷新机会
为什么允许：传说卡设计为"锦上添花"而非"唯一核心"，错过不影响通关
```
