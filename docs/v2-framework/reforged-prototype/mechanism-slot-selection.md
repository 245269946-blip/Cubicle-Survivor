# 开局机制：入职测评 + 工牌选择

**日期：2026-06-22**
**目录：reforged/ — 独立新区，不碰旧代码**

---

## 设计原则

> **不是"给你所有选项任选"——而是"给你一个起点，你从这个起点出发做决策"。**
> **随机性创造"适应"的乐趣，但留一个确定性锚点。**

---

## 一、属性槽：入职测评

### 1.1 流程

```
开局前 → 入职测评
  ├─ 系统随机抽取 3 个属性槽（从 5 个中选 3 个）
  ├─ 展示给玩家：「你的入职测评结果——」
  │   - 🧠 天赋突出
  │   - 🤝 人脉突出
  │   - 🎲 运气突出
  │   （努力/技能未被抽中 → 显示为灰色「待发展」）
  │
  ├─ 玩家选择：
  │   ✅ 接受 → 进入下一个选择（工牌）
  │   🔄 重新测评 → 消耗 1 工分，重新随机（限1次）
  ├─ Lv.5 → 解锁第 4 个属性槽（从剩余 2 个中自选）
  └─ Lv.10 → 解锁第 5 个属性槽（最后一个）
```

### 1.2 为什么是随机 + 有限选择

| 设计 | 玩家体验 | 避免的问题 |
|------|---------|-----------|
| 开局随机 3/5 | "我的性格就是这样，我要从这开始" | 避免每次都选天赋+技能+人脉（最优解固化） |
| 可重投 1 次 | "工分花得值，再给我一次机会" | 避免"完全看脸"的无力感 |
| Lv.5 自选 1 个 | "经过试用期，我选择发展方向" | 把解锁变成叙事事件，不是纯粹养成 |
| Lv.10 全部解锁 | "转正了，全面展现" | 提供终局补全的满足感 |

### 1.3 玩家心理分析

```
情况一：抽到天赋+技能+人脉
  → "我这局很稳，可以试试激进部门（产品）" 
  → 决策：部门选择

情况二：抽到努力+运气+人脉
  → "我这局是高风险赌狗——要不要重投？"
  → 决策：接受挑战 or 消耗工分

情况三：抽到天赋+技能+努力
  → "有基础有爆发，缺人脉和运气"
  → Lv.5 我是补人脉（联动）还是运

气（上限）？
  → 决策延迟到 Lv.5
```

**关键：属性槽的随机性不是"糟糕的设计"，而是"逼你做决策的材料"。**

### 1.4 工分的角色

```
工分用途：
  1. 重新测评（1工分/次，限1次）
  2. 商店刷新（2工分/次）
  3. 永久升级（5个维度，如最大HP/闪避/攻速/护甲/移速）

单局工分获取：
  每通关 1 关 +1
  通关 14 关 +3（额外）
  无尽模式每 3 波 +1

→ 工分是稀缺资源，重投测评 = 减少商店刷新次数
→ 选择本身就是权衡
```

## 二、部门：工牌选择 + 部门池抽取

### 2.1 流程

```
属性槽确定后 → 部门选择
  ├─ 玩家选择 1 个「入职部门」（工牌）
  │   技术 / 产品 / 运营 / 市场 / 综合
  │   该部门的卡本局必定出现
  │
  ├─ 系统从剩余 4 个部门中随机抽取 2 个
  │   → 本局卡池 = 3 个部门
  │
  └─ 出发！
```

### 2.2 为什么 3/5 部门出现

| 考虑 | 解释 |
|------|------|
| 5 个全出 | 卡池太大（25 张），稀释严重，Build 不专 |
| 1 个 | 没有跨部门协同，没有双重祝福的乐趣 |
| 2 个 | 只有 1 种跨部门协同，太少 |
| **3 个** | 3 种跨部门协同（A+B, A+C, B+C），刚好 |
| 4 个 | 6 种跨部门协同，太多，槽位不够放 |

**3/5 是和 Hades 5/8 神出场类似的黄金比例。**

### 2.3 部门池抽取的加权

为避免某些组合永远遇不到，部门池抽取用**伪随机池**：

```
最近 3 局未出现的部门 → 权重 ×2（保证玩家总能遇到不同部门）
上一局工牌部门 → 下一局不会被随机抽到（避免连续两局相同组合）
```

### 2.4 对 Build 多样性的影响

| 工牌 | 随机 2 个 | 可能的 Build 方向 |
|------|----------|------------------|
| 技术 | 产品+运营 | 敏捷创新 / 稳定交付 / 快速上线 |
| 技术 | 市场+综合 | 病毒传播 / 技术管理 / 标准运营 |
| 技术 | 产品+市场 | 敏捷创新 / 病毒传播 / 爆款策略 |
| 产品 | 技术+运营 | 敏捷创新 / 快速上线 / 稳定交付 |
| ... | ... | ... |

**10 种工牌 × C(4,2)=6 种随机组合 = 60 种部门组合。**
每局的 Build 方向从"固定 4 条路线"变成 60 种可能性。

## 三、起点武器：工位工位配置

### 3.1 流程

```
部门确定后 → 武器选择
  ├─ 系统根据玩家的「工牌部门」推荐 2 把该部门武器
  │   例：工牌=技术 → 咖啡 + 计算器
  │
  ├─ 系统从本局卡池的另外 2 个部门各随机 1 把武器
  │   → 共 4 把候选
  │
  ├─ 玩家选 1 把作为起始武器
  └─ 其余武器在后续关卡中获取（武器工坊/关卡奖励/商店）
```

### 3.2 为什么要这样

- **保证起点可控**：工牌部门至少给 2 把武器候选 → 玩家不会被迫玩不喜欢的风格
- **保留随机空间**：另外 2 把随机武器 → 可能引导玩家尝试跨部门 Build
- **不暴露所有武器**：不是一开始就 6 把全拿，武器获取是关卡间的重要决策节点

## 四、关卡 × 机制解锁时序

### 4.1 完整时间线

```
开局前
  ├─ 入职测评 → 随机 3 属性槽（可重投 1 次）
  ├─ 选工牌 → 确定 1 个部门 + 随机 2 个
  └─ 选起始武器 → 4 选 1

第 1 关：「漏洞潮」
  ├─ 只掉落普通卡（common）
  ├─ 升级选项 3 选 1
  └─ 玩家放置卡到属性槽

第 2 关：「需求变更」
  ├─ 继续掉落普通卡
  ├─ 首次出现关卡间事件（40% 触发率）
  └─ 本关结束：玩家已有 2-3 张卡

第 3 关：「会议轰炸」
  ├─ 首次出现稀有卡（rare）概率
  ├─ meeting 死后留减速（新增机制）
  └─ 本关结束：第一个商店 🛒
      └─ 5 张随机卡牌（来自本局 3 部门）
      └─ 可出售槽位中的卡换工分
      └─ 可刷新 2 次（2工分/次）

第 4-5 关：「Deadline 冲刺」「复盘压力」
  ├─ 稀有卡出现率上升
  ├─ Lv.5 → 解锁第 4 属性槽（自选 1 个剩余属性）
  └─ 武器工坊出现（概率 50%）

第 6 关：「季度审判」
  ├─ 本关结束：第二个商店 🛒（更高质量）
  ├─ 稀有卡出现率继续上升
  └─ 部门协同开始触发（需要两部门各≥1 张）

第 7-8 关：「紧急上线」「跨组拉齐」
  ├─ 传说卡可能掉落（但需同部门≥3 张前置）
  ├─ Lv.7 武器进化可选（二选一）
  └─ 属性协同开始触发

第 9 关：「财年封版」
  ├─ 本关结束：第三个商店（最高质量）
  └─ 材料掉落减半（政策）

第 10 关：「审计追问」
  ├─ Lv.10 → 解锁第 5 属性槽（最后一个）
  ├─ 传说卡掉率上升
  └─ 所有协同全部激活

第 11-13 关：考验综合能力
  ├─ 第 11 关：「组织调整」— 混合题型
  ├─ 第 12 关：「灰度事故」— 高速浪潮
  └─ 第 13 关：「年度述职」— 期末考试

第 14 关：「终局评审」
  └─ Boss 决战（多阶段）
```

### 4.2 商店刷新规则

| 第几次商店 | 触发关卡 | 卡牌质量分布 | 刷新费用 | 可操作 |
|-----------|---------|------------|---------|--------|
| 首次 🛒 | 第 3 关结束 | 普通 60%, 稀有 30%, 传说 10% | 1工分 | 买/卖/刷新 |
| 二次 🛒 | 第 6 关结束 | 普通 40%, 稀有 40%, 传说 20% | 2工分 | 买/卖/刷新 |
| 三次 🛒 | 第 9 关结束 | 普通 20%, 稀有 50%, 传说 30% | 3工分 | 买/卖/刷新 |

**传说卡前置条件不变**：即使商店有传说卡，也必须满足"同部门≥3 张"才能购买。

## 五、武器工坊（关卡间）

### 5.1 出现时机

```
第 4-5 关：50% 概率出现
第 6-8 关：75% 概率出现
第 9-14 关：100% 概率出现
```

### 5.2 工坊内容

```
每次工坊出现时：
  ├─ 随机 3 把未拥有的武器（优先本局 3 个部门的武器）
  ├─ 每把武器有价格（工分）：
  │   普通武器：3 工分
  │   同级部门武器：2 工分（工牌部门）
  │   高质量武器（已有升级基础）：4 工分
  └─ 或选择跳过 → +1 工分（"不买东西，攒着"）
```

## 七、后续：卡牌获取的随机保护

```
同部门卡牌保护：
  若最近 3 次升级选项均未出现工牌部门的卡 →
    下次升级必定出现 1 张工牌部门的卡

稀有度保护：
  若 Lv.8 时仍未获得任何稀有卡 →
    下次升级必定出现 1 张稀有卡

以上是隐性保护，不告诉玩家。防止"天谴局"。
```
