## 核心变更（v1 → v2）

1. **卡牌**：125 独立效果 → 25 张卡 × 3+1 模板（~100 变体，消除 dead pick）
2. **主轴**：属性×部门平权 → 部门主轴 + 属性副轴
3. **部门投资**：×1.2~2.0 线性 → 阶段里程碑（2/3/4 张）
4. **协同**：23 种 → 8 种（4 部门 + 4 属性）
5. **关卡**：14 离散关 → 5 阶段 20 分钟
6. **开局**：3 步固定 → 新手版 1 步 / 进阶版 3 步
7. **武器进化**：独立 A/B 选 → Build 卡牌决定方向
8. **协作任务**：新增跨部门引导混合
9. **选卡预览**：加 DPS 估算 + 互斥提示
10. **属性系统**：5 属性重命名为 6 属性（执行力/专注/抗压/摸鱼/表达力/社交）
