## 一、玩家一天（叙事框架）

### 1.1 你是谁

> **你不是"英雄"。你是大厂的一个普通打工人。**

早上 9:00 刷卡进楼，晚上不知道几点走。
你的武器不是剑和魔法——是手边的办公用品。
你的敌人不是怪物——是永远改不完的需求、永远开不完的会、永远做不完的述职。

**每局游戏 = 一个工作日。**
**从入职到通关 14 关 = 从试用期到年终述职。**

### 1.2 叙事弧线

```
入职（开局前）
  ├─ 性格测评 → "HR 让你做了一套性格测试"
  ├─ 选工牌 → "拿着工牌，走进你的工位"
  └─ 选起始武器 → "桌上放着今天要用的工具"

试用期（第 1-3 关）
  ├─ 漏洞潮 → "第一天：代码里全是 Bug"
  ├─ 需求变更 → "第三天：产品经理改了需求"
  └─ 会议轰炸 → "第五天：被拉进五个会"

转正前夕（第 4-5 关）
  ├─ Deadline 冲刺 → "下周转正答辩"
  ├─ 复盘压力 → "领导要看月度复盘"
  └─ 第 5 关结束：Lv.5 → "试用期通过！选一个发展方向"

季度考核（第 6-9 关）
  ├─ 季度审判 → "Q2 绩效考核"
  ├─ 紧急上线 → "周五晚上出事故"
  ├─ 跨组拉齐 → "和隔壁部门对齐目标"
  └─ 财年封版 → "年底封版预算吃紧"

年终冲刺（第 10-13 关）
  ├─ 审计追问 → "财务审计，所有东西翻出来看"
  ├─ 组织调整 → "HR 宣布部门重组"
  ├─ 灰度事故 → "流量灰度出了一次大事故"
  ├─ 年度述职 → "明天就是年终述职"
  └─ 第 10 关结束：Lv.10 → "你转正了！全面展现"

终局（第 14 关）
  └─ 终局评审 → "CEO 亲自来评审你的年度成果"
```

## 三、卡牌获取的时序曲线

### 3.1 什么时候能获得什么稀有度

```
第 1-2 关：  只有普通卡（common）
第 3-5 关：  稀有卡 20% 概率出现
第 6-8 关：  稀有卡 35% 概率出现，传说卡 5% 概率出现（需前置）
第 9-11 关： 稀有卡 50%，传说卡 10%
第 12-14 关：稀有卡 60%，传说卡 15%

升级选项总数（约每局）：
  14 关 × 约 1.5 次升级/关 ≈ 21 次升级选择
  期望获得卡牌数：15-18 张（有些升级是通用属性或武器升级）
  期望稀有卡数：3-5 张
  期望传说卡数：1 张（如果满足前置）
```

### 3.2 卡牌选择的动态

```
Lv.1-3（试用期）：
  只有 3 个属性槽，选项少 → 填满初始槽
  目标：3 个槽各 1 张卡，理解本局部门

Lv.4-7（转正）：
  Lv.5 新开 1 槽 → 需要快速填新槽
  稀有卡出现 → 开始构建跨部门协同
  商店 ① ② → 定向补卡

Lv.8-14（老员工）：
  Lv.10 全槽开满 → 填满最后 1 个槽
  传说卡 → 终局质变
  商店 ③ → 精调 Build
```

## 四、负面设计清单（不能获得 ≠ 惩罚）

### 4.1 主动负面（玩家可选择的代价）

这些是"选了就带负面，但收益更高"的设计：

| 来源 | 负面 | 正面 | 谁适合选 |
|------|------|------|---------|
| 努力槽·敏捷开发·扣血 | 每秒扣 1% HP | 攻速 +60% | 有回复手段的 Build |
| 努力槽·截止日期·扣血 | 击杀扣 1% HP | 半血伤害 +80% | 短对局爆发 |
| 努力槽·合规审查·归零 | 3s 护甲归零 | 伤害 +30% | 站桩堡垒（护甲高时快速回） |
| 努力槽·免责声明·扣血 | 队列清空扣 5% | 1.5s 快速审批 | 有充足回复时 |
| 努力槽·病毒营销·扣血 | 扩散扣血 | 扩散 ×2 | 小范围 Build（扩散少） |
| 关卡间·替同事顶班 | 怪物 +25% | 材料 +35% | 自信的玩家 |
| 关卡间·系统更新 | 15s 不能攻击 | 材料 +6 + 护甲 +3 | 堡垒 Build（不靠自动攻击）|

### 4.2 隐性负面（不接受某些能力）

这些是"选了 A 就不能选 B"——不是惩罚，是 Build 定义：

| 限制 | 谁被限制 | 为什么限制 |
|------|---------|-----------|
| 不能选天赋槽"免责声明"+ 天赋槽"备份恢复" | 运营堡垒 | 两者在一起 ≈ 无敌 |
| 不能选努力槽"截止日期"+ 运气槽"截止日期" | 任何 Build | 即死 + 扣血混沌 |
| 不能选天赋槽"全域投放"+ 天赋槽"品牌影响" | 市场辐射 | 全屏 + 击退 = 无交互 |
| 不能选 2 张传说 | 任何 Build | 本局只 1 张 |
| 选努力槽放弃天赋槽 | 纯技栈 / 运营堡垒 | 稳定流不需要代价 |
| 选运气槽放弃技能槽 | 天选之子 | 不靠成长靠运气 |
| 开局没抽到努力 → 整局无法选努力 | 任何人 | 属性槽随机 → 主动放弃某一整套风格 |

### 4.3 "不能获得"的设计价值

```
不是"设计师不让选" → 是"你定义了你是谁"
  例：你选了天赋+技能+人脉 = "一个稳扎稳打、靠关系成长的人"
       你一辈子不会加班（努力槽不存在）→ 你也一辈子不会猝死

这才是"Build"的本质——不是你能堆多少正面，
                    而是你主动放弃了什么可能性。
```

## 五、协同触发时序

### 5.1 什么时候能触发什么协同

```
第 1-5 关：无协同
  理由：卡牌太少，触发不了

第 6 关起：部门协同可触发
  条件：两个部门各有 ≥1 张卡
  例：技术+产品各 1 张 → 敏捷创新（暴击→链电）
  出现概率：第 6 关起 100%（只要满足条件）

第 8 关起：属性协同可触发
  条件：两个属性槽各有 ≥1 张卡
  例：天赋+技能 → 学以致用
  出现概率：第 8 关起 100%（只要满足条件）

第 10 关起：所有协同全部激活
  理由：Lv.10 = 转正 = 全面展现
```

### 5.2 为什么要延迟激活

- **前 5 关是"学习期"**：玩家在认识自己本局的部门组合和属性槽
- **第 6 关起才是"应用期"**：开始利用协同做更深的决策
- **Hades 也这样**：双重祝福在第 3-4 个地图才可能遇到，不会一开始就给你
