# 武器 Lv.7 进化二选一

**日期：2026-06-22**
**目录：reforged/**
**前提：武器基础数据全部保留（Lv.1→7 增幅、操作方式、基础 DPS）**

---

## 设计原则

> **Lv.7 进化是"质变"——不是"攻击力 +10%"，是"这个武器现在做完全不同的事"。
> 二选一让你选择武器在这个 Build 中的角色。**

现有每个武器的 Lv.7 进化有 1 个选项。现在为每个武器追加第 2 个选项，变成 A/B 二选一。

## 进化选择的设计考量

**每种进化都改变武器的角色——不是单纯的"更强"，是"不同方向"。**

| 武器 | A → 角色 | B → 角色 | 选择引导 |
|------|---------|---------|---------|
| 咖啡 | 持续性压制 | 单体高伤 | 群怪多选 A，Boss 多选 B |
| 马克笔 | 精准狙击 | 方向清理 | 鼠标熟练选 A，想稳选 B |
| 键盘 | 全方位近战 | 近战+远程 | 冲阵型选 A，安全型选 B |
| 订书机 | 强推进 | 全覆盖 | 正面猛型选 A，防守型选 B |
| 便签 | 动态封锁 | 爆发陷阱 | 预判型选 A，一波型选 B |
| 计算器 | 群怪清屏 | 单体熔化 | 清群选 A，Boss 选 B |
| 耳机 | 防线重置 | 持续输出 | 稳守选 A，攻守选 B |
| 报表 | 全屏轨道 | 阵地遗留 | 机动选 A，站桩选 B |
| 碎纸机 | 大范围高伤 | 聚怪绞碎 | 输出选 A，控制选 B |
| 保温杯 | 持续治疗 | 输出技能 | 需要治疗选 A，缺输出选 B |
