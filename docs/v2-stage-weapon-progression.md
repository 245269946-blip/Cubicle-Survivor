# Demo V1 阶段与武器升级层级

这份表是 v2 主循环的阶段基准。关卡是体验节拍，阶段是武器 Build 层级；不能再用“第几关”直接等同某个阶段。

## 核心原则

- 玩家先通过多关体验当前武器层级，再进入下一层级。
- 阶段奖励发生在阶段结束后，不发生在阶段进入时。
- 工坊、经验、材料、卡槽都是服务当前主武器层级的副线，不负责跳阶段。
- 未实装阶段可以在数据里标记为 planned，但不能在 UI 或流程里假装已经开放。

## 当前试玩可玩阶段

| 阶段 | 关卡 | 武器升级层 | 玩家要学会什么 | 阶段内副线 | 阶段结束奖励 |
| --- | --- | --- | --- | --- | --- |
| 实习期 | 1-3 关，第三关为小考 | 初始武器母题 / 基础攻击 | 这把办公工具的基础清怪动词，例如马克笔是长射程贯穿拉线 | 经验给通用属性，材料微调基础武器；不出现工牌卡槽 | 第 3 关结束后选择工牌，进入转正期 |
| 转正期 | 4-7 关，第七关为转正评审 | 工牌核心变体 / 部门形态 | 同一把武器被工牌改造成什么战斗形态，例如马克笔变成分裂、光爆、护盾反刺、波纹、网格 | 卡槽逐步开放，工坊只补强当前部门形态；第 1 步开放输出，第 2 步开放生存/资源，第 3 步开放机制，第 4 步开放代价 | 第 7 关评审结束后获得武器专属转正强化 |
| 独当一面 | 8-10 关，第十关为独立交付 | 转正专属强化 / 强化形态 | 围绕已转正的主形态做更深数值和机制成长，让流派稳定成型，但不完全封顶 | 结束后开放第二部门初级能力 |
| 跨部门协作 | 11-13 关，第十三关为联合评审 | 第二工牌初级形态 / 双部门形态 | 主武器叠加第二部门的初级攻击形态，但仍以主部门为核心 | 结束后开放跨技能学习 |
| 跨技能学习 | 14-16 关，第十六关为最终形态验证 | 副武器本质技能 / 副武器协同 | 选择一把副武器，只保留它最本质的辅助技能，与主武器形成配合 | 完成本轮最终形态，后续可接终局 Boss 线 |

## 后续 Boss 线备忘

武器系统跑通后，可在跨技能学习之后追加分支 Boss 线：升职述职演讲、团队合并内部赛马、出任 CEO、辞职躺平、考公考编、独立创业。它们应作为最终形态后的验证关，不提前干扰武器成长主线。

## 系统职责

| 系统 | 阶段职责 |
| --- | --- |
| 经验 | 全程独立结算，满了就给通用属性选择；选项文案必须说明它如何影响当前主形态 |
| 材料 | 工坊消费资源，只用于强化当前主武器形态或当前阶段允许的副线 |
| 工坊 | 战斗后的材料强化点，不负责强行弹出阶段系统，不越权提供未开放的跨部门/跨武器内容 |
| 卡槽 | 转正期开始服务工牌形态；按转正期进度开放，显示覆盖/追加前后影响 |
| 复盘 | 先总结主武器最终处于哪个阶段、哪种形态，再讲伤害和建议 |
