# 《工位幸存者》Demo V3.2 战斗三角预算与霓虹增幅说明

## 目标

Demo V3.2 不新增武器、模块、组件、敌人或道具。它只深化两个已经验证但仍不足的体验层：

1. 让割草感持续来自“更小单击 × 更高频率 × 更多有效目标”，而不是单项数值膨胀。
2. 让霓虹成为攻击能量和技能轮廓的一部分，而不是全局提亮或与判定脱节的装饰。

V3.1 保留为独立回归入口，V3.2 通过协调器开关启用。

## 三角预算

三个参数必须联动：

| 参数 | V3.1 | V3.2 | 体验职责 |
|---|---:|---:|---|
| 马克笔基础伤害 / 间隔 | 11 / 0.58s | 8.5 / 0.46s | 让线网持续划过敌群，而不是一次清空 |
| 保温杯基础伤害 / 间隔 | 9.5 / 0.58s | 7.2 / 0.46s | 维持短宽蒸汽扇面的连续空间压力 |
| 剪刀基础伤害 / 最短轮转 | 13.5 / 0.30s | 10.5 / 0.25s | 增加可见剪切次数，同时保留贴身风险 |
| 修正液基础伤害 / 间隔 | 6.5 / 0.36s | 5 / 0.29s | 更快制造错误状态，避免基础喷射直接承担爆发 |

普通关相对原始固定遭遇：

- 总配额约 `1.88×`。
- 同时在场保底约 `1.75×`。
- 场上上限约 `1.68×`。
- 单批生成量约 `1.62×`。
- 生成间隔约 `0.52×`，最低0.58秒。

Boss关只使用较温和的 `1.32×—1.42×` 增量，避免杂兵遮挡Boss机制。

## 三角预算约束

- 不允许只提高敌人生命制造“怪很多”的假象。
- 不允许只缩短攻速而保留大单击，避免更快清空屏幕。
- 不允许只增加总配额而不提高同时在场保底，否则玩家仍会经历长空窗。
- 普通关目标是让贯穿、范围、连剪和传播持续找到目标；Boss关目标仍是读懂Boss并处理有限杂兵。
- 敌人伤害、移动速度和危险预警本轮不随密度同步加码，避免一次同时改变过多风险变量。

## 霓虹增幅规则

每个真实武器事件使用两层结构：

1. 低透明度、较大尺寸的外辉光，表达能量与运动残影。
2. 高对比、较小尺寸的核心，表达真实轨迹、中心和方向。

具体规则：

- 使用 `lighter` 叠加只绘制外辉光，不修改命中区域。
- 线性攻击的辉光沿真实起点与终点绘制。
- 区域技能的辉光读取真实半径和寿命。
- 击杀热浪保留金色爆心、琥珀波前和浅色压力回声，并额外增加低透明外环。
- UI只强化边缘、当前焦点、进度条和重要标题；正文与敌人信息不做全局发光。
- 敌人血条、Boss轮廓、危险预警和玩家本体必须始终压过背景辉光。

## 验收

1. 首关10秒内持续出现可攻击目标，不再在攻击轮次间形成明显空屏。
2. 四把武器基础攻击事件频率均比V3.1更高，但单次数字更小。
3. 马克笔贯穿、保温杯扇面、剪刀连剪和修正液叠层均能持续消耗敌群，而不是一次清屏。
4. Boss仍可从杂兵和技能辉光中辨认。
5. 同一技能的外辉光和核心来自同一个事件对象，不出现假范围。
6. 1280×720下，敌人血条、危险预警、玩家位置和移动方向保持清晰。
7. V3.0、V3.1及历史固定入口数值不发生漂移。
