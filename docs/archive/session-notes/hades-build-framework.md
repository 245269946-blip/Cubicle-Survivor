# Cubicle Survivor — Hades 式 Build 系统框架 v0.1

**设计目标：借鉴 Hades 2 的槽位+部门+协同结构，适配幸存者载体。**
**不做复制，做翻译。**

---

## 一、核心类比

| Hades 2 | Cubicle Survivor | 说明 |
|---------|-----------------|------|
| 8 个神 | 5 个部门 | 本局只出现 3-4 个 |
| 5 个槽位（攻/特/法/趋/魔） | 5 个槽位（主武/副武/移动/防御/通用） | 互斥，新覆盖旧 |
| 祝福 × 60+ | 卡牌 × 25（5部门×5张） | 精简版 |
| 双重祝福 | 跨部门协同 | 需要两个部门各特定卡 |
| 信物 | 工牌 | 开局前选 1 个部门强制出现 |
| 锤子 | 武器进化（Lv.7 二选一） | 武器形态质变 |

---

## 二、5 个部门

| 部门 | 办公概念 | 战斗风格 | 标志色 |
|------|---------|---------|--------|
| 🔥 **技术部** | 写代码/搞创新 | 链电、AOE、不稳定高爆发 | 橙 |
| 🛡️ **运营部** | 流程/规范 | 防御、续航、稳定 | 蓝 |
| ⚡ **产品部** | 赶需求/冲刺 | 攻速、暴击、高风险 | 紫 |
| 📋 **行政部** | 制度/后勤 | 范围、控制、辅助 | 绿 |
| 💼 **管理层** | 战略/全局 | 全属性加成、协同强化 | 金 |

每个部门 = 一种战斗哲学。不是数值差异，是**机制风格**。

## 三、5 个槽位（互斥）

```
┌──────────────────────────────────────┐
│  槽位 1：主武器加成                    │
│  ┌────────────────────────────────┐  │
│  │ 影响：你的第一把武器的行为       │  │
│  │ 例：技术部 → 攻击触发链电        │  │
│  │     产品部 → 攻击速度 +40%       │  │
│  │     运营部 → 攻击命中恢复 1 HP   │  │
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│  槽位 2：副武器加成                    │
│  ┌────────────────────────────────┐  │
│  │ 影响：第二把武器的行为           │  │
│  │ 和槽位 1 可以是同一个部门        │  │
│  │ 也可以是不同部门（跨部门组合）    │  │
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│  槽位 3：移动/走位                    │
│  ┌────────────────────────────────┐  │
│  │ 影响：移速、闪避、冲刺           │  │
│  │ 例：产品部 → 冲刺后 2 秒内伤害+30%│  │
│  │     行政部 → 经过处留下减速区域   │  │
│  │     管理层 → 每 15 秒瞬间传送到   │  │
│  │              最近的掉落物        │  │
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│  槽位 4：防御/续航                    │
│  ┌────────────────────────────────┐  │
│  │ 影响：血量、护甲、治疗、免伤     │  │
│  │ 例：运营部 → 获得护盾，低速回充  │  │
│  │     技术部 → 杀敌回血 2%         │  │
│  │     管理层 → 每关首次致命伤锁1HP │  │
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│  槽位 5：通用/资源                    │
│  ┌────────────────────────────────┐  │
│  │ 影响：经验、材料、拾取、全局     │  │
│  │ 例：行政部 → 掉落物自动吸附       │  │
│  │     产品部 → 杀敌经验 +25%        │  │
│  │     管理层 → 每有一张不同部门卡   │  │
│  │              +5%全伤害           │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

**关键：槽位互斥。** 槽位 1 已经有产品部的"攻速+40%"，就不能同时有技术部的"链电"。
如果想换，新卡覆盖旧卡。这个"覆盖"就是风险决策。

## 四、卡牌结构（25 张）

每个部门 5 张：2 普通 + 1 稀有 + 1 传说 + 1 跨部门协同触发卡

### 技术部 🔥

| 稀有度 | 卡名 | 槽位 | 效果 | 前置 |
|--------|------|------|------|------|
| 普通 | 敏捷开发 | 主武 | 击杀 10 个敌人后，下次攻击触发链电 | 无 |
| 普通 | 版本迭代 | 防御 | 每 15 秒，随机一个武器伤害 +20%，切换 | 无 |
| 稀有 | 重构 | 移动 | 消灭精英后重置所有冷却 | 拥有 1 张技术部卡 |
| 传说 | 技术突破 | 主武 | 所有攻击附带链电，链电可弹回已命中目标 | 拥有 3 张技术部卡 |
| 联动 | 开源协议 | 通用 | 使用其他部门卡牌时，技术部卡牌效果 +25% | 无(但需跨部门) |

### 运营部 🛡️

| 稀有度 | 卡名 | 槽位 | 效果 | 前置 |
|--------|------|------|------|------|
| 普通 | 流程审批 | 防御 | 受伤后 2 秒内受伤害 -30% | 无 |
| 普通 | 备份恢复 | 副武 | 每 30 秒回复 15% HP | 无 |
| 稀有 | 合规审查 | 防御 | 每 20 秒清除所有负面效果 | 拥有 1 张运营部卡 |
| 传说 | 免责声明 | 防御 | 每关首次致命伤害锁定 1 HP，获得 3 秒无敌 | 拥有 3 张运营部卡 |
| 联动 | 标准化作业 | 通用 | 与其他部门联动时，额外 +8% 全属性 | 无 |

### 产品部 ⚡

| 稀有度 | 卡名 | 槽位 | 效果 | 前置 |
|--------|------|------|------|------|
| 普通 | 紧急上线 | 主武 | 攻速 +40% | 无 |
| 普通 | 快速迭代 | 移动 | 冲刺后 2 秒内伤害 +30% | 无 |
| 稀有 | 截止日期 | 主武 | 对 50% 血以下敌人伤害 +35% | 拥有 1 张产品部卡 |
| 传说 | 产品发布 | 主武 | 暴击时产生范围爆炸，连锁触发其他暴击 | 拥有 3 张产品部卡 |
| 联动 | 需求评审 | 副武 | 主武和副武的伤害互相 +15% | 无 |

### 行政部 📋

| 稀有度 | 卡名 | 槽位 | 效果 | 前置 |
|--------|------|------|------|------|
| 普通 | SOP 标准 | 副武 | 武器冷却 -25% | 无 |
| 普通 | 留痕存档 | 通用 | 击杀经验 +25% | 无 |
| 稀有 | 自动化巡检 | 移动 | 每 8 秒在最近敌人位置自动生成一个陷阱 | 拥有 1 张行政部卡 |
| 传说 | 全自动办公 | 通用 | 每 15 秒自动释放一次任何武器的 Lv.3 级攻击 | 拥有 3 张行政部卡 |
| 联动 | 远程办公 | 防御 | 远离敌人 (>200px) 时伤害 +25% | 无 |

### 管理层 💼

| 稀有度 | 卡名 | 槽位 | 效果 | 前置 |
|--------|------|------|------|------|
| 普通 | 晨会 | 通用 | 选择卡牌时多一个选项 | 无 |
| 普通 | 团建 | 通用 | 所有武器伤害 +10% | 无 |
| 稀有 | KPI 考核 | 通用 | 连杀 30 时，获得 8 秒全属性 +25% | 拥有 1 张管理层卡 |
| 传说 | 全员持股 | 通用 | 每拥有一张不同部门的卡牌，全伤害 +8% | 拥有 3 张管理层卡 |
| 联动 | 战略重组 | 通用 | 可以替换任意槽位的卡牌不需要同部门 | 无 |

**传说卡需要 3 张同部门卡才能出现 → 玩家必须"投资"某个部门。**

## 五、跨部门协同（替代双重祝福）

**触发条件：两个槽位分别装了不同部门的特定卡牌。**

不是随机出现，而是**当你凑齐条件自动激活**。

| 协同名 | 条件 | 效果 |
|--------|------|------|
| 敏捷创新 | 技术部(主武) + 产品部(移动) | 冲刺后的链电基础伤害翻倍 |
| 快速迭代 | 产品部(主武) + 行政部(副武) | 杀敌后副武冷却 -0.3 秒 |
| 合规冲刺 | 运营部(防御) + 产品部(主武) | 暴击时获得 1 层护盾（上限 3） |
| 技术监管 | 技术部(主武) + 运营部(防御) | 链电命中后生成小型保护区（2 秒） |
| 自动化测试 | 技术部(主武) + 行政部(移动) | 陷阱自动触发链电 |
| 全员创新 | 管理层(通用) + 技术部(主武) | 所有武器共享链电跳跃次数 |
| 远程办公 | 行政部(联动) + 管理层(通用) | 低血量时自动在身后生成保护区 |
| 风险对冲 | 产品部(主武) + 运营部(防御) | 扣血效果减半，护甲效果翻倍 |
| 流程加速 | 行政部(副武) + 产品部(移动) | 武器冷却额外 -15%（叠加） |
| 全员冲刺 | 管理层(通用) + 产品部(主武) | 移速加成也适用武器攻速 |

## 六、本局流程

```
开局前
  ├─ 选 1 个起始武器（10 选 1）
  ├─ 选 1 个「工牌」（5 部门选 1，该部门的卡本局必定出现）
  └─ 其余 2-3 个部门从剩下 4 个中随机选出
      → 本局只有 3-4 个部门的卡池
  
第 1-2 关（熟悉期）
  ├─ 每次升级：3 选 1 卡牌
  ├─ 出现权重：工牌部门 +30%，其他出现部门各 +20%
  └─ 目标：填满 2-3 个槽位

第 3-5 关（定型期）
  ├─ 稀有卡开始出现（需要同部门前置）
  ├─ 玩家面临"覆盖"决策：新卡换槽位里的旧卡？
  └─ 第一次跨部门协同可能触发

第 6-8 关（成型期）
  ├─ 传说卡解锁条件可能达成（3 张同部门）
  ├─ 武器 Lv.7 进化
  └─ 第二个跨部门协同

第 9-10 关（终考）
  └─ Build 巅峰，检验是否经得起压力
```

## 七、和现有代码的关系

### 要删的
- 4 条路线系统（routeDefinitions / routeProgress）
- 7 个职业加成（weaponClassBonuses）
- 升级三选一里的通用词条（改从部门卡池抽）
- 现有的隐藏协同（替换为跨部门协同）
- 武器对绑定逻辑

### 要改的
- 升级面板 → 改为卡牌选择
- 武器进化 → 改为 Lv.7 二选一
- 道具系统 → 保留但降级为"通用道具"（不与部门卡竞争槽位）
- 开局流程 → 加工牌选择界面

### 要新建的
- 部门系统（5 个部门 × 5 张卡 = 25 张数据）
- 5 个槽位管理
- 卡牌稀有度/前置条件/权重系统
- 跨部门协同检测与激活
- 开局工牌选择 UI

### 保留的
- 10 个武器的基础数据和操作方式
- 敌人/关卡/材料/经验系统
- softCap 系统
- 战斗核心循环（移动+自动攻击+躲闪）

## 八、为什么不照搬 Hades 的全部

| Hades 有 | 我们不做（或简化） | 原因 |
|----------|-------------------|------|
| 60+ 祝福 | 25 张卡 | 幸存者载体不需要那么复杂 |
| 元素/赋能祝福 | 不做 | 增加学习成本 |
| 阿卡那牌 | 保留永久升级系统 | 已有工分升级 |
| 代达罗斯之锤 | 融入 Lv.7 进化 | 已有武器进化系统 |
| 房间路线选择 | 不做 | 幸存者类不需要 |
| 8 个神全 | 5 个部门 | 匹配办公题材 |
| 信物强制 1 个神 | 工牌强制 1 个部门 | 核心保留 |
| 双重祝福 30+ | 跨部门协同 10 个 | 保留深度但不溢出 |

## 九、改动量估算

| 改动 | 量级 | 说明 |
|------|------|------|
| 删旧代码 | 中 | 路线/职业加成/隐藏协同 |
| 部门+卡牌数据 | 小 | 25 张卡的 JSON |

**总计：中量改动（不是重写 60%，是删除 20% + 替换 30%）。**
