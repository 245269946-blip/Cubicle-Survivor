# 难度平衡补丁 — 2026-06-18 18:39

## 问题
用户反馈第 5 关即可挂机，难度设计有明显偏差。

## 根因分析
三项因素叠加导致过早"无敌"：

| 问题 | 旧值 | 问题描述 |
|------|------|----------|
| 敌人减伤(DR) | Stage 5: 92%, 9: 85%, 13: 75% (阶梯式) | 过于平缓，玩家 DPS 轻松碾压 |
| 护甲公式 | `100/(100+护甲×7)` | 16 护甲仅承受 47.2% 伤害 |
| 回血+无敌帧 | 0.64s+持续回血 | 被打后立刻回满，容错过大 |

## 实施的改动

### 1. DR 连续曲线（替代阶梯式）
```
Stage 1-2: 100% | Stage 3: 93.5% | Stage 5: 82.6%
Stage 7: 74.1% | Stage 9: 62.9% | Stage 11: 54.6%
Stage 13: 46.1% | Stage 14: 42.7%
```
公式: `1 / (1 + max(0,s-2)×0.07 + max(0,s-7)×0.05 + max(0,s-11)×0.05)`

### 2. 护甲削弱
`100/(100+护甲×5.5)` — 16 护甲从 47.2%→53.2% 受伤，↑13%

### 3. 敌人属性全面提升
- **healthMult**: 环形加速度项 (stage×0.14 + 平方项 0.028 + stage≥8 额外 0.025/级)
- **damageMult**: 线性和加速度均上调 (0.085/stage, mid+0.075, late+0.055)
- **speedMult**: 0.052/stage, stage≥6 额外 +0.02
- **maxConcurrent**: 基础值 16(stage×4.2), 压力关 +15%

### 综合效果（Stage 5 对标）
- 敌人有效 EHP: 2.1x → 2.6x (↑24%)
- 敌人伤害: 1.45x → 1.55x (↑7%)
- 承受伤害: 47.2% → 53.2% (↑13%)
- **总难度增幅**: ~35-40%，无法挂机但可通关
