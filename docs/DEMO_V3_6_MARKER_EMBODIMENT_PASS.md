# Demo V3.6 马克笔人武器实体化版

## 版本目标

Demo V3.6 只解决一个正式试玩缺口：马克笔实验已经验证的实体展示，在 Demo V3.5 四武器框架中完全缺失。

本版完整继承 Demo V3.5 的战斗数值、17 关结构、敌人配额、Boss 压力、经验、组件和模块规则。不得把三分钟实验的伤害、攻速、敌人或成长时间带入正式 Demo。

## 运行入口

- 当前入口：`Cubicle-Survivor-demo/demo-v3-6.html`
- 回归入口：`Cubicle-Survivor-demo/demo-v3-5.html`
- 协调器：`four-weapon-v3-6`

## 展示合同

### 身体层

- 马克笔角色使用四方向“马克笔人＋背部打印坞＋平行双墨盒”整合图集。
- 角色与双墨盒只跟随玩家移动方向，不跟随自动攻击方向旋转。
- 未选择路线时，双墨盒结构保持可读但核心处于低亮待机，避免出现“装备不存在”的错觉。

### 武器层

- 物理马克笔使用八方向图集，只跟随当前真实攻击目标方向。
- 笔保持在角色近身外围，笔尖朝外；角色、笔和攻击路径必须属于同一因果链。
- 基础数量和复写平行线数量直接决定可见发射笔数量，上限只用于避免角色周围完全被遮挡，不修改真实攻击事件。

### 路线光感

- 复写：暖黄核心＋低透明暖黄辉光。
- 留档：冷青核心＋低透明冷青辉光。
- Lv1—Lv4 同时提高核心亮度与外围辉光，Lv4 仍由真实全屏机制承担终局反馈。
- 混合路线必须同时保留两种核心颜色，禁止整个人物统一染色。

### 组件实体

- 笔头组件安装在真实笔尖侧，笔身组件安装在真实笔杆，范围型笔尾组件安装在笔尾。
- 数量组件首先以 Demo 的真实 `amount` 增加可见发射笔，不额外伪造攻击数量。
- 持续时间组件属于供墨流程，固定显示在背部留档侧，不跟随攻击瞄准旋转。
- 白—蓝—紫—红品质提高组件的尺寸、核心亮度与外辉光，但不改变机制。

## 数值冻结

以下内容必须与 Demo V3.5 一致：

- 四把武器的全部 `activeFormParams` 数值与布尔机制开关；
- 17 关敌人配置、持续配额、Boss 血量与攻击频率；
- 模块出现时间、Lv1—Lv4 行为和组件属性成长；
- 经验、材料、商店与通关条件。

## 验收矩阵

1. 基础马克笔阶段：笔清晰可见，双墨盒框架可识别，攻击判定不变。
2. 四个身体方向：角色与双墨盒保持同一穿戴关系，不出现接在空气上的部件。
3. 八个攻击方向：笔尖与真实激光同向，角色转身不强迫笔改向。
4. 复写 Lv1—Lv4：暖黄墨盒逐级变亮，可见笔数反映 Demo 的数量与平行线状态。
5. 留档 Lv1—Lv4：冷青墨盒逐级变亮，墨迹仍由原正式机制生成。
6. 混合路线：两种墨盒都清楚，黄激光与青墨迹保持分层。
7. 组件路线：三个槽的部位、互斥属性和品质能落到正确实体；数量只随真实 `amount` 增笔。
8. 四武器回归：保温杯、剪刀、修正液的模型、战斗和数值不受影响。
9. 版本回归：Demo V3.5 入口继续运行且不会自动启用实体化层。

## 自动验证

- Demo V3.6 协调器与入口存在；
- V3.6 四武器数值快照与 V3.5 完全一致；
- 马克笔视觉状态从正式模块、数量、移动方向和攻击方向读取；
- V5 四方向穿戴图集与 V4 八方向马克笔图集已进入正式运行包。
