# 《工位幸存者》Demo V2.6 四武器霓虹整合测试

状态：**统一试玩入口已实现；四个单武器固定测试继续保留为回归入口**

入口：`Cubicle-Survivor-demo/demo-v2-6.html`

## 1. 目标

在同一个版本选择并对比四把武器：

| 武器 | 改变的关系 | 固定路线 |
| --- | --- | --- |
| 马克笔 | 攻击路径 | 复写 / 留档 |
| 保温杯 | 战场空间 | 冷凝 / 击杀热浪 |
| 剪刀 | 自身位置与近战时间线 | 合刃 / 张刃 |
| 修正液 | 敌人状态与价值 | 错误扩散 / 致命纠错 |

统一入口只负责武器选择、Demo V2.6 版本身份与共享视觉层。选择后仍进入该武器独立的固定配置，继续使用相同的 5 阶段 17 关、经验、模块和组件节奏。不得为了合版合并四把武器的数据、路线或组件含义。

## 2. 疯狂办公室视觉原则

> 办公室是世界的材质来源，不是视觉的最终边界。

- 暗色办公室背景作为低亮底板，武器异化产生战斗主光。
- 办公物件材质保留在武器实体和少量残留痕迹中；攻击不能全部像正常桌面用品。
- 马克笔以青蓝长线和紫色扫描高光表现路径失控。
- 保温杯以青白蒸汽、绿色冷凝和暖金热浪表现空间压力。
- 剪刀以钢白刃光、橙红终剪和品红故障闪点表现近战危险。
- 修正液最适合完整赛博故障语言：白色介质说明状态，青/品红扫描说明错误，橙红用于崩溃和最终纠错。
- 共享霓虹层只能从真实 `*_test_*` 事件对象读取位置、方向、半径和寿命；通过透明精灵绘制，不新增伤害事件或可见 Canvas 几何图元。

## 3. 版本与入口规则

- `demo-v2-6.html` 是本轮主要试玩入口。
- `demo-v2-marker.html`、`demo-v2-thermos.html`、`demo-v2-scissors.html`、`demo-v2-correction-fluid.html` 继续保留，用于定位单武器回归问题。
- 统一入口显示 Demo V2.6；进入战斗后保留武器本身的历史固定配置，同时 HUD 和结算继续显示 V2.6 套件身份。
- Demo V2.6 是固定框架整合试玩，不等于当前 Demo V1 默认入口完成切换，也不等于生产简报中 8—10 分钟完整主线自动通过门禁。

## 4. 验收

1. 选择页同屏显示四把武器，不出现即时贴或完整 Demo V1 的武器/工牌池。
2. 四张卡能用一句话区分路径、空间、位移和状态关系。
3. 每张卡进入正确的独立固定测试，版本 HUD 保持 Demo V2.6。
4. 共享霓虹高光不会改变命中、范围、敌人压力或组件经济。
5. 修正液错误状态和两条路线完整可玩。
6. 四把武器的战斗主色、形状和节奏仍可区分，不退化成统一青色换皮。
7. 自动测试覆盖四武器路由、修正液核心机制、视觉/音频事件和 7 张修正液资产。
8. 浏览器实机检查选择页、基础战斗、错误 Lv4、商店与 1280×720 战斗安全区。
