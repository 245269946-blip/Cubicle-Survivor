# 马克笔三分钟欲望闭环实验

状态：独立可玩实验，不替换 Demo V3.5，不命名为 Demo V3.6。

入口：`Cubicle-Survivor-demo/marker-desire-loop.html`

## 唯一验证问题

第一次接触游戏的玩家，能否在三分钟内连续感到：

1. 这把武器有独立动词；
2. 我的选择真实长在武器上；
3. 两条路线不是相加，而是产生新的因果结果；
4. 我愿意为了另一种组合再来一次。

## 冻结范围

- 仅马克笔；
- 复写 Lv.1—Lv.4；
- 留档 Lv.1—Lv.4；
- 一次实体组件安装；
- 一个复写 × 留档的“调阅”融合；
- 四次模块选择；
- 三分钟连续战斗；
- 一次成长归因复盘。

不包含 17 关、组件品质合成、刷新经济、经验属性池、第三模块、道具、第二武器和复杂 Boss。Lv.4 只验证纯复写与纯留档的终极统治窗口。

## 时间线

| 时间 | 内容 | 玩家应感知到的变化 |
|---|---|---|
| 0—25 秒 | 普通马克笔 | 中性白线是尚未偏向路线的基础动作 |
| 25 秒 | 第一次模块 | 新攻击实体 + 新武器部件同时出现 |
| 60 秒 | 一次组件安装 | 属性判定与笔头/笔身/笔尾模型同时变化 |
| 100 秒 | 第二次模块 | 继续极化或建立混合路线 |
| 140 秒 | 第三次模块 | 形成 Lv.3 主轴或 2+1 混合结构 |
| 155 秒 | 第四次模块 | 纯路线进入 Lv.4；混合路线继续形成 3+1 或 2+2 |
| 155—180 秒 | 高密度展示 | 对比融合协同和纯路线终极技的不同欲望 |
| 180 秒 | 成长复盘 | 显示形态链与四类伤害归因 |

## 视觉与机制硬合同

- 暖黄：当前发生的即时激光；
- 冷青：留在战场上的历史墨迹；
- 白色：当前黄线与历史青墨发生交点；
- 洋红：从交点沿旧档案移动的调阅脉冲。

复写控制器、留档墨仓和选中组件必须归属于同一套“马克笔人”装配系统。攻击特效、命中判定和实体装配读取同一份模块与组件状态。

本轮视觉资产使用赛博霓虹“马克笔人＋可组合改造件”的统一风格，不再使用完整人物插画互相叠加。运行时由四类独立图集拼装：四方向两步态的人物骨架 `marker-person-directional-v4.png`、八个攻击朝向且共享后端锚点的近身发射笔 `marker-weapon-directions-v4.png`、共用背部打印坞与复写/留档 Lv1—Lv4 墨盒图集 `marker-printer-rig-v1.svg`、攻击图集 `marker-attack-atlas-v2.png`。人物始终只绘制一层；只有发射笔根据实时攻击角度选择八方向帧并做小角度校正。打印坞、复写墨盒和留档墨盒只读取人物朝向，作为一套刚性穿戴结构共同旋转；纯路线使用中置单墨盒，混合路线在同一坞体上并列安装双墨盒。

纯复写 Lv.4【全页批注】周期展开以当前瞄准方向为核心的宽幅聚焦束群，并由少量斜向/后向线束补足外围；纯留档 Lv.4【整页归档】周期生成大范围持续墨场。它们必须在覆盖量、持续时间和镜头反馈上显著强于一次调阅，但代价是放弃另一条路线及其持续协同。

调阅不能用全屏染色替代。每条旧墨迹每轮最多被调阅一次；单轮最多触发两条，洋红只显示移动中的局部脉冲，不能覆盖冷青墨迹的持续识别。

### 外围显性 Build 空间合同

角色身体只承担移动与朝向，不再承载整张路线插画。所有玩家需要辨认的发射笔、路线控制器和实体组件都安装在身体外侧，并共享以下运行时合同：

- 身体核心识别区半径为 48px；穿戴件可以有限压入该区形成真实遮挡，但不得覆盖人物头部、主体朝向或完整武器。
- 基础发射笔位于约 64px 的近身圈；打印坞位于背部约 18px，路线墨盒位于背部约 31px。升级优先通过新增真发射器、墨盒输出栅格、液位与辉光强度膨胀，不把零散部件推到远距离轨道。
- 显示位置、八方向瞄准帧、笔尖偏移和攻击判定读取同一份发射器数据。主可见光束只从真实笔尖向外绘制；角色身体到笔尖之间保留不可见的贴身保护判定，消除非设计性盲区，但不得再画第二条前向光束造成双重判定错觉。
- 只有发射笔读取实时攻击方向并围绕角色重新排布。其他实体不能只用“固定坐标”冒充装配，必须声明拥有者、安装部位与跟随规则。
- 留档墨盒与复写墨盒共享同一个背部打印坞：纯路线中置安装，混合路线在坞体左右并列安装；两者只读取人物移动朝向，不追随攻击目标。墨盒 Lv1—Lv4 逐级增加亮度、液位/输出栅格与局部轮廓，不能只依靠 HUD 表示等级。
- 笔头组件安装到每支真实发射笔的笔尖；加急笔身安装到笔身；范围笔尾安装到笔尾；数量笔身以新增真实发射笔作为实体结果，不额外漂浮一块道具；长效笔尾接入背负墨仓。
- 复写与留档 Lv1—Lv3 的真实发射器均保持同向平行前射，只通过发射器数量、横向覆盖和攻击轮次膨胀。只有复写 Lv4 终极技允许出现外围四散束，而且正面聚焦束群必须承担主要视觉和命中覆盖。
- 路线控制器、武器、组件和人物按世界坐标 y 值排序。位于角色后方的装置可被身体部分遮挡，但任何完整武器不得长期消失。
- 数量组件会增加真实第二组发射器；Lv3 的第二轮仍由原有发射器再次开火，不用假武器冒充；Lv4 终极控制器进入最外圈。
- `?layout=1` 仅用于开发验收，显示安全区、安装圈、挂点和笔尖，不属于玩家正式画面。

跨武器复用的所有权、安装、坐标、攻击因果与素材验收规则统一见 `WEAPON_VISUAL_DESIGN_STANDARD.md`。

## 对照版本

- `?variant=A`：压缩基线；没有实体成长，也没有调阅融合；
- `?variant=B`：加入实体成长；两条路线仍只并行；
- `?variant=C`：实体成长 + 调阅融合，默认版本。

## 验收

- 玩家能指出本轮马克笔具体长出了什么；
- 玩家能解释第二个选择如何改变第一个选择；
- 混合路线在最终一分钟稳定出现多次可读调阅；
- 纯路线到达 Lv.4 后，玩家能在一次发动内立即分辨“普通膨胀”和“终极统治”；
- 黄、青、白、洋红不会长期融成同一种光；
- 复盘能解释伤害来自基础、复写、留档还是调阅；
- 玩家主动重开时，理由是想试另一种组合，而不是没看懂刚才发生了什么。
