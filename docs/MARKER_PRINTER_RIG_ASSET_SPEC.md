# 马克笔背部打印坞实装素材规格

状态：生成正式美术前的硬门槛。任何大图概念稿、产品展示图或未经过实机缩放检查的图集都不能接入运行时。

## 1. 目标

打印坞不是角色旁边的道具图标，而是马克笔人的穿戴身体。玩家在约 94px 的人物绘制框、约 48px 的主体识别区中，必须无需 HUD 就能辨认：

- 当前是否安装路线墨盒；
- 是暖黄复写还是冷青留档；
- 是单路线还是双路线；
- 模块等级正在提高。

## 2. 已通过的运行布局

运行坐标来自 `marker-desire-loop.js` 的 `BUILD_LAYOUT`：

| 对象 | 运行尺寸 | 人物背向距离 | 横向位置 |
|---|---:|---:|---:|
| 单路线打印坞 | 56 × 48px | 10px | 中央 |
| 双路线打印坞 | 80 × 48px | 10px | 中央 |
| 单路线墨盒 | 44 × 58—64px | 15px | 主肩背位 +21px |
| 双路线单个墨盒 | 40 × 58—64px | 15px | 左右各 ±23px |

四个人物朝向统一使用人物局部的 `back` 与 `right` 轴计算，不使用屏幕固定偏移。正面朝向时设备位于人物身后，但每个墨盒必须至少从肩侧露出约 14px；背面朝向时显示完整功能面；左右朝向允许产生真实的前后遮挡。

## 3. 单张样稿门槛

第一张正式样稿只制作：

> 正面站立人物 + 双路线打印坞 + 复写 Lv2 墨盒 + 留档 Lv1 墨盒

这张样稿只验证轮廓，不扩展其他等级和朝向。必须满足：

1. 人物头部、脸和移动朝向保持原角色识别；
2. 两个墨盒分别从左右肩后露出，不得被身体完全遮住；
3. 墨盒的有效像素覆盖各自素材框至少 80%，不能在大透明框里放一个小产品图；
4. 复写依靠大面积输出栅格辨认，留档依靠大面积透明液窗辨认；
5. 暖黄/冷青只是强化结构，关闭辉光后仍能靠轮廓区分；
6. 缩放到 94px 与 64px 人物高度时仍能识别双墨盒；
7. 不出现独立漂浮、桌面摆放、商品摄影透视或无法连接人体的接口。

## 4. 等级成长语法

同一墨盒骨架上做局部帧，不为每级重画一台完全不同的机器：

| 等级 | 复写墨盒 | 留档墨盒 |
|---|---|---|
| Lv1 | 一格输出栅格 | 低液位单窗 |
| Lv2 | 两格输出栅格 | 中液位双刻度 |
| Lv3 | 满格栅格 + 外接走纸件 | 高液位 + 外接软管 |
| Lv4 | 过载外框 + 脉冲灯 | 压力外框 + 脉冲液路 |

亮度随等级上升，但核心像素保持深色实体边框，禁止把 Lv4 画成失去结构的发光方块。

## 5. 完整图集顺序

只有单张样稿通过后才扩展：

1. 四方向打印坞；
2. 四方向复写墨盒基础骨架；
3. 四方向留档墨盒基础骨架；
4. 两路线各 Lv1—Lv4 的局部等级层；
5. 站立与移动遮挡矩阵；
6. 94px、64px 和战斗密集场景验证。

生成大图好看不属于验收项。可裁切、可安装、可缩放、可辨认才算完成。

## 6. 2026-07-22 实机接入决定

- 正式四朝向穿戴资产为 `marker-person-printer-rig-directions-v5.png`，顺序固定为正面、向右、背面、向左。
- 两只墨盒与共享背部打印坞作为永久穿戴硬件存在，不再在纯路线和混合路线之间凭空拆装；未选择路线的墨盒熄灯待机。
- 复写为角色左肩背部的黄色双层输出格栅，留档为角色右肩背部的青色液窗；左右所有权随人物转向保持，不按屏幕左右镜像交换。
- 运行时先按每格非透明像素裁切，再按人物总高绘制；不得直接按原始大画布缩放。
- 运行时从透明资产中分别提取黄色格栅与青色液窗，生成独立内核光层。Lv1—Lv4 只提高对应路线的清晰内核和低透明 bloom，不给整个人物染色。
- 混合路线长期保持黄/青双通道；洋红只属于真实“调阅”交点和回读脉冲。
- 已通过 1280×720 战斗背景中的 94px 与 64px 可读性门槛。后续等级结构图仍需按 Lv1—Lv4 分层补齐，但不得回退到旧的简笔 SVG 占位打印坞。
