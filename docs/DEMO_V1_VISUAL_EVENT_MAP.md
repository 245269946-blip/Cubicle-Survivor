# Demo V1 武器视觉事件映射

> 本文只描述 active Demo V1：`Cubicle-Survivor-demo/`。事件源、视觉合同和运行时渲染的唯一实现入口分别是 `src/v2/data/form-signatures.js` 与 `src/v2/combat/systems.js`。

## 映射合同

每个武器事件源必须同时具备：

- `family`：`marker / thermos / sticky_note`
- `phase`：机制语义，如 `cast / charge / detonate / expand / link`
- `topology`：玩家实际看到的形状，如贯穿线、蒸汽柱、旅行环、贴纸陷阱、多边形区域
- `cue`：该事件独有的动作含义，如出程、返程、二次命中、破盾、同步信号、死亡传播
- `role`：`primary / secondary / support`
- `timeline`：从 `anticipation / release / impact / residual / fade` 中选择的真实表现阶段
- `palette` 与 `intensity`：保持武器家族色，同时约束主次层级

当前 71 个已登记事件源全部具备上述字段。形态签名中引用的任何事件源如果没有视觉映射，`test-runner.js` 会直接失败。

## 层级规则

| 层级 | 强度 | 视觉职责 |
|---|---:|---|
| 主形态 `primary` | 1.00 | 保持当前主武器攻击拓扑最清楚、最亮 |
| 跨部门 `secondary` | 0.72 | 只补充同武器的低频次级机制，不覆盖主形态 |
| 跨武器 `support` | 0.58 | 只保留借用武器的核心动词；更细、更暗、更低频 |

## 15 个部门形态的关键视觉读法

| 武器 | 部门 | 事件链 | 实机视觉 |
|---|---|---|---|
| 马克笔 | 技术 | 主贯穿 → 命中点分支 → 二次锁敌 → 全屏扫线 | 主线完整贯穿；分支只从真实命中点生长；精修扫线使用平行扫描轨 |
| 马克笔 | 产品 | P0 标记 → 倒计时 → 二次命中引爆 → 转标/过期 | 四角锁定框与倒计时弧；爆炸只在二次命中出现；过期只消散 |
| 马克笔 | 运营 | 命中充盾 → 承伤破盾 → 反刺 | 分段护盾弧先积累，破盾后才出现从玩家射出的反击短线 |
| 马克笔 | 市场 | 末命中点 → 出程波 → 返程波 | 出程为蓝色实线旅行环；返程为紫色虚线反向环，并带方向箭头 |
| 马克笔 | 行政 | 残留线 → 校准交点 → 控制区 | 残线带移动扫描点；真实交点展开规则区域 |
| 保温杯 | 技术 | 蓄热 → 模块部署 → 巡航 → 模块蒸汽 | 模块实体与玩家分离巡航；蒸汽从模块位置喷向目标 |
| 保温杯 | 产品 | 预热 → 沸点压缩 → 粗蒸汽柱 → 余温 | 预热是细束与蓄热弧；释放为带汽团分节的粗柱，和弱蒸汽明显区分 |
| 保温杯 | 运营 | 蒸汽充盾 → 破盾 → 热浪 | 护盾弧积累；破盾后出现带传播方向的热浪环 |
| 保温杯 | 市场 | 茶香主波 → 附着 → 死亡回声 | 主波与死亡点小回声使用不同半径和节奏，均保持旅行波前 |
| 保温杯 | 行政 | 据点蓄热 → 部署 → 补给区域 | 茶水站实体固定；安全范围、治疗和减速边界由独立区域圈表示 |
| 即时贴 | 技术 | 放置 → 装订 → 寻敌 → 碰撞/弹跳 | 贴纸实体可见；装订刻度、寻敌移动和一次性碰撞爆点分开 |
| 即时贴 | 产品 | 多点放置 → 同步开关 → 延时连爆 | 中央金色开关脉冲先出现；爆点按序延迟，固定靶场用不同展开进度展示链条 |
| 即时贴 | 运营 | 路线放置 → 首次领取 → 敌人减速 | 路线贴保留实体；领取使用一次性护盾弧，不伪装成持续增益 |
| 即时贴 | 市场 | 目标附着 → 击杀 → 放射传播 | 附着框留在敌人身上；死亡后才出现放射转移线 |
| 即时贴 | 行政 | 三点放置 → 校准 → 连边 → 闭合区域 | settled 状态只保留三张贴纸、三条边和内部区域，已结束的放置闪光不会永久叠加 |

## 跨阶段映射

- 转正与精修：通过数量、宽度、半径、持续、第二触发或返程层直接改变已有事件，不另造无机制意义的装饰。
- 跨部门：使用 `secondary_*` 事件源，强度 0.72，保持同武器家族色。
- 跨武器：辅助马克笔是细虚线短贯穿；辅助保温杯是低强度小旅行环；辅助即时贴是单张延迟陷阱及一次触发爆点。
- 固定靶场会把 `source:family:topology:role:cue` 写入 `data-mechanic-lab-visuals`，便于浏览器验收与后续音频映射复用。
- 武器选择、工牌选择和页面身份区的缩略预览也读取同一事件合同：马克笔显示贯穿/分支，保温杯显示蓄热环/蒸汽束，即时贴显示贴纸实体/布阵结构。旧版 `marker_beam / thermos_steam / sticky_base` 等裁切图不再预加载或由 UI 请求。

## 2026-07-13 验收

- 自动合同：71/71 事件源通过 family、topology、cue、role、palette 与 timeline 完整性检查。
