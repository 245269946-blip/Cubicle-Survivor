## 决策节点详解

### 决策 1：开局准备（运行前，权重 ⭐⭐⭐⭐⭐）

**这是最重要的决策。决定整局的 Build 身份。**

```
选择 2 个核心武器（10 选 2）：
  → 定义起始 Build 方向
  → 影响后续选项出现权重

选择 1 个起始道具（3 选 1）：
  → 轻度方向指引
  → 可选：外文合同（暴击）/ 番茄钟（冷却）/ 保温杯垫（治疗）

可选：选择难度词条（黑暗词条）：
  → 收益：材料/经验加成
  → 风险：对应负面效果
```

**为什么放在开局前而不是第一关里？**
- 试 Build 的主动机需要"我有计划地进去"
- 中途发生 Build 转向才有意义（"我本来走精准，但出了个键盘进化道具..."）
- 开局前无压力，可以慢慢思考

### 决策 2：升级三选一（局内，权重 ⭐⭐⭐⭐）

**最频繁的决策点。当前已经存在，需要改造的是选项质量。**

```
改造前（当前）：
  4 个选项随机出现，和 Build 不相关
  
改造后：
  3 个选项（减 1），但出现权重受 Build 身份影响：
  - 精准 Build 下，精准类词条出现率 +40%
  - 已有 3 件武器同职业时，该职业词条出现率 +25%
  - 保证至少 1 个选项与当前 Build 相关
  
  每 5 级给一次"重抽"机会（替换 3 个选项）
```

### 决策 3：流派定型选择（局内 S3-4，权重 ⭐⭐⭐⭐⭐）

**新型决策节点。在玩家有一定基础后，要求明确方向。**

```
在 Lv.6、Lv.9、Lv.12 触发（共 3 次）

形式：不是"三选一"，而是"二选一方向"
  例：精准路线玩家可能看到：
  ┌─────────────────────────┐
  │ 选择你的流派方向          │
  │                          │
  │ A：暴击特化               │
  │   暴击率 +8%，暴击倍率→2.0│
  │   代价：攻速 -15%         │
  │                          │
  │ B：贯穿特化               │
  │   贯穿 +2，贯穿伤害不衰减  │
  │   代价：单发伤害 -12%     │
  └─────────────────────────┘
  
作用：把 Build 从"顺其自然"变成"有意识的选择"
```

### 决策 4：风险道具（局内 S5-6，权重 ⭐⭐⭐⭐）

**新节点。在压力上升期提供"贪 vs 稳"的决策。**

```
触发：S5 开始，每关 Boss 击杀后概率出现（约 50%）

形式：3 选 1 风险道具
  每个道具都有强力正面 + 明确代价

例：
┌───────────────────────────────────────────────┐
│ 加班补贴：攻速 +20%，冷却 -25%                   │
│ 代价：每 10 秒失去 5% 当前生命                   │
│                                               │
│ 全员持股：所有伤害 +18%                          │
│ 代价：商店价格翻倍，经验获取 -20%                  │
│                                               │
│ 无限会议：经验获取 +40%                          │
│ 代价：所有敌人速度 +12%                          │
└───────────────────────────────────────────────┘
```

### 决策 5：武器进化（Lv.7 触发，权重 ⭐⭐⭐⭐⭐）

```
每个武器到达 Lv.7 触发"进化选择"：

不是自动进化，而是 2 选 1 进化方向：

马克笔 Lv.7：
  A：蓄力期间自动发射咖啡弹幕（联动咖啡）
  B：满蓄后额外产生 3 道分裂激光（独立方向）

键盘 Lv.7：
  A：挥击产生冲击波覆盖背后（360°）
  B：击中后产生键帽碎片阵（延迟二次伤害）
```

### 决策 6：路线终局（局内 S7-8，权重 ⭐⭐⭐）

```
当一条路线达到 Tier 3（两武器均 Lv.5+）触发：

"你的 [精准贯穿] 路线已经成熟。选择终极方向："

A：强化路线巅峰（路线联动效果 ×1.5，其他路线失效）
B：开启第二条路线（另选一对武器激活第二条路线，双路线各 75% 效果）

这是"专精 vs 混搭"的终局选择。
```

### 决策 7：道具替换（已有，优化权重 ⭐⭐）

```
保持现有的 6/6 槽满触发替换面板
增加：道具替换时提示"这个道具对 [当前 Build] 的重要性：高/中/低"
```

### 决策 8：关底总结（通关/死亡后，权重 ⭐⭐⭐⭐）

```
不是现在的一句话结算，而是：

┌───────────────────────────────────────────┐
│  第 7 关 — 审计追问                         │
│                                            │
│  你死于：audit（审计员）                    │
│  受伤最多的伤害类型：单体高血量               │
│                                            │
│  你的键盘+订书机对此敌人效率：⚠️ 不足        │
│  该敌人弱点：calculator / report            │
│                                            │
│  建议下次尝试：                              │
│  → 更换一把弱点武器（计算器或报表）           │
│  → 或在 S5 风险道具中拿"全员持股"补输出      │
│                                            │
│  本次收获：                                 │
│  材料 ×78   工分 ×42                         │
│  新发现组合：键盘+碎纸机（近战绞肉）           │
│  [再开一局]                                 │
└───────────────────────────────────────────┘
```

## 决策密度曲线

```
开局前  ██████████  最重要的决策（选武器）
S1-2    ████        频繁低重要度的升级选择
S3-4    ████████    流派定型选择（高重要度）
S5-6    ███████     风险道具 + 进化选择
S7-8    ██████      终局方向 + 道具替换
S9-10   ███         Boss 战，少决策、多执行
```

决策密度先升后降：前期在选"我是什么"，后期在执行"我选的这个能不能活"。
