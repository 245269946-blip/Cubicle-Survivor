# 战斗载体改造方案 v1.0

**目标：4 种 Build = 4 种操作体验。不是"换个武器自动打"。**

---

## 操作类型分类

### A 类：自动攻击（无需操作）
适用于防御/光环型武器。玩家不操作它，它自动生效。

### B 类：面向攻击（跟随移动方向）
适用于近战/扇形武器。玩家用 WASD 控制移动方向 = 控制攻击方向。

### C 类：手动瞄准（跟随鼠标/右摇杆）
适用于精准/单点武器。玩家需要瞄准后再攻击。

### D 类：技能放置（按键触发）
适用于陷阱/召唤型武器。玩家需要在特定位置/时机使用。

## 逐武器改造方案

### 1. 咖啡 ☕ — A+C 混合

```
现状态：自动向最近敌人射击（A 类）
改造后：保持自动，但增加手动注入

默认：自动向最近敌人射击（保留）
新增：按 [空格] 或右键→强制向鼠标方向发射一波加速咖啡弹幕
      有独立 CD（～1.5 秒），不占用自动射击
      
目的：保留 Survivor-like 的易上手，
      同时给精准玩家一个"手动点杀"的技能表达
```

### 2. 马克笔 🖊️ — C 类（最大改动）

```
现状态：自动向最近敌人发射激光（A 类）
改造后：按住左键蓄力，松开发射

蓄力阶段（按住）：
  - 角色不能攻击，移速 -30%
  - 准星线指向鼠标方向
  - 蓄力条在角色上方显示（0.8 秒满蓄）
  - 期间自动攻击暂停
  
发射阶段（松开）：
  - 发射高伤贯穿激光
  - 伤害 = base × 蓄力系数（0.3~1.0）
  - 满蓄时必定暴击
  - 贯穿所有路径上敌人，穿透衰减
  - Lv.3+ 满蓄额外射出一道分支激光

Lv.7 进化 A — 蓄力风暴：
  蓄力期间自动向周围发射咖啡弹幕
  蓄力 0.8 秒内发射 4 波，每波 3 发

Lv.7 进化 B — 分裂棱镜：
  满蓄激光命中后分裂为 3 道短距离折射
  折射伤害 = 主激光的 60%

操作门槛：需要预判安全窗口 → 找位置 → 蓄力 → 发射
对走位和时机判断要求高
```

### 3. 键盘 ⌨️ — B 类（已部分改造，需强化）

```
现状态：已改为近战挥动武器（B 类方向性）
需要强化：

挥击方向 = 最后 WASD 输入方向（不是鼠标）
  如果玩家按 W+D 移动，挥击指向右上方
  如果玩家静止不动，挥击指向上一次移动方向
  
命中反馈增强：
  - 击中时画面微震（视效，不干扰操作）
  - 击中数量越多震感越强
  - 致命一击（击杀精英）产生大震
  
Lv.7 进化 A — 冲击波：
  挥击产生 360° 冲击波覆盖背后
  冲击波伤害 = 主挥击的 50%

Lv.7 进化 B — 键帽碎片阵：
  每次击中产生 5 个键帽碎片
  碎片追踪附近敌人，造成延迟二次伤害

新增：键盘敲击音效随击中数量变化
     击中 1 个=清脆，击中 10 个=沉闷轰鸣
```

### 4. 订书机 📎 — B 类

```
现状态：扇形弹幕（方向不明确）

改造后：
发射方向 = 玩家最后移动方向（同键盘）
  
如果键盘和订书机共用方向 → 近战挥击+扇形弹幕在同一方向
  → 狂战士体验：冲过去→键盘打脸+订书机补刀一气呵成

如果键盘在 CD → 退后一步向怪物方向发订书钉
  → 攻防转换的节奏感

旋转技术：玩家可以 WASD 微调方向旋转订书钉覆盖角度
          （例如顺时针转一圈，扇形覆盖 360°）

Lv.7 进化 A — 重型订书钉：
  钉书钉尺寸 ×2，穿透 +1，击退 +50%

Lv.7 进化 B — 订书钉风暴：
  发射时额外向两侧 ±30° 各射一排钉书钉
  三排扇形 = 超大覆盖面
```

### 5. 便签 🟨 — D 类（完全改造）

```
现状态：自动在脚下放置陷阱（A 类）

改造后：
按 [E] 在鼠标位置放置一个便签陷阱（最长 6 秒）
  放置 CD：2.5 秒（受冷却影响）
  同一时间最多 5 个陷阱
  陷阱：半径 54-96px，敌人进入减速 40% + 每秒受伤
  
视觉：陷阱出现时便签纸飘落动画
      陷阱生效时微微发光
      快消失时闪烁警告

Lv.7 进化 A — 智能便签：
  陷阱缓慢追踪最近敌人（速度 ~20px/s）
  多重陷阱覆盖同一敌人时伤害叠加

Lv.7 进化 B — 复印风暴：
  放置时在周围 120px 内产生 3 个临时子陷阱（持续 2 秒）
  子陷阱伤害 = 主陷阱的 40%

操作门槛：需要预判敌人走位 → 在地图上布置封锁线
         后续利用陷阱间距 kiting
```

### 6. 计算器 🧮 — A 类（保持自动）

```
现状态：自动连锁电击（A 类）
改造后：保持自动，强化视觉和机制

优化：
  链电优先选择陷阱中的敌人（强化路线联动）
  链电跳弹时清晰显示电弧路径
  每次链电击杀触发小型 EMP 视觉波纹

Lv.7 进化 A — 量子计算：
  链电可以弹回已击中目标（A→B→A 可能）
  总链次数翻倍

Lv.7 进化 B — 过载回路：
  链电对相同目标第二次击中时伤害 +80%
  适合单体高血目标

操作方式不变（自动），但需要和便签配合使用空间
```

### 7. 耳机 🎧 — A 类 + 站位条件

```
现状态：始终环绕的光环（A 类）
改造后：光环效果和站位挂钩

正常状态：光环半径 = baseRadius，伤害 = baseDmg
站立状态（0.3 秒不移动）：
  半径 ×1.5，伤害 ×1.3，轨道报表 +2 圈
  视觉：光环颜色加深，出现同心圆波纹
移动状态：
  光环缩小（0.5 秒过渡），回到正常
  
决策点：敌人逼近时"再站 2 秒吃完这一波"还是"现在就跑"
跑太早 = 输出掉 50%
跑太晚 = 受伤

Lv.7 进化 A — 静音全域：
  站立 3 秒后触发全屏脉冲
  击退所有敌人 + 眩晕 1 秒 + 大量伤害
  脉冲后冷却 8 秒

Lv.7 进化 B — 降噪共鸣：
  轨道报表每击中 10 次触发一次小脉冲
  半径 ×0.5 但频率 ×3
```

### 8. 报表 📊 — A 类（保持自动）

```
现状态：环绕轨道弹幕（A 类）
改造后：保持自动，但轨道数量随站位变化

正常状态：轨道数 = baseOrbits
站立状态（配合耳机）：轨道 +2
轨道碰触敌人时出现"文件散落"粒子

Lv.7 进化 A — 年度报告：
  轨道半径扩大 30%，旋转速度 +50%
  命中产生碎片追踪附近敌人

Lv.7 进化 B — 报表结界：
  轨道碰撞后留下"数据光栅"残留伤害
  每个轨道后拖出持续 1 秒的伤害尾迹

操作方式不变（自动），但站位决策绑定
```

### 9. 碎纸机 🗑️ — B 类

```
现状态：已改为定向锥形绞碎（B 类雏形）
需要强化：锥形方向 = 最后移动方向（同键盘/订书机）

与键盘的关系：
  键盘 = 瞬间挥击 + 击退
  碎纸机 = 持续喷射 + 绞杀
  两者面向同一方向 = 毁灭锥形
  键盘清近身→碎纸机收远距离残血

Lv.7 进化 A — 工业粉碎：
  锥形角度 +40%，伤害 +35%
  代价：暖机时间改为 1.5 秒

Lv.7 进化 B — 自动进纸：
  碎纸机持续期间自动吸引前方 100px 内敌人
  吸力随距离衰减（近强远弱）
```

### 10. 保温杯 🫖 — D 类

```
现状态：自动蓄能治疗（A 类）
改造后：主动释放

按 [Q] 释放蒸汽爆发：
  消耗当前所有茶量
  产生范围蒸汽治疗 + 伤害
  半径 = 70-110px（根据茶量）
  治疗量 = 茶量 × 0.3
  伤害 = 茶量 × 0.2

蓄能条件：站立时蓄能速度 ×2
  → 和耳机路线有天然协同
  → 耳机堡垒站住后顺便蓄茶量，关键时刻爆发

Lv.7 进化 A — 无限续杯：
  蒸汽爆发不消耗茶量（改为 CD 8 秒）
  茶量始终满格

Lv.7 进化 B — 浓缩咖啡：
  蒸汽伤害 ×2.5，治疗减半
  变成输出技能而非治疗技能
```

## 操作复杂度一览

| Build | 主要操作 | 次要操作 | 操作密度 |
|-------|---------|---------|---------|
| 精准贯穿 | 鼠标瞄准+蓄力释放 | WASD 走位 | 高 |
| 键盘风暴 | WASD 方向控制 | 冲阵时机判断 | 中高 |
| 工位雷网 | 鼠标预判布陷阱 | WASD kiting | 中高 |
| 会议结界 | WASD 站位决策 | 站/走判断 | 中 |
| 碎纸混搭 | WASD 近身-撤退 | 方向切换 | 中 |
| 保温杯混搭 | WASD 站/走 + Q 技能 | 茶量管理 | 中 |

纯自动武器保持低门槛（计算器、报表），
手动武器提供技巧表达空间（马克笔、便签、保温杯）。

新人可以先玩耳机堡垒或便签计算器（中等操作），
熟练后再玩精准贯穿或键盘风暴（高操作）。
