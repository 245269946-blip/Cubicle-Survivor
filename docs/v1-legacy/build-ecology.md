# Build 生态位表 v1.0

**目标：4 个路线不再只是"数值风格不同"，而是战斗节奏、操作方式、短板截然不同。**

---

## 路线 1：精准贯穿（咖啡 + 马克笔）

### 战斗节奏：**狙击手**
- **咖啡**：对最近敌人快速点射，清近身威胁。射速快、单发低、带贯穿。
- **马克笔**：按住蓄力，松开发射高伤贯穿激光。蓄力越久伤害越高，满蓄额外暴击。
- **节奏**：咖啡扫近身 → 退后找角度 → 马克笔蓄力秒杀高血目标 → 重复。

### 爽点
- 满蓄马克笔一穿五，每个都暴击
- 咖啡贯穿收割残血，连锁触发特效
- 在怪群中精准点杀精英，不碰小怪

### 短板
- **怕包围**：被虫群贴身后没有自保手段，咖啡打不死、马克笔蓄不出来
- **怕高速冲脸**：intern / change 冲过来时没时间蓄力
- **输出窗口窄**：必须在安全距离才能有效输出
- **无续航**：挨打就是真的挨打，没有盾/回血

### 操作方式（需要改造）
```
现有：自动瞄准发射
改为：
  咖啡 = 自动向最近敌人射击（保留自动）
  马克笔 = 玩家按住某个键蓄力，松开发射
         蓄力条显示在角色头顶
         Lv.7 进化：蓄力期间自动发射咖啡弹幕
```

### 应该怕的敌人
| 敌人 | 为什么克 |
|------|---------|
| bug 群 | 数量淹没，咖啡清不过来 |
| intern | 速度冲脸，没时间蓄力 |
| change | 快速骚扰，打断瞄准节奏 |

### 应该克的敌人
| 敌人 | 为什么怕 |
|------|---------|
| deadline | 弱点 1.35x，远程对狙占优 |
| boss | 马克笔满蓄单体爆发最强 |
| audit | 弱点 1.38x（配合 calculator 时），高血量适合贯穿 |

## 路线 2：键盘风暴（键盘 + 订书机）

### 战斗节奏：**狂战士**
- **键盘**：向鼠标/右摇杆方向挥击，弧形 AOE。每次击中产生击退和短硬直。
- **订书机**：向同一方向扇形喷出弹幕。击中后订书机 CD 缩短。
- **节奏**：冲进怪堆 → 键盘挥击清近身 → 订书机扇形扫远 → 键盘挥击 CD 好 → 继续。
- **核心循环**：键盘命中 → 减订书机 CD → 订书机命中 → 减键盘 CD → 永动。

### 爽点
- 冲进 20 只虫群，两下键盘全清
- 键盘+订书机交替不停，屏幕全是键帽和订书钉
- 击退把精英推到墙角，订书机全弹命中

### 短板
- **怕远程**：冲不过去的距离是被白打
- **怕单体高血**：爆发后没死，进入长空窗期
- **贴脸吃伤害**：必须近身输出，容错低
- **怕击退免疫**：Manager / Boss 不吃击退，键盘失去功能性

### 操作方式（需要改造）
```
现有：键盘自动挥击（有方向但不用管）
改为：
  键盘 = 向玩家面对方向（最后移动方向）挥击
         需要玩家控制朝向
         WASD 移动同时决定挥击方向
         Lv.7 进化：挥击产生冲击波，覆盖背后
  订书机 = 向同一方向射击（自动，但方向受控）
```

### 应该怕的敌人
| 敌人 | 为什么克 |
|------|---------|
| deadline | 远程高伤，冲过去的过程就被打到 |
| manager | 不吃击退，贴脸站撸反而吃亏 |
| alarm | 高速+高伤，追不上也躲不掉 |

### 应该克的敌人
| 敌人 | 为什么怕 |
|------|---------|
| bug 群 | 挥击 AOE 完美对位 |
| meeting | 体积大容易命中，击退后出安全空间 |
| 包围精英 | 越包围越兴奋（路线联动） |

## 路线 3：工位雷网（便签 + 计算器）

### 战斗节奏：**布阵师**
- **便签**：主动放置范围陷阱到指定位置。陷阱持续 4-6 秒，踩入减速+受伤。
- **计算器**：自动连锁电击，优先链入陷阱中的敌人。
- **节奏**：预判敌人走向 → 在路径上布陷阱 → 拉开 → 计算器收割 → 新方向再布。

### 爽点
- 布 3 个陷阱封住一条走廊，看虫群排队踩进去
- 计算器从陷阱敌人起跳，连锁全屏 8 次
- 一个精英踩进三重陷阱，瞬间蒸发

### 短板
- **需要预判**：陷阱放错位置 = 白放
- **被冲脸 = 等死**：没有即时输出，没有自保
- **CD 管理严格**：陷阱放完还在冷却时只能跑
- **开阔场地弱势**：敌人从四面八方来时无法封路

### 操作方式（需要改造）
```
现有：便签自动放下陷阱
改为：
  便签 = 玩家按技能键在脚下/指向位置放置陷阱
         有放置 CD（2-3 秒），最多同时 5 个
         Lv.7 进化：陷阱自动向最近敌人缓慢移动
  计算器 = 保持自动连锁（不需要操作）
```

### 应该怕的敌人
| 敌人 | 为什么克 |
|------|---------|
| change | 太快，陷阱还没生效就穿过去了 |
| alarm | 到处乱窜，不按预判路线走 |
| emergency | 冲进安全区，打乱整个布局 |

### 应该克的敌人
| 敌人 | 为什么怕 |
|---------|---------|
| meeting | 慢，陷阱充分生效 |
| audit | 弱点 1.38x，陷阱+链电双重克制 |
| intern | 弱点 1.45x，速度虽快但跑进陷阱后即死 |

## 路线 4：会议结界（耳机 + 报表）

### 战斗节奏：**堡垒**
- **耳机**：以玩家为中心的大范围光环。**站立不动时范围扩大 50%，伤害+30%。移动后 1 秒内缩减。**
- **报表**：环绕玩家的轨道弹幕，自动碰撞敌人。**站立时轨道数量 +2。**
- **节奏**：选阵地 → 站稳 → 输出飙升 → 敌人逼近 → 判断：再守一回合还是转移 → 转移 → 重新站稳。
- **核心决策**："我现在该站还是该走？"

### 爽点
- 站稳 3 秒，光环+轨道全开，满屏敌人融化
- 轨道报表像卫星一样高速旋转切割
- 耳机脉冲爆发，全屏击退+眩晕

### 短板
- **站不住 = 0 输出**：被逼移动时 DPS 掉 50%+
- **转移代价极高**：换位置 = 重新暖机
- **怕强制位移**：Boss 推人直接废掉
- **对单体不如精准路线**：虽然是 AOE 之王，但单个 Boss 打得很慢

### 操作方式（需要改造）
```
现有：光环始终生效
改为：
  耳机 = 光环始终存在，但站立时效果 ×1.5
         移动后光环范围缩小，1 秒后恢复
         需要玩家做"站/走"决策
         Lv.7 进化：站立 3 秒后触发全屏脉冲（击退+伤害）
  报表 = 保持自动环绕（不需要操作）
         但站立时轨道数量 +2
```

### 应该怕的敌人
| 敌人 | 为什么克 |
|------|---------|
| deadline | 远程输出逼你走位 |
| boss | 强制位移技能打乱阵地 |
| alarm | 高速冲脸逼你撤离 |

### 应该克的敌人
| 敌人 | 为什么怕 |
|------|---------|
| bug 群 | 站稳后 AOE 全覆盖 |
| meeting | 慢=留在光环里吃满伤害 |
| intern | 围过来正好被轨道切 |

## 跨路线混搭（2 路线各 1 武器）

| 混搭 | 战斗风格 | 爽点 | 短板 |
|------|---------|------|------|
| 键盘+碎纸机 | 近战绞肉机 | 双 AOE 叠加，贴脸毁灭 | 怕一切远程 |
| 咖啡+计算器 | 精准链杀 | 标记→链电，单体爆发 | 怕虫群 |
| 耳机+保温杯 | 不朽堡垒 | 光环+蒸汽治疗，站到天荒地老 | 单体输出极低 |
| 便签+报表 | 轨道雷区 | 陷阱+轨道双自动，走位即输出 | 成型最慢 |
| 键盘+便签 | 冲阵陷阱 | 击退把敌人推进陷阱 | 操作复杂度最高 |
| 马克笔+计算器 | 远程链爆 | 蓄力秒杀+弹跳收尾 | 蓄力时毫无自保 |

---

## 设计原则

1. **每个 Build 的操作方式不同**——不是"换个武器自动打"
2. **每个 Build 的短板明确且不可弥补**——玩家必须学会应对短板，不能靠数值硬吃
3. **混搭有自己的风味**——不强制走纯路线
4. **短板 > 长板**——好的体验不是"我很强"，而是"我在我的短板上变聪明了"
