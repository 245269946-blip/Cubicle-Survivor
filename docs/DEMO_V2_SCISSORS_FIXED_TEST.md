# 《工位幸存者》Demo V2.3 剪刀固定类型测试

状态：**独立受控候选；不覆盖 Demo V2.1 马克笔与 Demo V2.2 保温杯**

入口：`Cubicle-Survivor-demo/demo-v2-scissors.html`

## 1. 范围与版本边界

本轮只验证剪刀，并将武器级内容版本递增为 **Demo V2.3**。剪刀是第四把候选武器，也是固定测试里的第一把纯近战武器。

复用五阶段 17 关、四次模块选择、六次组件商店、经验属性分配、材料与三部位 1/2/4/8 品质进度；不把剪刀加入完整 Demo V1、阶段 A、阶段 B 或完整 Demo V2 主线。

低血量防护区作为本轮固定携带的独立测试道具，不进入模块、组件或随机道具商店。禁止加入第三模块、工牌、跨武器协同、武器买卖、通用道具池或永久成长。

## 2. 基础剪击

- 未获得模块时，向最近敌人方向执行一次角色前方的小范围剪击。
- 攻击判定绑定角色当前位置，不生成脱手投射物、持续留场或自动环绕。
- 攻击距离短、伤害中等，必须贴近并调整方向。
- 不命中角色背后的敌人。
- 第一次获得模块后，基础剪击替换为对应模块阶段。

## 3. 单轮时间轴

一轮攻击最多包含两个阶段，顺序固定为：

> 合刃突刺 → 张刃连剪

只拥有一条路线时只执行对应阶段。完整动作结束前禁止开启下一轮；同一轮的方向在起手时锁定，后续段数不得追踪身后敌人。

攻速只对整条时间轴计算一次：缩短内部段落、终结衔接和轮后等待的总时长。设置单段最低间隔与整轮最低持续时间，禁止内部间隔和外部冷却重复吃攻速。

## 4. 固有被动：轻步突进

- 通过时间和完成有效攻击轮次充能；多目标命中只提供少量额外充能且每轮有上限。
- 多段伤害不能按每个数字重复获得基础充能。
- 满充能后，在下一轮攻击开始前自动突进，突进结束立即攻击。
- 方向优先级：当前移动输入 → 当前攻击目标 → 当前朝向。
- 突进可穿过普通敌人但不能越过边界；突进不造成伤害。
- 突进期间获得固定极短闪避窗口；距离、窗口与充能速度不受组件强化。
- 人物附近显示可预测的充能进度条，满充能时明确提示下一轮将突进。

## 5. 模块轴 A：合刃突刺 Lv1–Lv4

定位：窄幅、较长、单次高伤、从角色位置发出的纵向贯穿。

- **Lv1｜单次突刺**：1 次狭长矩形贯穿，每个敌人在本次突刺中只受一次伤害。
- **Lv2｜双重突刺**：同一锁定方向连续 2 次，长度与宽度小幅增加。
- **Lv3｜三重突刺**：同一方向连续 3 次，继续强化纵向路线处理。
- **Lv4｜贯穿裁断**：三次突刺后追加更宽更长的高额贯穿斩；命中普通敌人固定减速约 35%、持续约 1.7 秒，重型与 Boss 保留递减后的少量效果。

贯穿裁断仍是近战长条，不转为圆形或全屏攻击。继承伤害、暴击与有上限的范围。

## 6. 模块轴 B：张刃连剪 Lv1–Lv4

定位：短距离宽扇面多段剪切，中心目标更容易承受完整连击，攻击后不留场。

- **Lv1｜双重剪切**：同一方向连续 2 次。
- **Lv2｜四重剪切**：连续 4 次，长度与宽度小幅增加。
- **Lv3｜六重剪切**：连续 6 次；玩家必须让目标留在正面中心。
- **Lv4｜终幕斩杀**：六次剪切后追加一次高额终剪，并读取目标本轮承受的前置剪切次数。

普通敌人终剪斩杀线为基础 5%，每承受一次前置剪切增加 2%，完整六次最高 17%。精英上限更低；Boss 最高 5%，超过上限的收益转为少量终剪伤害。斩杀仅由终剪命中结算，不暴击，也不受伤害属性直接提高。

## 7. 混合路线

四次模块选择允许 4/0、3/1、2/2、1/3、0/4。纯路线获得 Lv4 终局机制；混合路线同时获得纵向贯穿和正面范围处理，但因包含两个顺序阶段而拥有更长动作时间，不获得隐藏伤害补偿。

## 8. 组件

| 部位 | 互斥方向 | 规则 |
|---|---|---|
| 剪刃 | 伤害 / 暴击 | 强化正常剪刀伤害；斩杀判定不暴击 |
| 转轴 | 攻速 / 闪避 | 攻速只缩短一次完整时间轴；闪避不延长突进窗口 |
| 手柄 | 范围 / 移动速度 | 范围有近战上限；移速不增加突进距离或充能 |

同类购买按 1/2/4/8 件升为白/蓝/紫/红。购买同槽另一方向会替换并清空原进度。组件只提供属性，不解锁突进、减速、斩杀、防护区或新动作。

## 9. 固定测试道具：低血量防护区

- 玩家生命首次降至 30% 以下时触发，持续短时间并进入固定冷却；同一段低血状态不能连续触发。
- 区域外发出的远程弹体在进入防护区边界时被拦截。
- 已在区域内的敌人仍可近战命中；接触、环境与不可闪避伤害正常结算。
- 防护区不增加闪避率，不提供全面无敌，也不由组件强化。
- 玩家恢复到阈值以上后，下一次重新进入低血状态才可在冷却结束后再次触发。

## 10. HUD 与结果统计

战斗 HUD 显示轻步充能、下一轮突进状态、合刃/开刃等级、每轮突刺/剪切次数、当前是否处于攻击时间轴、贯穿裁断与终幕斩杀解锁状态、防护区状态。

结果页统计突进次数、突进闪避、合刃命中、开刃命中、贯穿裁断、终幕斩杀和实际斩杀次数，以及防护区触发与拦截远程弹体数量。

## 11. 验收门槛

1. 30 秒内可以判断剪刀是角色绑定的纯近战，不是短距离投射或保温杯扇面换皮。
2. 背后敌人不会被基础剪击、突刺或连剪自动命中。
3. 轻步突进可预测、方向优先级正确、不越界、不伤敌，固定闪避窗口不会被组件延长。
4. 多段攻击按一轮获得充能，不能按伤害数字倍增。
5. 高攻速状态仍不会出现两轮动作重叠，攻速倍率只计算一次。
6. 合刃 Lv1–Lv3 按 1/2/3 次增长并锁定同一方向；Lv4 仍是近战长条贯穿并产生递减减速。
7. 开刃 Lv1–Lv3 按 2/4/6 次增长；中心目标更可能承受完整连剪。
8. 终幕斩杀只奖励本轮前置命中且受普通、精英、Boss 上限约束。
9. 混合路线动作更长但兼顾纵深与正面，不稳定压过获得 Lv4 的纯路线。
10. 闪避、移速与范围提高近战容错，但不会把剪刀变成远程武器或高频无敌。
11. 低血量防护区只拦截区外远程压力，不阻止贴身与不可闪避伤害。
12. 最终循环清晰成立：贴近 → 爆发 → 突进 → 闪避 → 调整方向 → 再次贴近。
