# 《工位幸存者》Demo V2.1 马克笔固定测试规格

状态：**Demo V2.1 候选基线**
适用入口：`Cubicle-Survivor-demo/demo-v2-marker.html`
版本边界：只验证马克笔，不扩展保温杯、即时贴、工牌、第三模块、负面道具、卡牌、协同或旧工坊。

## 1. 本轮目标

继续验证三条成长线，并修正关卡拖尾、初始生存压力、组件选择路径、马克笔击退和留档视觉/判定偏差。

- **经验**：战斗中累计经验并产生升级点；每关收集期结束后进入升级属性商店，由玩家分配。
- **模块**：前四阶段 Boss 后固定选择复写或留档，负责改变攻击机制。
- **材料与组件**：六次组件商店直接购买具体属性组件；同槽属性互斥，同类购买合成品质，只负责武器属性成长。

模块、经验点和材料互不消耗。经验提供小幅通用属性，组件提供更集中的武器属性专精。

## 2. 单局与阶段结构

- 5 个阶段，共 17 关。
- 标称战斗倒计时总和仍为 14 分 50 秒。
- 每关结束后固定进入 **10 秒资源收集期**；停止生成敌人，玩家可以移动拾取，结束时自动吸取剩余经验和材料。
- 下一关开始前显示短暂预告：关卡名、怪物类型、主要压力文案。当前文案允许先作为占位，但必须读取真实关卡配置。
- 前四阶段各 3 关；第五阶段 5 关。
- 模块节点：第 3、6、9、12 关后。
- 组件商店：第 2、5、8、11、14、16 关后。

顺序仍保持：

> 战斗 → 10秒收集 → 经验属性分配（若有点数）→ 商店/模块/下一关

模块与组件商店不能连续出现，中间至少保留一关完整战斗。

## 3. 固定怪量与通关条件

每关配置固定普通敌人配额。生成器达到配额后必须停止，HUD显示“尚未生成 + 场上存活”的总剩余量。

### 普通关

满足以下任意一项即可通关：

1. 本关倒计时归零；
2. 固定敌人配额已经生成并全部清除。

固定数量是生成上限和提前清场目标，不再要求弱 Build 在倒计时结束后继续处理厚血残兵。进入收集期时驱散剩余普通敌人。

### Boss关

Boss死亡是必要条件，同时还必须满足以下任意一项：

1. 本关倒计时已经归零；
2. 固定普通敌人配额已经生成并全部清除。

因此快速击杀Boss不会立刻跳过整关；但若玩家已经完成全部清杂，也不必等待空倒计时。

分裂敌人的子体计入固定配额，避免实际敌人数无限超出关卡表。

## 5. 经验属性商店

普通敌人稳定掉落经验，经验仍需靠近拾取。经验条满后不立刻弹窗，只增加 1 个待分配升级点。

每关10秒收集期结束后，如果有待分配点数，打开升级属性商店。每个点数从12项基础属性中随机出现4个不同选项，可重复投资：

- 生存：最大生命、护甲、闪避。
- 恢复：生命再生、生命窃取。
- 输出：伤害、攻击速度、暴击率。
- 覆盖与走位：范围、速度。
- 资源：幸运、收获。

当前不加入近战伤害、远程伤害、元素伤害和工程学，也不制作属性品质与升级刷新。幸运先提高普通敌人的材料掉率；收获每投入1次，在每关结算时额外提供1材料。

所有待分配点用完后，才进入本关对应的组件商店、模块选择或下一关。Demo V2.1 将马克笔初始升级需求提高，目标是平均每关约0—2点，禁止一次结算连续选择大量属性。

## 6. 材料与组件经济

三个物理槽位分别为笔头、笔身、笔尾；每个槽位的两个属性方向彼此互斥：

| 槽位 | 互斥方向 |
|---|---|
| 笔头 | 伤害 / 穿透 |
| 笔身 | 攻速 / 数量 |
| 笔尾 | 范围 / 持续时间 |

商店直接出售“伤害笔头”“穿透笔头”等具体组件，不再先购买部位、合成后再弹属性二选一。

- 空槽购买：装入该方向的白色组件。
- 同方向购买：累计1/2/4/8件，依次提升为白/蓝/紫/红。
- 另一方向购买：整个槽位替换为新方向，原品质与累计件数清空，新方向从白色1件开始。
- 每次商店首次打开时，所有已装但未红的方向至少各保证出现1个同类升级件。
- 商品必须明确显示“装入 / 同类升级 / 替换并重置”，以及购买后的品质进度。

- 白色组件价格从 10 降为 **7材料**。
- 首次刷新费用从 3 降为 **2材料**；同一商店继续刷新时递增。
- 普通敌人材料掉率提高到低概率可感知水平。
- 精英稳定掉落2材料，Boss继续提供独立材料包。
- 第1、2关保底材料合计必须允许第一次商店在不依赖随机掉落时购买2个白色组件。

结果目标：

- 正常集中投资：稳定1红，并推进第二部位。
- 击杀和材料收集较好：有机会完成2红。
- 极高效率与良好刷新：才可能冲击3红。

## 7. 阶段4强度修正

阶段4不允许形成原地站桩秒杀：

- 复写新增平行线与第二轮使用递减伤害系数，不再让每条复制线都继承100%伤害。
- 留档多条墨迹降低单条倍率并放慢伤害跳数，覆盖膨胀仍保留。
- Lv4全屏机制继续作为终局反馈，但普通线、复制线和全屏线分别使用独立倍率。
- 阶段4、5同步提高普通敌人与Boss耐久，保持“明显变强但仍需移动和处理威胁”。
- 每个阶段的第一关使用更低的基础敌人生命，以数量和阵型重新建立节奏，不用厚血拖延新阶段开场。
- 马克笔即时激光与复写线不再击退敌人，避免破坏玩家主动排出的贯穿队列。
- 留档墨迹改为更宽的低伤减速带：判定与可见宽度统一，不使用锐利的瞬时激光表现。

## 8. 验收重点

1. 每关实际生成数不超过固定配额；普通关在“时间到或配额清空”任一条件成立时进入收集期。
2. Boss必须死亡，并满足“时间到或杂兵清完”后才能进入收集期。
3. 10秒收集期允许移动拾取，结束时不会遗漏场上经验和材料。
4. 下一关预告能显示真实怪物类型与压力文案。
5. 经验升级点由玩家分配，且不侵占组件五项专属武器属性。
6. 组件属性方向互斥；同类才能合成，替换会明确重置；首次开店保证当前未红方向的同类升级件。
7. 阶段4不再站桩秒杀，复写和留档仍有清晰数量/覆盖膨胀。
8. 17关、6商店、4模块和最终Boss流程完整可跑通。

未通过本规格前，不增加第三模块，不扩展其他武器，也不把该组件经济回写旧Demo V1。
