# Demo V1 武器声音事件映射

> 本文只描述 active Demo V1：`Cubicle-Survivor-demo/`。声音系统不建立第二套战斗命名；它直接消费视觉合同已经登记的 71 个 `source`。

## 当前实现结论

- 71/71 个武器事件源均有声音合同，覆盖 15 个部门形态、转正/精修、跨部门与跨武器辅助。
- 当前没有外部音频文件，第一版使用 Web Audio 实时合成，先验证玩法节奏、辨识度和层级；以后替换采样时无需改战斗事件名。
- 战斗事件进入 `traceWeaponEvent` 后，同时写入视觉轨迹和声音审计轨迹。即使浏览器尚未解锁、静音或不支持 Web Audio，也会留下可自动验收的映射记录。
- 浏览器首次指针或键盘操作后解锁声音；暂停界面提供“声音：开/关”，静音状态写入本地存储。

## 合同字段

每个 `source` 必须包含：

- `family`：`marker / thermos / sticky_note`
- `role`：`primary / secondary / support`
- `voice`：合成音色预设
- `triggers`：真实事件类型到时间线阶段的映射，例如 `beam -> release`、`hit -> impact`
- `timeline`：沿用视觉层的 `anticipation / release / impact / residual / fade`
- `cooldown` 与 `hitCooldown`：事件限流，避免多段贯穿和持续区每帧叠音
- `mix`：主次层级混音系数

声音角色强度为：

| 角色 | 混音 | 职责 |
|---|---:|---|
| 主形态 `primary` | 1.00 | 明确当前 Build 的主要攻击节奏 |
| 跨部门 `secondary` | 0.55 | 能辨认新增机制，但不盖住主轴 |
| 跨武器 `support` | 0.36 | 只提示借来的核心动词，保持辅助感 |

全局同时发声上限为 12 个 voice。命中声音额外降到事件音量的 0.58，连续命中采用独立 `hitCooldown`。

## 三种武器的基础听感

| 武器 | 主音色方向 | 玩家应听到的核心动词 |
|---|---|---|
| 马克笔 | 高频锯齿划线、扫描下滑、标记上扬、短促点击 | 划线、贯穿、分裂、扫描、标记 |
| 保温杯 | 低频蓄热上升、柔蒸汽、粗蒸汽泄压、模块提示音 | 蓄热、沸点、释放、巡航、据点 |
| 即时贴 | 纸张落点噪声、寻敌上扬、开关双音、路线短拍、传播跳音 | 放置、装订、触发、连锁、传播 |

## 验收与替换规则

- `test-runner.js` 强制声音 source 数与视觉 source 数相等，并检查 family、role、voice、trigger、timeline、cooldown 和 mix。
- 代表性实战测试必须确认声音事件确实进入 `state.stats.audioEvents`，不能只有静态配置。
- `demo-qa.js` 检查所有形态签名引用的 source 同时具有视觉和声音映射。
- 固定靶场将 `source:voice:role:stage` 写入 `data-mechanic-lab-audio`，并输出解锁、静音、播放与审计状态。
- 后续替换真实素材时，应按 `voice` 家族替换合成器，不得绕过 `source`、角色混音和限流规则直接在战斗函数里播放文件。

## 下一轮建议

现在适合进入真实玩家盲测和听感调音：优先调整三种主武器的频段冲突、沸点释放的重量感、即时贴连锁的节奏清晰度，再决定是否制作/采购正式采样与背景音乐。不要在完成这轮听感验证前扩新武器。

## 2026-07-13 阶段环境音乐

环境音乐已经接入同一个 Web Audio 总线，并与武器 SFX 共用首次交互解锁和持久化静音控制。当前定义 10 个程序合成场景：五个学习阶段各有普通关与 Boss 关变奏。

| 阶段 | 普通关 | Boss 关 | 听感职责 |
|---|---:|---:|---|
| 初始武器理解 | 84 BPM | 104 BPM | 稀疏工位节拍，留空间听清基础攻击 |
| 工牌形态定型 | 92 BPM | 110 BPM | 增加中频脉冲，强调形态开始成型 |
| 转正后主轴强化 | 100 BPM | 116 BPM | 更连续的旋律步进，表现主轴成熟 |
| 跨部门协作 | 108 BPM | 122 BPM | 使用更开放的和声音程，表现双部门叠加 |
| 跨武器学习 | 116 BPM | 132 BPM | 最密集的终局节拍，但仍低于武器 SFX 主层 |

Boss 变奏不是简单提高音量：它提高 BPM、缩短打击间隔、增加低音脉冲并改变波形。暂停时音乐总线降低到战斗音量约四分之一；离开战斗进入选择或工坊时保留低强度阶段氛围，避免每个页面完全断音。

这套程序音乐用于确认阶段辨识和节奏，不视为最终音乐资产。后续替换正式曲目时必须保留 `phase:normal / phase:boss` 十场景合同和同一静音总线。
