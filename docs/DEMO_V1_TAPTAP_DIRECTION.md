# Demo V1 TapTap 推进方向

> 当前计划发布目标调整为 TapTap。现阶段不推进 Steamworks、SteamPipe、Steam 商店审核或对应平台功能。

## 当前优先级

Demo V1 继续按“核心玩法完成度与玩家体验完成度优先”推进：

1. 陌生玩家能在不听开发者解释的情况下理解三把武器。
2. 每次 Build 选择后十秒内能看见攻击方式变化。
3. 主动输入、蓄力窗口、护盾触发、标记倒计时和布阵进度在战斗中可直接读取。
4. 三条合理构筑路线的完整体验时长和 Boss 用时不出现极端差异。
5. 完成真实玩家盲测后，再决定 TapTap 包体、账号体系、数据统计和商店物料。

## 当前不做

- 不增加第四把武器。
- 不增加新的成长系统、成就、排行榜或长期养成。
- 不提前做 Steam 专属接入。
- 不用全局加血量掩盖单个武器过强或过弱。
- 不把程序合成音乐和现有临时美术直接视为最终宣传素材。

## 下一轮完成标准

- 8–12 名首次接触玩家完成无指导试玩。
- 关键操作遗漏导致的卡住次数为 0。
- 至少 80% 玩家能说出所选武器的核心动词。
- 至少 80% 玩家能指出一次 Build 选择造成的实战变化。
- 三条核心路线的自动战斗时间保持在约 10–12 分钟。
- 根据玩家录像只修前三项高频问题，不横向扩内容。
