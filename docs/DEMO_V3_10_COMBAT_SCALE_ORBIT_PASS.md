# Demo V3.10 战场比例与外围武器修正

## 问题

Demo V3.9 把四套新人物图集统一为 112px 绘制高度，但只完成了跨武器一致，没有验证人物、普通怪物和战场空间之间的比例。

透明像素实测显示：

- 旧版 70px 图块中的人物实际可见高度约 56px；
- V3.9 剪刀与修正液人物实际可见高度约 81—82px；
- 普通怪物基础可见尺寸仍约 48px。

同时，部分武器虽然中心锚点位于人物外侧，但素材长轴仍穿回人物中心，导致“外围武器”在实机中继续遮挡角色。

## 本版边界

Demo V3.10 完整继承 Demo V3.9：

- 武器、敌人、Boss、模块、组件与经济数值；
- 17关与阶段流程；
- 马克笔、保温杯、剪刀、修正液的既有机制和素材。

只调整：

- 人物绘制尺度；
- 瞄准武器外围半径；
- 多武器横向间距；
- 穿戴件的同步缩放；
- 贴身泄压效果与人物新尺度的协调。

## 尺度合同

- 四套异化人物图集统一使用 78px 绘制高度。
- 人物透明像素可见高度回到约 55—59px。
- 普通敌人继续保持约 48px 基础尺寸。
- 穿戴件继续绑定身体挂点，但随人物尺度同步缩小。
- 瞄准武器使用各自真实素材长宽比计算外围间距，不能只移动素材中心点。

外围基准：

| 武器 | 外围半径 | 基础武器高度 |
|---|---:|---:|
| 马克笔 | 54px | 22px |
| 保温杯 | 47px | 32px |
| 剪刀 | 49px | 48px |
| 修正液喷头 | 51px | 18px |

## 所有权仍然保持

- 墨仓、压力包、剪刀腰部铰链、修正液储液囊属于人物穿戴层。
- 笔、杯、完整剪刀和修正液喷头属于瞄准武器层。
- 只有瞄准武器跟随攻击方向。
- 软管、把手或连接件可以接触人物；武器主体不得压住头部、胸腹和腿部。

## 验收

1. 四把武器切换后人物可见尺寸不跳变。
2. 人物高度接近 Demo V3.5 旧版，而不是 V3.9 的大比例。
3. 四类瞄准武器在八方向均能看见，并且内缘不穿过身体核心。
4. 普通怪物与人物能在同一画面中形成明确的围攻压力。
5. V3.9 数值快照完全不变。
