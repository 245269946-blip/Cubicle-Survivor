# 《工位幸存者》Demo V3.3 修正液前期循环强化说明

Demo V3.3 只修复修正液在第一阶段依靠单点喷涂、难以周转高密度敌群的问题。马克笔、保温杯、剪刀以及 V3.2 的怪群密度、低伤高频预算和霓虹表现保持不变。

## 核心调整

- 基础伤害由 5 调整为 5.8，基础攻击间隔由 0.29 秒调整为 0.27 秒。
- 主喷涂仍然只锁定距离玩家最近的一个威胁。
- 主喷涂命中后，若附近 68 像素内存在另一个敌人，会产生一次近邻溅写：造成主喷涂 52% 的伤害并附加1层错误。
- 近邻溅写最多影响1个敌人，不留下区域，不产生独立多目标锁定。
- 选择致命纠错 Lv1 后，近邻溅写关闭，改由路线能力提供两个独立主目标，避免基础能力与模块升级重叠。

## 验收边界

1. 第一阶段密集敌群中，修正液能同时培养主目标与一个近邻目标。
2. 敌人分散时，修正液仍然表现为单目标状态武器。
3. 错误扩散路线可以借助溅写更快建立死亡节点，但不会免费获得污染区域。
4. 致命纠错 Lv1 仍然是清晰的机制升级，而不是基础溅写的数值加强。
5. V3.2 保留为回归入口，不被覆盖。
