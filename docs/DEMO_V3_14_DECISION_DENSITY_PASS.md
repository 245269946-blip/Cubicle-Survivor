# Demo V3.14 轻量决策版

状态：当前推荐四武器试玩入口  
入口：`Cubicle-Survivor-demo/demo-v3-14.html`

## 目标

Demo V3.14 完整继承 Demo V3.13 的四武器机制、数值、17 关、敌群、Boss、模块、经验与组件经济。它只解决一个核心体验问题：购买页和选择页文字过多，玩家需要先读懂系统才能做决定，直接削弱策略判断与继续游玩的欲望。

## 决策页硬规则

- 页面只回答当前问题，不承担系统说明书职责。
- 单张卡默认只显示名称、立刻结果，以及最多一条未来或协同提示。
- “怎么操作”“完整机制”“实体成长细节”优先在战斗反馈中表达；非当前信息延后或删除。
- 不允许通过缩小字号、增加滚动或压紧行距保留长文案。
- 文案必须以玩家结果开头，避免重复“不会解锁什么”“不属于什么系统”等边界说明。

## 页面落地

- 武器选择：四张卡只保留打法标签和一句攻击方式。
- 经验选择：移除重复的主形态标签，只保留属性名与即时效果。
- 模块选择：保留“立刻”；第二行按情境显示“终局”“协同”或“专精”，不再同时展示四段说明。
- 组件商店：规则压成一句；商品只显示安装/升级/替换结果、实体位置、材料与操作按钮。
- 组件品质强化：只显示当前投入与可选属性。

## 回归边界

- Demo V3.13 继续保留为四武器欲望链回归快照。
- 不改变任何武器伤害、攻速、范围、模块等级、组件价格、刷新价格或关卡节奏。
- 自动 QA 必须验证 V3.14 继承 V3.13 且只启用 `decisionCompressionPass`。
- 1280×720 必须人工检查武器、模块、经验和组件四类决策页，确认无裁切、无滚动依赖，且首眼焦点落在可点击选项而不是说明文字。
