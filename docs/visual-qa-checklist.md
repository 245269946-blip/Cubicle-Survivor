# Visual QA Checklist

每次提交前必须做一次视觉检查，尤其是中文 UI 和贴图。

## 必查项

- 中文标题、标签、按钮必须横向显示，不能逐字竖排。
- 卡片内图标、标题、标签、描述不能互相遮挡。
- 弹层打开时，关卡横幅、提示条、暂停按钮不能盖在弹层内容上。
- 桌面 16:9 视口检查升级面板、工坊面板、结算面板。
- 移动窄屏视口检查升级面板和结算面板，内容不能横向溢出；必要时允许纵向滚动。
- 贴图和图标必须落在自己的容器内，不能漂到文字上或被裁掉关键部分。
- 按钮文字必须完整可读，不能被压缩到单字换行。

## 当前推荐验收视口

- Desktop: 1600 x 900
- Mobile: 390 x 844
