# 《工位幸存者》Demo V3.4 Boss机制与环形战场说明

Demo V3.4 是建立在 Demo V3.3 之上的小型关卡空间修整。本轮不改四把武器、模块、组件与数值成长，只解决出生位置、刷怪方向和 Boss 战内容不足三个问题。

## 本轮锁定目标

1. 新一局从 2600×1800 世界的真实中心出生，而不是停留在初始镜头左上区域。
2. 普通怪仍遵守每关固定配额、批次、场上限额与敌人名单，但从当前视野的完整环形边界随机进入。
3. Boss 不再只靠血量和接触伤害，增加有预警、可躲避、命中惩罚明确的专属攻击语法。

## 环形刷怪规则

- 队列：随机选择一个环形入口，保留狭长队列，但每批入口重新抽取。
- 集群：随机选择一个环形入口作为集群中心，保留局部抱团关系。
- 追击与混合压力：使用随机旋转和角度扰动，不再沿固定上下左右方向或完全等分圆周出现。
- 随机只改变空间入口，不改变怪物总量、关卡配额、敌人种类和关卡结束条件。
- 出生点保持在当前可视区域之外，避免随机贴脸。

## Boss攻击语法

### 点名追责

Boss 锁定玩家预警时的位置，先显示一条宽品红危险走廊，0.86 秒后沿相同方向释放五枚并排高速弹体。玩家需要横向离开走廊。

### 弹幕复核

Boss 先显示琥珀危险环与两条安全缺口边界，0.96 秒后释放环形弹幕。弹幕不会进入预告的缺口，玩家需要寻找并守住安全方向。

Boss 根据身份轮换攻击语法；后期阶段提高弹体数量与速度，低于半血后缩短下一次攻击间隔。所有伤害都发生在预警结束后，预警几何与真实弹道必须一致。

## 明确不做

- 不新增 Build 随机系统。
- 不改模块节点、组件商店或属性池。
- 不提高 Boss 血量来代替机制难度。
- 不改变每关固定怪物数量与通关条件。

## Build随机性后续议题

本轮只记录方向，不实现。推荐保持“武器身份与模块主轴固定，局内分支结果随机”：固定四次模块节点和武器母题，在节点内提供少量随机变体，并让 Boss 奖励/轻量道具承担跨轴规则变化。随机性应改变这一局如何兑现路线，而不是让玩家随机失去路线本身。

## 自动验收

1. V3.4 四武器入口保留 V3.3 的全部体验开关。
2. 四把武器开局坐标均为世界中心。
3. 环形采样覆盖四个象限，且出生点不落在当前可视区域内部。
4. Boss 预警阶段不直接扣血、不提前生成伤害弹体。
5. 点名追责生成五枚并排走廊弹体。
6. 弹幕复核同时显示危险环与两条安全缺口边界，并生成环形弹幕。
7. 两套 Boss 语法都进入运行时审计记录。
