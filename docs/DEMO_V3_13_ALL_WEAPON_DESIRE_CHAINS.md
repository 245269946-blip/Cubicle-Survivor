# Demo V3.13 四武器欲望链扩展版

## 版本边界

Demo V3.13 完整继承 Demo V3.12 的开局伤害、攻速、范围、17 关、敌群压力、Boss、经验与组件经济。它不增加新资源条、新操作键、道具系统或第三模块，只把 V3.12 已验证的成长表达扩展到保温杯、剪刀和修正液。

## 简单性门禁

每把武器只允许新增一条一句话能说清的混合关系：

- 保温杯：热浪碰到冷凝区会触发热交换。
- 剪刀：合刃命中张刃留下的裁缝会触发交叉裁切。
- 修正液：错误过载目标死亡会让旧污染区同步回滚。

玩家不需要管理额外资源，也不需要记忆额外概率或按键。机制深度来自原有两条路线的因果连接，而不是增加第三套系统。

模块卡保持同一阅读顺序：

1. 下一场立刻多什么；
2. 玩家应该如何利用；
3. 与另一模块会发生什么；
4. Lv4 最终会变成什么。

关系和即时变化是主信息，Lv4 预告是次级信息。

## 三把武器的关系

### 保温杯：热交换

冷青冷凝区储存战场空间，橙色击杀热浪负责兑现。当热浪扩张范围触碰冷凝区时，冷凝区位置产生一次白紫温差冲击，对区内敌人造成独立伤害与短暂减速。

纯冷凝第五次选择强化全屏冷凝的触发率、持续时间与伤害；纯热浪第五次选择强化全场点杀和死亡热浪。模块等级仍停在 Lv4。

### 剪刀：交叉裁切

张刃命中会留下短暂紫青裁缝；后续合刃突刺或裁断命中同一目标时消费裁缝，产生一组可见 X 形重剪。张刃负责留缝，合刃负责裁开。

纯合刃第五次选择强化大型裁断的长度、宽度和伤害；纯张刃第五次选择强化合剪终结的覆盖与处决阈值。模块等级仍停在 Lv4。

### 修正液：级联回滚

混合路线下，三层错误过载目标死亡会让既有污染区同步闪回：区内敌人受到一次伤害并追加一层错误。单体状态培养由此反向驱动污染网络。

纯扩散第五次选择强化系统崩溃的阈值、冷却和爆发；纯纠错第五次选择强化最终纠错的频率、百分比清算与死亡爆炸。模块等级仍停在 Lv4。

## 组件实体安装

三把武器的商店商品均显示自己的真实安装位置：

- 保温杯对应杯口喷汽冠、背部压力装置、喷汽口、导流环和冷/热双罐；
- 剪刀对应完整双刃、中央铰链、平衡配重、外延光刃和轻步牵引带；
- 修正液对应真实喷头、挤压泵、肩背分配器、储液囊和供液软管。

组件仍只提供基础属性，不新增攻击机制。
