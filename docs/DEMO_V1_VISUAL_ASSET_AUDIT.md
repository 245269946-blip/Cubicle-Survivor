# Demo V1 底层视觉资产审计

> 当前基线：2026-07-14。仅适用于 `Cubicle-Survivor-demo/`，不得与旧版原型混用。

## 根因结论

此前玩家看到的点、线、圆环和空面板不是单一素材加载失败，而是三层问题叠加：

1. 贴图存在但只被预加载，角色、敌人、特效与 UI 仍由 Canvas/CSS 几何绘制。
2. 旧几何渲染器虽然一度不在主循环调用，但仍留在源码中，误接线即可复活。
3. 新贴图覆盖在旧布局上，导致目标栏、Build 状态、经验条和卡槽内容叠压。

本轮已把运行时标准改为：可见视觉只能来自项目内 PNG 资产；CSS 只负责排版，Canvas 只负责贴图变换与清屏。

源图集和色键中间件只作为可追溯生产资料；运行时与分享包只引用验收后的最终 PNG。

## 已清除的回退路径

- 删除旧版 `drawEffects` 及其圆环、折线、矩形、方块粒子绘制函数。
- 背景未就绪时只透明清屏，不再补画纯色矩形。
- 主循环只调用 `drawGeneratedEffects`、贴图敌人与贴图玩家。
- `generated-skin.css` 禁用动画、过渡、阴影和伪元素装饰，并把可见 UI 表面映射为 PNG。
- 修正战斗 HUD 的独立视觉分区，避免 Build、机制状态与经验条互相覆盖。
- 删除 `selection-preview-vfx.png` 与 `marker-laser-vfx-spritesheet.png` 两张横向赛博预览条；武器选择页改用四张当前办公室机制图的静态组合，不再压缩、拉伸或循环播放多帧图。
- 删除旧马克笔、保温杯与即时贴临时特效；QA 会阻断旧文件名重新进入预加载、CSS 或运行时映射。
- 删除通用 RPG/科幻图标图集 `office-rogue-ui-icons.png`；部门改用电脑/剪贴板/工单/扩音器/审批章，卡槽改用订书器/急救资料夹/物料箱/制图工具/加班单据。新图集按 5×2、2:1 原始比例裁切，不再把宽图集强行压成方形。

## 强制验收门禁

`npm run qa` 会阻断以下回归：

- `generated-skin.css` 未在旧布局样式之后加载。
- 生成皮肤出现 gradient、keyframes 或非 `none` 的 animation。
- UI/CSS/HTML 引用的 PNG 不存在。
- 战斗运行时引用的任何 PNG 不存在。
- 战斗源码出现 `arc`、`fillRect`、`strokeRect`、`moveTo`、`lineTo` 或 Canvas gradient。
- 主循环重新调用旧几何渲染器，或背景恢复几何占位。

代码通过不等于视觉通过。每次修改仍须在 1280×720 实机检查三把武器、普通关/Boss 关和全部流程页；截图首帧若出现合成黑块须等待后复验，不能把首帧缓存现象当作素材结论。
