# 《工位幸存者》Demo V2.4 战斗视觉品质补全

状态：**范围冻结；只补 Demo V2.2 保温杯与 Demo V2.3 剪刀的视觉表达**

适用入口：

- `Cubicle-Survivor-demo/demo-v2-thermos.html`
- `Cubicle-Survivor-demo/demo-v2-scissors.html`

## 1. 本轮目标

Demo V2.4 不新增武器、模块、组件、道具、敌人、关卡或数值机制。它只解决两项固定测试已经能运行、但动态战斗素材不足的问题：

1. 保温杯的近距宽扇、冷凝、聚焦和热浪必须在战斗中互相可辨。
2. 剪刀的轻步、合刃、张刃、终剪和防护必须形成完整动作时间线，而不是只显示静态剪刀和通用光束。

## 2. 资产范围

### 保温杯

- 独立杯体：用于选择页、战斗持有物和武器识别。
- 宽扇喷汽：4 帧，读取基础扇面的真实方向、距离与横向宽度。
- 分段冷凝：4 帧，读取冷凝区真实圆心、半径和剩余寿命。
- 聚焦汽流：4 帧，读取玩家到真实低血目标的连线。
- 击杀热浪：4 帧，读取死亡点与真实传播半径。
- 全场点燃：复用热浪家族但使用独立暖色关键目标反馈，不伪装成全屏伤害。

### 剪刀

- 剪刀实体：保留现有 Demo V2.3 识别图，不无故换形。
- 轻步残影：4 帧，读取突进起点、终点和固定闪避窗口。
- 合刃突刺：4 帧，读取真实突刺长度、宽度和锁定方向。
- 张刃剪切：4 帧，读取真实扇面方向、距离和动作段数。
- 贯穿裁断 / 终幕终剪：使用同族动画的强化帧、放大、色相与冲击层，不新造无判定装饰。
- 防护区 / 弹体拦截：4 帧，读取真实区域半径与拦截位置。

## 3. 动态精度合同

- 动画帧由 `event.age / duration` 或伤害区 `life / maxLife` 驱动，不使用与判定脱节的独立定时器。
- 线性动作从真实 `x1/y1` 到 `x2/y2` 拉伸、旋转；区域动作以真实 `x/y/radius` 缩放。
- 每个事件只绘制一次主动画。保温杯扇面的多条判定辅助线与剪刀张刃的左右边界不得重复叠出多个完整动作。
- 资产使用透明 PNG 精灵条；运行时只允许 `drawImage`、位移、旋转、缩放和透明度，不恢复 Canvas 可见几何图元。
- 静态页面预览与战斗效果使用同一武器家族和色彩语言：保温杯青白蒸汽配暖金热浪，剪刀钢白刃光配橙红终剪和青色轻步。

## 4. 限度

- 不修改 Demo V2.2 / V2.3 的伤害、攻速、范围、组件品质和敌人压力。
- 不替换 Demo V1 三武器资源池，不把剪刀加入完整 Demo V2。
- 不增加屏幕常驻 HUD，不压缩战斗安全区。
- 不为“更华丽”添加没有伤害、控制、位移或防护语义的额外事件源。
- 不覆盖旧资产；所有新文件使用 `v24` 版本名，并可单独回退。

## 5. 验收

1. 不读文字也能区分保温杯的基础宽扇、冷凝铺场、聚焦点杀和击杀热浪。
2. 扇面视觉的长度与横向覆盖不小于真实判定，也不扩出明显虚假伤害区。
3. 剪刀一次完整动作能读出轻步进场、合刃纵向、张刃横向和终剪收束。
4. 张刃左右边界只生成一个完整剪切动画；多段通过帧相和节奏表达，不形成重复贴图噪音。
5. 防护区只在真实有效期内显示，弹体拦截反馈落在真实拦截位置。
6. 1280×720 下敌人、玩家、掉落物和危险弹体仍可读。
7. 自动 QA 无缺失资产、无旧裁切资源回流、无可见 Canvas 几何图元。
