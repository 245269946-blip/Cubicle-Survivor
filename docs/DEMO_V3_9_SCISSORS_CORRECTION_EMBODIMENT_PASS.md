# Demo V3.9 — 剪刀与修正液异化显形

## 版本边界

Demo V3.9 完整继承 Demo V3.8 的关卡、敌群、Boss、经验、材料、组件、模块和全部战斗数值。本轮只解决剪刀与修正液在实机中的实体归属、攻击因果和成长可读性。

入口：`Cubicle-Survivor-demo/demo-v3-9.html`

## 跨武器角色一致性

- 四把武器必须使用同一位金框眼镜办公角色。
- 人物头身比、发型、服装、四方向朝向和 112px 渲染高度与马克笔、保温杯图集对齐。
- 选择武器只能改变贴身异化装置、外部武器和攻击表现，不得改变人物画风、年龄、体型或镜头。
- 大型武器可以越出人物包围盒，但人物本体不能被长期遮住，也不能因为装备尺寸显得换了角色。

## 剪刀

### 实体结构

- 人物穿戴青/品红腰髋铰链外骨骼；穿戴层只跟随人物朝向。
- 战斗中始终只有一把完整剪刀：两枚手柄环、一枚铰链和两片完整刀刃。
- 待机剪刀靠近人物并跟随真实攻击方向；攻击事件开始后待机剪刀退场，由同一把完整剪刀的动画接管。
- 禁止同时出现待机剪刀、第二把攻击剪刀和无来源刀光。

### 路线表现

- 合刃：冷白、青、靛蓝，完整剪刀由张开到合拢并沿窄线突刺；Lv4 形成更长、更宽的定向裁断。
- 张刃：青与品红的梦幻丝线、纸屑和裁切裂痕；刀刃真实闭合后才出现宽幅裁切结果。
- 张刃保留梦幻、流动、略带原始魔性的霓虹感，避免把剪刀改成硬表面机械枪械。

## 修正液

### 实体结构

- 白色可挤压储液层贴合躯干/腰背，橙色压力阀固定在肩部，半透明软管连接至前臂喷头。
- 人物储液层与路线装置跟随人物朝向；只有喷头跟随真实攻击目标。
- 致命纠错的多喷头必须安装在同一条身体导轨上，并分别朝向真实目标；不得成为漂浮枪阵。

### 可见因果链

每次攻击必须按同一事件依次表现：

> 身体储液层挤压 → 软管/喷头响应 → 白色修正介质喷出 → 敌人获得白色错误痕迹

错误层数使用白色介质作为主体：

1. 一笔白色修正痕。
2. 两笔交叉/重复覆盖。
3. 厚重白色覆盖并出现青/品红故障裂纹。
4. 过载兑现时增加故障碎片与短暂橙红确认点。

颜色环、毒雾和普通激光不能代替白色错误痕迹。

### 路线表现

- 错误扩散：品红污染储液器、软管组织和世界错误区；死亡节点产生新的污染源。
- 致命纠错：冷青多喷头导轨与并行目标培养；Lv4 喷头聚焦最高错误目标后完成集中兑现。
- 整体可更生物化、蛇形和不稳定，但办公修正液的白色介质、橙色阀门与人工纠错母题必须保留。

## 实机验收

- 四把武器人物均为相同头身比、相同战斗高度和相同四方向身份。
- 剪刀基础、合刃、张刃和 Lv4 画面中均能指出同一把完整剪刀。
- 攻击时不存在第二把剪刀或两条竞争性的伤害特效。
- 修正液人物、喷头、白色喷流和敌人错误痕迹可沿画面连续追溯。
- 多目标纠错的喷头数量和角度来自真实目标，不是装饰性散射。
- 关闭霓虹 bloom 后，武器本体、安装关系和状态层数仍能辨认。
- Demo V3.8 与 V3.9 的四武器数值快照完全一致。
