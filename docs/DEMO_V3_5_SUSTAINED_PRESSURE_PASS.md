# 《工位幸存者》Demo V3.5 持续压力与属性兑现说明

Demo V3.5 建立在 Demo V3.4 的四武器、17 关、环形来敌与 Boss 预警语法之上。本轮不增加武器、道具、模块或 Build 随机系统，只解决“敌人很多但没有持续压力、Boss 招式之间发呆、属性成长看不出来”三个体验断点。

## 核心判断

地图尺寸不是主要原因。V3.4 的敌人已经按照当前镜头外围生成，真正的问题是：

1. 固定配额在开场短时间内集中释放，玩家清完第一团后整关失压；
2. 敌人位于屏外且移动、射击、冲刺偏慢，生成数量没有转化成接敌频率；
3. Boss 的专属招式冷却错误地占用了整段行为意图，导致冷却期间不进行普通射击或冲刺；
4. 马克笔基础射程已经接近整屏，继续增加长度很难被看见，范围属性没有同步改变线宽、并行间距与残留覆盖；
5. 近战与短程武器需要可交战距离和生存边界，不能用无限风筝或纯伤害堆高制造伪难度。

## 持续压力规则

- 每关固定配额保留，但只在开场释放约一小部分，剩余敌人按照关卡进度在 84%—88% 的战斗窗口内持续放量。
- 普通关提高总配额、场上目标下限与上限，同时缩小单批数量，避免第一批聚成一团后长期断怪。
- 普通敌人基础接敌速度提高，射手弹速与射击频率、冲刺敌人的冲刺频率与速度同步提高。
- 普通敌人不额外提高接触伤害；难度主要来自更多方向、更短空档和更多主动行为。
- 站桩会快速失败，但持续移动的四把武器必须都能通过前 12 秒真实受伤测试。
- 剪刀作为唯一纯近战武器获得小幅先天闪避余量，不增加额外生命或伤害。

## Boss 压力规则

- Boss 生命相对 V3.4 提高约 38%。
- 专属走廊与缺口弹幕提高弹体数量、速度与释放频率。
- 专属招式只在预警窗口拥有独占意图；冷却期间 Boss 恢复普通射击或冲刺。
- 普通 Boss 攻击频率、弹速、冲刺速度和伤害适度提高。
- 远程 Boss 保持危险的中距离环绕，不再永久停在保温杯有效范围之外。
- Boss 依然必须被击败，且遵守原有倒计时/敌群结算条件。

## 属性兑现规则

组件仍然只提供属性，不新增机制，但属性必须改变真实攻击形态：

- 马克笔范围同时提高长度、线宽、复写间距、留档间距与墨迹带宽；穿透组件每次提供更明显的贯穿数量。
- 保温杯范围同时扩大短距扇面纵深与横向宽度。
- 剪刀范围提高突刺长度和宽度、张刃扇面距离和角度、终局裁断覆盖。
- 修正液范围提高喷射距离、开局溅射半径与错误区域半径。
- 攻速、伤害组件的单次品质兑现幅度同步提高，但不改变经验属性每级的通用增量。

## 混合 Build 视觉层级

- 马克笔复写激光使用短促、锐利的暖黄色内核，位于战斗事件前景。
- 留档墨迹使用低亮度青蓝、柔边宽带，位于世界残留层，不再套用激光的强泛光。
- 两个模块同时存在时应明确看到“黄色即时切割 + 青蓝持续墨迹”，而不是融合成一个高亮色块。
- 剪刀合刃动作隐藏角色侧重复武器，并把普通剪刀本体放到突刺/裁断效果前端，使武器与攻击成为同一个动作。

## 明确不做

- 不缩小世界地图来伪造密度。
- 不新增敌人类型、道具、模块或随机 Build 规则。
- 不把所有敌人统一变成高血量木桩。
- 不提高普通怪接触伤害作为主要难度来源。
- 不改变固定 17 关、模块节点、组件商店和经验成长职责。

## 自动验收

1. V3.5 入口继承 V3.4 全部开关并独立启用持续压力、Boss 压力和属性兑现。
2. 开场释放量显著低于总配额，接近关卡末段时完整配额可被释放。
3. Boss 专属招式冷却期间普通攻击仍然工作。
4. Boss 生命、速度、弹幕数量和专属招式频率高于 V3.4。
5. 四把武器相同的满级范围组件必须让真实攻击形态相对 V3.4 明显扩大。
6. 四把武器均完成移动状态下的真实受伤开局测试。
7. 四把武器各完成一条 V3.5 完整 17 关流程；既有 V2.9 八条纯路线回归继续通过。
8. 剪刀合刃前端本体、马克笔暖色激光与青蓝墨迹的分层代码进入静态校验。
