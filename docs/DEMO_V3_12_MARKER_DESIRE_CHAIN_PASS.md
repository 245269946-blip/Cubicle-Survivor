# Demo V3.12 — 马克笔欲望链实验版

## 版本目标

V3.12 不增加新武器、道具、敌人或关卡，也不重新调整四武器基础数值。

它只回答一个问题：

> 玩家第一次接触马克笔时，能否在做出选择前看懂“现在会变什么、之后想追什么、两条路线如何产生新关系”，并在战斗中立刻确认这份承诺？

因此 V3.12 完整继承 V3.11 的前期容错、四武器平衡、17关、6次组件商店、5次模块选择和敌群压力。

## 一、模块选择的四层承诺

每张马克笔模块卡固定显示：

1. **现在改变**：下一场战斗立刻新增的攻击事件或场上实体。
2. **玩法要求**：玩家需要怎样瞄准、走位或利用旧路径。
3. **终局承诺**：该路线 Lv4 最终要形成的统治形态。
4. **组合关系**：另一模块接入后产生什么新因果，而不是两套效果简单并排。

升级确认反馈使用同一份承诺文本，避免选择页与实战提示互相矛盾。

## 二、混合路线：调阅

当复写和留档都至少达到 Lv1 时，解锁【调阅】。

真实循环：

> 基础激光留下冷青旧墨迹 → 后续暖黄复写线接触旧墨迹 → 沿整条档案触发洋红回读 → 旧墨迹短暂续期并再次结算。

边界：

- 只读取上一轮及更早的普通留档墨迹。
- 同一轮刚生成的墨迹不能自触发。
- 每轮最多触发2次，单条旧墨迹存在短内置冷却。
- 调阅拥有独立伤害来源、视觉事件、音频拓扑、HUD计数与结算统计。
- 洋红色只表示路线关系，不覆盖暖黄复写和冷青留档各自的所有权颜色。

## 三、纯路线：Lv4终局专精

整局仍只有5次模块选择，每条路线仍封顶 Lv4，不制造 Lv5。

若前4次全部投入同一路线，第5次形成真实二选一：

- 继续选择同一路线：锁定该路线【终局专精】。
- 选择另一条路线：放弃纯路线，接通【调阅】。

纯复写专精提高全页批注的触发率、伤害、宽度并缩短冷却。

纯留档专精提高整页归档的触发率、持续时间、墨迹伤害并缩短冷却。

这让“纯路线”与“混合关系”都获得独立回报，而不是一边天然正确。

## 四、组件的实体安装承诺

V3.12 不改变组件属性和合成经济，只补齐购买前后的物理语义：

- 笔头组件安装到每支真实发射笔的笔尖。
- 数量组件在人物近身外圈增加真实发射笔。
- 攻速组件安装到主发射笔的笔身控制器。
- 持续时间组件接入背部打印坞与留档供墨结构。
- 范围组件安装到每支发射笔的笔尾扩幅件。

商店商品显示安装位置和可见结果；已安装槽位持续显示实体位置。组件仍只强化基础属性，不解锁新攻击机制。

## 五、明确不做

- 不修改保温杯、剪刀、修正液的数值或机制。
- 不增加第三条马克笔模块路线。
- 不加入道具、器官拼装、法术融合或随机协同池。
- 不更改17关流程、商店价格、材料掉落和组件品质规则。
- 不用纯视觉特效伪装额外伤害判定。

## 六、验收标准

自动化必须验证：

1. V3.12入口和协调器正确，V3.11继承标记完整。
2. 三把非马克笔武器的战斗参数快照与V3.11完全一致。
3. 马克笔开局伤害、攻速和范围与V3.11一致。
4. 两张模块卡均包含四层承诺。
5. 第5次选择能在纯Lv4专精与混合路线之间真实分叉。
6. 纯专精不制造Lv5，也不暗中解锁调阅。
7. 调阅不能由同轮墨迹自触发，后续攻击能产生独立洋红事件。
8. 每个组件商品均声明实体安装位置与可见成长。
9. 完整QA、站点镜像校验和浏览器实机检查通过。
