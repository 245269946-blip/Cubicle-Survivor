# 《工位幸存者》Demo V2.5 修正液固定测试

状态：**机制与视觉范围冻结；作为 Demo V2.6 四武器整合版的第四把可选武器保留独立回归入口**

入口：`Cubicle-Survivor-demo/demo-v2-correction-fluid.html`

## 1. 本轮只验证什么

修正液验证第四种武器关系：

> 马克笔改变攻击路径，保温杯改变战场空间，剪刀改变自身位置，修正液改变敌人状态。

它复用固定测试的 5 阶段 17 关、4 次模块选择、6 次组件商店、经验属性分配和 10 秒关末回收。复用只用于横向比较，不授权把修正液加入 Demo V1、阶段 A/B、完整 Demo V2 或跨武器辅助池。

## 2. 基础攻击与错误状态

- 中距离单目标喷射，基础伤害较低，命中添加一层【错误】。
- 每个敌人独立拥有 0—3 层错误和状态持续时间。
- 1 层：移动速度降低。
- 2 层：只提高修正液家族伤害，不是全局易伤。
- 3 层：【错误过载】，本身不直接死亡，等待路线利用。
- 错误层数必须由敌人身上的白色修正痕迹读出；青/品红故障环只负责强化层级和过载，不替代状态主体。

## 3. 错误扩散 Lv1—Lv4

1. 过载目标死亡留下错误区域；区域造成低额持续伤害并感染进入者。
2. 区域扩大、延长，持续感染更稳定。
3. 相邻区域融合成大型污染区，并可更快重复叠加错误。
4. 三个以上区域触发【系统崩溃】：清除当前区域，对区域内敌人按错误层数爆发；崩溃击杀不立即重新生成区域。

这条路线的主要输出循环是“制造过载死亡节点 → 污染扩散 → 融合 → 系统崩溃”，不是传统毒伤常驻。

## 4. 致命纠错 Lv1—Lv4

1. 同时处理 2 个目标。
2. 同时处理 3 个目标。
3. 同时处理 4 个目标，并让过载目标进入更长、更脆弱的待修正状态。
4. 定期选择错误层数最高、随后生命价值最高的目标，清除错误并执行最终纠错；若目标死亡，产生一次小范围错误爆炸。

这条路线的主要输出循环是“高频培养多个错误目标 → 锁定最高错误目标 → 最终纠错”，重点是精英和 Boss，而不是普通散射弹幕。

## 5. 组件槽

| 槽位 | 互斥属性 |
| --- | --- |
| 笔头 | 伤害 / 攻速 |
| 墨管 | 暴击 / 范围 |
| 瓶身 | 持续时间 / 移动速度 |

组件继续遵守同槽二选一互斥、同类购买才按 1/2/4/8 推进白蓝紫红、购买另一属性会整槽替换重置。组件只改变属性，不产生错误区域、系统崩溃或最终纠错。

## 6. 视觉合同

- 武器本体保留白色修正液瓶、橙色瓶盖和少量办公物件材质。
- 喷射、状态、污染区和纠错使用“白色修正介质 + 青/品红故障霓虹 + 少量橙红错误码”。
- 背景已经是暗色办公室，战斗光亮用于表达状态升级和爆发，不把所有画面重新做成桌面文具陈列。
- 7 张 `v25` 透明资产包括瓶体，以及喷射、错误层、污染区、系统崩溃、故障环、最终纠错六张 2×2 四帧表。
- 所有动画位置、方向、范围、帧相与寿命读取真实战斗事件；不使用无判定装饰，也不绘制可见 Canvas 几何图元。

## 7. 验收

1. 三层错误无需读说明即可区分，过期后正确消失。
2. 2 层易伤只影响修正液家族伤害。
3. 错误扩散能形成感染、融合和清场循环，而非高伤毒池。
4. 致命纠错能优先培养错误目标，并对关键目标形成清楚处决反馈。
5. 混合路线可以用多目标快速制造过载，再用死亡区域补群体压力。
6. 组件路线产生不同购买判断，但不替代模块机制。
7. 1280×720 暗色战场中，白色介质可读，霓虹故障高光不遮挡敌人、弹体和掉落物。
