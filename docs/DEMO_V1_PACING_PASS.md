# Demo V1 第一轮节奏与数值调整

> 本文只描述 active Demo V1 的 16 关流程。本轮目标不是一次性做最终平衡，而是先缩短重复段、保留 Build 学习时间，并让群体型构筑在 Boss 评审中仍有表达空间。

## 调整后的普通关窗口

普通关持续时间现在限制在 30–65 秒，目标击破数限制在 20–80。具体蓝图为：

| 阶段 | 关卡 | 时长 | 目标击破 |
|---|---|---:|---:|
| 初始武器 | 1 / 2 | 34 / 38 秒 | 20 / 27 |
| 工牌定型 | 4 / 5 / 6 | 44 / 47 / 50 秒 | 34 / 40 / 46 |
| 主轴强化 | 8 / 9 | 52 / 54 秒 | 54 / 60 |
| 跨部门 | 11 / 12 | 54 / 57 秒 | 62 / 70 |
| 跨武器 | 14 / 15 | 58 / 62 秒 | 72 / 80 |

普通关不是单纯降难度：刷怪间隔同步略微加快，减少“尾段等怪”，同时略微降低会议怪与审批流的纯拖时属性。第一关 warmup 从 3 秒降至 2.4 秒，其余关卡从 1.2 秒降至 0.75 秒。

## Boss 关规则

- Boss 关只在 `stageBossDefeated` 为真时完成；击杀普通工作项不再可能误结算。
- Boss 存活期间最多保留 5 个敌人，并按低频补充普通工作项，让分裂、传播、连线和范围构筑仍能发挥。
- 自动攻击在 Boss 关优先锁定 Boss；由攻击产生的分支和范围效果仍可处理周围工作项。
- 五个 Boss 分别使用 0.16 / 0.12 / 0.10 / 0.09 / 0.075 的单次伤害上限比例，减少高爆发 Build 一击跳过完整评审节奏。
- Boss 血量调整为 380 / 820 / 1280 / 1680 / 2150。

## 下一轮验收重点

1. 真人操作下记录每阶段首次理解机制所需时间，而不只看自动路线。
2. 比较三种主轴在第 7、10、13、16 关的 Boss 本体伤害占比和清杂收益。
3. 重点观察玩家是否能通过新的机制状态条理解保温杯释放空窗、马克笔 Boss 回折和即时贴空格引爆。
4. 将死亡点、材料购买和玩家停留页面时间纳入总 Demo 时长，再决定是否继续压缩 16 关结构。
