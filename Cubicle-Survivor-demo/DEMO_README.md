# 工位幸存者 Steam Demo HTML 包

## 运行方式

直接用本地静态服务器打开本目录：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 当前垂直切片

- 实机武器：马克笔、保温杯、即时贴。
- 主流程：选择武器 -> 战斗 -> 工牌形态 -> 卡槽强化 -> 转正强化 -> 跨部门协作 -> 跨武器学习 -> 终局结算。
- 关卡威胁：16 关按阶段引入追击、绕行、厚血、远程、冲刺、分裂、护盾、客户远程压力；Boss / 评审关必须击破目标才算通过。
- 视觉管线：沿用 `assets/v2-weapon-vfx` 的 image2 帧动画 / sprite 资产。
- 本包为静态 HTML 包，不依赖构建步骤。

## 底座修复说明

本版本只处理底层可靠性：选择面板不再每帧重建 DOM，战斗层加入 world/camera，武器实现增加 `beam`、`zone`、`projectile` 等 primitive 合同入口。

三把武器的真实机制重写不在本次范围内，下一阶段必须按 `FOUNDATION_FIX_NOTES.md` 的验收原则逐个重验。

## 验证

已通过：

```bash
node test-runner.js && node demo-qa.js
```

其中：

- `test-runner.js` 覆盖 15 个武器 × 工牌形态、卡槽、战斗事件、转正、跨阶段链路。
- `demo-qa.js` 覆盖静态资源完整性、对外 demo 文案检查、三把武器实战循环烟测、8 类关卡威胁行为、三组关键 Boss 压力关实战、三把武器各自 1-16 关完整真实战斗路线、Boss 关击破验证、各自完整 16 关流程、三类工坊选择、刷新成本递增、最终胜利结算。
- 浏览器烟测覆盖三把武器进入战斗：`marker`、`thermos`、`sticky_note`。
