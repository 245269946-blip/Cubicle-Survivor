# 工位幸存者 Demo V1 HTML 包

## 运行方式

直接用本地静态服务器打开本目录：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

Demo V2 当前开放三个相互隔离的验证入口：

```text
http://127.0.0.1:4173/demo-v2.html
http://127.0.0.1:4173/demo-v2-b.html
http://127.0.0.1:4173/demo-v2-marker.html
```

阶段 A 是 60 秒“三把基础武器 × 四类敌群”测试，不开放成长。阶段 B 是 3 分钟 Build 对话测试：30 秒自动定型唯一代表工牌，随后在 55/100/145 秒各选择一次办公模块。阶段 B 只包含三条代表工牌和六类模块，不接入旧卡槽、军械库、材料或第二部门。默认入口仍是可完整运行的 Demo V1。

`demo-v2-marker.html` 是 Demo V2.1 的马克笔固定测试候选：5 阶段 17 关、每关固定怪物生成上限、关后 10 秒资源回收、Boss 双条件结算、4 次模块选择、6 次组件商店，以及从12项基础属性中随机四选一的经验升级。普通关倒计时结束或清空配额均可通过；组件商店直接出售互斥属性方向，同类购买升色、异类购买替换重置。该入口只验证马克笔的复写/留档两条机制轴与组件纵向成长，不扩展其他武器或旧系统。

## 当前垂直切片

- 实机武器：马克笔、保温杯、即时贴。
- 主流程：选择武器 -> 战斗 -> 工牌形态 -> 卡槽强化 -> 转正强化 -> 跨部门协作 -> 跨武器学习 -> 终局结算。
- 关卡威胁：16 关按阶段引入追击、绕行、厚血、远程、冲刺、分裂、护盾、客户远程压力；Boss / 评审关必须击破目标才算通过。
- 视觉管线：沿用 `assets/v2-weapon-vfx` 的 image2 帧动画 / sprite 资产。
- 本包为静态 HTML 包，不依赖构建步骤。

## 底座修复说明

本版本只处理底层可靠性：选择面板不再每帧重建 DOM，战斗层加入 world/camera，武器实现增加 `beam`、`zone`、`projectile` 等 primitive 合同入口。

三把武器的真实机制重写不在本次范围内，下一阶段必须按 `FOUNDATION_FIX_NOTES.md` 的验收原则逐个重验。

## 验证

已通过：

```bash
node test-runner.js && node demo-qa.js
```

其中：

- `test-runner.js` 覆盖 15 个 Demo V1 武器 × 工牌形态、阶段 A/B 门禁，以及 Demo V2.1 马克笔固定测试的配额、收集期、经验属性商店、Boss 双条件、材料经济和阶段 4 数值收束。
- `demo-qa.js` 覆盖静态资源完整性、对外 demo 文案检查、三把武器实战循环烟测、8 类关卡威胁行为、三组关键 Boss 压力关实战、三把武器各自 1-16 关完整真实战斗路线、Boss 关击破验证、各自完整 16 关流程、三类工坊选择、刷新成本递增、最终胜利结算。
- 浏览器烟测覆盖三把武器进入战斗：`marker`、`thermos`、`sticky_note`。
