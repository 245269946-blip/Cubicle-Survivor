# 工位幸存者底座修复版说明

本版本暂停新增关卡和新内容，只处理试玩反馈中暴露出的底层问题。

## 已确认的问题

- 选择面板在战斗循环中反复重建 HTML，导致武器、工牌、属性、商店卡片 hover 和点击状态抖动。
- 战斗空间原来是固定 1280x720 画布，玩家只能在固定框内移动，没有 world/camera 分层。
- 武器机制缺少统一的战斗 primitive 合同，容易用一个视觉事件或区域伤害冒充真实机制。
- 马克笔分裂、保温杯蓄热、即时贴召唤等仍需要下一阶段按真实机制合同重写和验收。

## 本次修复范围

- UI 渲染增加 HTML 写入缓存，同样内容不会每帧重建 DOM。
- 战斗状态增加 `world` 和 `camera`，玩家移动、敌人生成、绘制管线改为 world-space + camera viewport。
- 战斗层增加 `CombatPrimitives`，统一提供 `beam`、`circleEvent`、`zone`、`projectile` 基础结构。
- QA 增加底座合同，覆盖 UI 缓存、world/camera 跟随、primitive 暴露。

## 本次没有做的事

- 没有新增关卡。
- 没有新增武器或道具内容。
- 没有把三把武器的真实机制全部重写。
- 没有重新包装视觉资产。

## 下一阶段验收原则

- 武器描述必须能被代码事件和屏幕表现同时证明。
- 马克笔分裂必须是命中后生成新的 beam path，并能命中新目标。
- 保温杯蓄热期间和释放期间必须有不同且可感知的攻击节奏。
- 即时贴的寻敌、放置、连线必须拆成明确实体，而不是混用 circle zone。
- QA 不能只检查总伤害，必须检查事件类型、命中链、实体生命周期和视觉资源。
