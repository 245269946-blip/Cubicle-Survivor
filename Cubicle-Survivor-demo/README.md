- `marker-desire-loop.html`：验证复写、留档、实体组件、“调阅”融合和纯路线 Lv.4 终极技能否在三分钟内形成继续游玩的欲望。

- 该入口仍是独立三分钟实验；已验证的武器展示逻辑由 Demo V3.6 正式吸收，但实验自身继续保留。实验边界见 `../docs/MARKER_DESIRE_LOOP_EXPERIMENT.md`。
