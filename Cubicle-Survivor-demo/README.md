- 详细边界和验收流程见 `../docs/DEMO_V3_0_COMBAT_PERCEPTION_PASS.md`。

这是一个可直接运行的 HTML 试玩包，核心体验是：

- 选择马克笔、保温杯、即时贴三把初始武器之一。
- 通过工牌形态把同一把武器改造成不同战斗路线。
- 在 16 关中经历卡槽强化、转正强化、跨部门沟通、跨武器学习和终局评审。
- 使用材料工坊持续补强当前主武器 Build。

Demo V2.3 继续沿用 5 阶段 17 关、4 次模块选择和 6 次组件商店，只把验证对象替换为剪刀：轻步闪身、合刃突刺、张刃连剪/处决，以及固定携带的低血临时安全区。剪刀仍是隔离测试，不进入 Demo V1 或完整 Demo V2 的三武器池。
