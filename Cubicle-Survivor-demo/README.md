# 工位幸存者 Steam Demo

这是一个可直接运行的 HTML 试玩包，核心体验是：

- 选择马克笔、保温杯、即时贴三把初始武器之一。
- 通过工牌形态把同一把武器改造成不同战斗路线。
- 在 16 关中经历卡槽强化、转正强化、跨部门沟通、跨武器学习和终局评审。
- 使用材料工坊持续补强当前主武器 Build。

## 底座修复版

本版本只修复试玩反馈暴露出的底层问题：选择面板 DOM 抖动、固定屏幕战斗空间、缺少战斗 primitive 合同。

详细问题、处理范围和下一阶段武器验收标准见：

```text
FOUNDATION_FIX_NOTES.md
```

## 本地运行

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/
```

## 验证

```bash
npm run qa
```

该命令会执行武器形态、阶段流程、Boss 击破、三条完整实战路线、静态资源和对外文案检查。
