# 工位幸存者 Demo V1

这是一个可直接运行的 HTML 试玩包，核心体验是：

- 选择马克笔、保温杯、即时贴三把初始武器之一。
- 通过工牌形态把同一把武器改造成不同战斗路线。
- 在 16 关中经历卡槽强化、转正强化、跨部门沟通、跨武器学习和终局评审。
- 使用材料工坊持续补强当前主武器 Build。

## 底座修复版

本版本只修复试玩反馈暴露出的底层问题：选择面板 DOM 抖动、固定屏幕战斗空间、缺少战斗 primitive 合同。

详细问题、处理范围和下一阶段武器验收标准见：

```text
FOUNDATION_FIX_NOTES.md
```

## 本地运行

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/
```

## 固定武器测试入口

- `demo-v2-7.html`：Demo V2.7 四武器正式可玩入口（推荐）。
- `demo-v2-6.html`：Demo V2.6 四武器霓虹整合试玩（历史快照）。

- `demo-v2-marker.html`：Demo V2.1 马克笔双路线测试。
- `demo-v2-thermos.html`：Demo V2.2 保温杯双路线测试。
- `demo-v2-scissors.html`：Demo V2.3 剪刀纯近战双路线测试。
- `demo-v2-correction-fluid.html`：Demo V2.5 修正液错误系统双路线测试。

Demo V2.6 在一个选择页中整合马克笔、保温杯、剪刀和修正液。四把武器分别代表路径、空间、自身位置和敌人状态四种关系；选择后仍进入各自隔离的 5 阶段 17 关固定配置。暗色办公室只作为底板，战斗使用克制的赛博霓虹高光；修正液以白色修正介质、青/品红故障扫描和橙红崩溃反馈形成最强的错误系统视觉。

Demo V2.7 是早期可玩体验修整快照：修复 Boss 关普通怪继承 Boss 血量的问题，将第一次模块选择提前到第 1 关后，并完成剪刀突进蓄力指向、快速移动、剪切动作、安全区、属性页、组件页和正式文案的可玩体验修整。模块选择共 5 次，但每条路线仍最高 Lv4。

Demo V2.4 是上述保温杯与剪刀入口共享的战斗视觉品质补全：新增保温杯实体与宽扇/冷凝/聚焦/热浪四帧动画，新增剪刀轻步/合刃/张刃/防护四帧动画。V2.4 不修改两把武器的数值和固定测试版本身份，动画位置与尺寸读取同一套战斗判定事件。

Demo V2.3 继续沿用 5 阶段 17 关、4 次模块选择和 6 次组件商店，只把验证对象替换为剪刀：轻步闪身、合刃突刺、张刃连剪/处决，以及固定携带的低血临时安全区。剪刀仍是隔离测试，不进入 Demo V1 或完整 Demo V2 的三武器池。
